# HJ50 四则运算

## 一、题目为什么要用栈

表达式不能简单地从左到右计算，因为有优先级：

```text
括号 > 乘除 > 加减
```

例如：

```text
3 + 2 * 4 = 11
```

必须先算 `2 * 4`，再算加法。

括号又可能有三种：

```text
()、[]、{}
```

它们的作用相同，都表示先计算括号中的内容。

这类“遇到符号先暂存，满足条件后再计算”的问题，很适合使用栈。

## 二、两个栈分别做什么

使用两个栈：

```text
numbers：数字栈
operators：运算符栈
```

例如处理：

```text
3 + 2 * 4
```

读取过程大致是：

```text
读到 3：数字栈 [3]
读到 +：运算符栈 [+]
读到 2：数字栈 [3, 2]
读到 *：运算符栈 [+, *]
读到 4：数字栈 [3, 2, 4]
```

表达式结束后，先处理栈顶的 `*`：

```text
2 * 4 = 8
```

再处理 `+`：

```text
3 + 8 = 11
```

这就自动保证了乘法优先于加法。

## 三、什么时候计算

遇到以下情况时，把运算符栈顶的运算符取出来计算：

1. 遇到右括号：一直计算到对应的左括号；
2. 遇到新运算符：如果栈顶运算符优先级不低于新运算符，就先计算栈顶；
3. 表达式读取结束：把运算符栈剩余内容全部计算完。

## 四、负数怎么处理

如果 `+` 或 `-` 出现在表达式开头、左括号后、或者另一个运算符后，它表示正负号，而不是二元加减法。

例如：

```text
-4
2*-3
[-4+7]
```

代码将这种符号分别记为：

```text
u+
u-
```

其中 `u` 表示一元运算。

## 五、Python 栈实现

```python
import sys


s = sys.stdin.readline().strip()

numbers = []       # 数字栈
operators = []     # 运算符栈

priority = {
    '+': 1,
    '-': 1,
    '*': 2,
    '/': 2,
    'u+': 3,
    'u-': 3,
}

left_brackets = '([{'
right_to_left = {
    ')': '(',
    ']': '[',
    '}': '{',
}


def divide(a, b):
    """整数除法，结果向 0 截断。"""
    result = abs(a) // abs(b)

    if (a < 0) != (b < 0):
        return -result

    return result


def calculate_top():
    """计算运算符栈顶部的一个运算符。"""
    operator = operators.pop()

    # 一元正负号只需要一个数字
    if operator == 'u+':
        return

    if operator == 'u-':
        numbers.append(-numbers.pop())
        return

    # 二元运算符需要两个数字
    right = numbers.pop()
    left = numbers.pop()

    if operator == '+':
        numbers.append(left + right)
    elif operator == '-':
        numbers.append(left - right)
    elif operator == '*':
        numbers.append(left * right)
    else:
        numbers.append(divide(left, right))


def push_operator(operator):
    """将普通运算符压入运算符栈，并先计算更高优先级运算符。"""
    while operators and operators[-1] not in left_brackets:
        top = operators[-1]

        if priority[top] > priority[operator]:
            calculate_top()
        elif priority[top] == priority[operator] and operator not in ('u+', 'u-'):
            # 二元运算符同级时从左到右计算；一元运算符不提前计算
            calculate_top()
        else:
            break

    operators.append(operator)


index = 0
expect_operand = True

while index < len(s):
    ch = s[index]

    # 读取完整数字
    if ch.isdigit():
        value = 0

        while index < len(s) and s[index].isdigit():
            value = value * 10 + int(s[index])
            index += 1

        numbers.append(value)
        expect_operand = False
        continue

    # 左括号直接入栈
    if ch in left_brackets:
        operators.append(ch)
        index += 1
        expect_operand = True
        continue

    # 右括号：计算到对应左括号
    if ch in right_to_left:
        left_bracket = right_to_left[ch]

        while operators[-1] != left_bracket:
            calculate_top()

        operators.pop()
        index += 1

        # 处理 -(2+3) 这种括号前的一元负号
        if operators and operators[-1] in ('u+', 'u-'):
            calculate_top()

        expect_operand = False
        continue

    # 加减可能是一元正负号，也可能是二元运算符
    if ch in '+-':
        if expect_operand:
            operator = 'u' + ch
        else:
            operator = ch

        push_operator(operator)
        index += 1
        expect_operand = True
        continue

    # 乘除
    if ch in '*/':
        push_operator(ch)
        index += 1
        expect_operand = True
        continue

    index += 1


# 表达式结束后，清空运算符栈
while operators:
    calculate_top()

print(numbers[-1])
```

## 六、样例中的栈变化

处理：

```text
3+2*4
```

读取数字和运算符：

```text
读取 3：numbers = [3]
读取 +：operators = ['+']
读取 2：numbers = [3, 2]
读取 *：operators = ['+', '*']
读取 4：numbers = [3, 2, 4]
```

表达式结束后，先弹出 `*`：

```text
2 * 4 = 8
numbers = [3, 8]
```

再弹出 `+`：

```text
3 + 8 = 11
numbers = [11]
```

## 七、括号的处理

例如：

```text
2*[3+4]
```

遇到 `[` 时压入运算符栈。遇到 `]` 时，不断计算栈顶，直到遇到 `[`：

```text
3 + 4 = 7
```

然后删除 `[`，最后计算：

```text
2 * 7 = 14
```

## 八、整数除法

不能直接使用 Python 的 `//` 处理负数，因为：

```python
-3 // 2 == -2
```

而四则运算中整数结果通常向 `0` 截断，应为 `-1`。

因此代码先计算绝对值：

```python
abs(a) // abs(b)
```

再根据两个数的符号决定结果正负。

## 九、复杂度

每个字符最多入栈、出栈一次：

```text
时间复杂度：O(len(s))
空间复杂度：O(len(s))
```
