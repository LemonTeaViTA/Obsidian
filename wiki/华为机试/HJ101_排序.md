# HJ101 排序

## 一、答案

```python
import sys

n = int(sys.stdin.readline())
numbers = list(map(int, sys.stdin.readline().split()))
op = int(sys.stdin.readline())

if op == 0:
    numbers.sort()
else:
    numbers.sort(reverse=True)

print(*numbers)
```

## 二、题目翻译成人话

输入一组整数，再输入一个排序要求：

```text
op = 0：从小到大排序
op = 1：从大到小排序
```

例如：

```text
数组：1 2 2 5 4
op = 0
```

从小到大排列后是：

```text
1 2 2 4 5
```

## 三、这是什么类型的题目

这是一道基础排序题。Python 已经提供了列表排序方法，直接调用即可，不需要自己实现冒泡排序或选择排序。

## 四、`sort()` 是什么

```python
numbers.sort()
```

表示把列表 `numbers` 按从小到大排序，而且会直接修改原列表。

例如：

```python
numbers = [5, 1, 4, 2]
numbers.sort()
print(numbers)
```

输出：

```text
[1, 2, 4, 5]
```

## 五、`reverse=True` 是什么意思

```python
numbers.sort(reverse=True)
```

默认情况下，`sort()` 是升序，也就是从小到大。

加上 `reverse=True` 后会变成降序，也就是从大到小：

```text
原数组：5 1 4 2
降序结果：5 4 2 1
```

因此代码根据 `op` 选择：

```python
if op == 0:
    numbers.sort()
else:
    numbers.sort(reverse=True)
```

## 六、为什么重复数字不用特殊处理

题目没有要求去重，只要求排序，所以相同数字要全部保留。

例如：

```text
1 2 2 5 4
```

排序后仍然有两个 `2`：

```text
1 2 2 4 5
```

`sort()` 会自动正确处理重复数字，不需要额外代码。

## 七、输入代码解释

```python
n = int(sys.stdin.readline())
```

读取数组长度 `n`，例如输入 `5` 后，得到整数 `5`。

```python
numbers = list(map(int, sys.stdin.readline().split()))
```

读取第二行的数字：

1. `readline()` 读取一整行；
2. `split()` 按空格拆分；
3. `map(int, ...)` 把每一项转换为整数；
4. `list(...)` 转换成列表。

```python
op = int(sys.stdin.readline())
```

读取排序方向。

## 八、`print(*numbers)` 是什么

如果写：

```python
numbers = [1, 2, 4, 5]
print(numbers)
```

输出会带方括号和逗号：

```text
[1, 2, 4, 5]
```

但题目要求输出：

```text
1 2 4 5
```

所以使用：

```python
print(*numbers)
```

`*numbers` 会把列表拆开，等价于：

```python
print(1, 2, 4, 5)
```

Python 的 `print` 默认用空格分隔参数，正好符合题目格式。

也可以写成：

```python
print(' '.join(map(str, numbers)))
```

不过 `print(*numbers)` 更简单。

## 九、样例解析

### 样例 1

```text
n = 5
numbers = [1, 2, 2, 5, 4]
op = 0
```

`op=0`，升序排序：

```text
[1, 2, 2, 4, 5]
```

输出：

```text
1 2 2 4 5
```

### 样例 2

```text
numbers = [1, 2, 2, 4, 5]
op = 1
```

`op=1`，降序排序：

```text
5 4 2 2 1
```

## 十、复杂度

Python 排序的时间复杂度为 `O(n log n)`，额外空间复杂度通常为 `O(n)`。

题目限制 `n <= 1000`，可以轻松通过。
