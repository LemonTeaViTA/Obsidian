# HJ73 计算日期到天数转换

## 一、答案

```python
import sys


year, month, day = map(int, sys.stdin.readline().split())

# 先按照平年设置每个月的天数
days_in_month = [31, 28, 31, 30, 31, 30,
                 31, 31, 30, 31, 30, 31]

# 判断是否为闰年
is_leap = (year % 400 == 0) or (year % 4 == 0 and year % 100 != 0)

# 闰年的2月多1天
if is_leap:
    days_in_month[1] = 29

# 当前日期是：前面完整月份的天数 + 当前月份已经经过的天数
answer = sum(days_in_month[:month - 1]) + day

print(answer)
```

## 二、题目翻译成人话

输入一个日期：

```text
年 月 日
```

要求计算这个日期是这一年的第几天。

例如：

```text
2012 12 31
```

2012 年是闰年，全年有 366 天，所以 12 月 31 日是第 366 天。

## 三、怎么计算第几天

假设输入的是 `3 月 4 日`，那么它是：

```text
1 月的完整天数 + 2 月的完整天数 + 3 月已经经过的 4 天
```

平年中：

```text
31 + 28 + 4 = 63
```

所以 `1982 年 3 月 4 日` 是第 63 天。

代码中的：

```python
sum(days_in_month[:month - 1]) + day
```

就是这个计算过程。

## 四、`days_in_month` 是什么

```python
days_in_month = [31, 28, 31, 30, 31, 30,
                 31, 31, 30, 31, 30, 31]
```

这是一个列表，按月份顺序保存每个月的天数：

```text
下标 0：1 月，31 天
下标 1：2 月，28 天
下标 2：3 月，31 天
...
下标 11：12 月，31 天
```

Python 列表的下标从 `0` 开始，而月份从 `1` 开始，所以月份 `month` 对应的下标是 `month - 1`。

## 五、为什么切片是 `[:month - 1]`

Python 的列表切片：

```python
列表[:结束下标]
```

会取出从开头到“结束下标之前”的元素，不包含结束下标。

例如：

```python
days_in_month = [31, 28, 31, 30, 31]
days_in_month[:2]       # [31, 28]
sum(days_in_month[:2])  # 59
```

当 `month = 3` 时：

```python
days_in_month[:month - 1]
```

也就是：

```python
days_in_month[:2]
```

取出 1 月和 2 月，正好是当前 3 月之前的完整月份。

如果输入的是 1 月：

```python
days_in_month[:0]  # []
```

前面没有完整月份，天数就是当前的 `day`。

## 六、什么是闰年

题目规定，满足下面任意一种情况就是闰年：

1. 年份能被 400 整除；
2. 年份能被 4 整除，但不能被 100 整除。

因此代码写成：

```python
is_leap = (year % 400 == 0) or (year % 4 == 0 and year % 100 != 0)
```

其中：

- `%` 是求余数，例如 `2024 % 4 == 0` 表示 2024 能被 4 整除；
- `or` 表示“或者”；
- `and` 表示“并且”。

例如：

```text
2024：能被4整除，不能被100整除，是闰年
1900：能被4整除，但也能被100整除，且不能被400整除，不是闰年
2000：能被400整除，是闰年
```

## 七、为什么闰年只修改 2 月

平年和闰年的区别只有 2 月：

```text
平年 2 月：28 天
闰年 2 月：29 天
```

列表中第 2 个月对应下标 `1`，所以写：

```python
if is_leap:
    days_in_month[1] = 29
```

修改后，后面的求和会自动使用 29 天。

## 八、样例解析

### 样例 1

输入：

```text
2012 12 31
```

2012 能被 4 整除且不能被 100 整除，是闰年。2 月按 29 天计算：

```text
1 月到 11 月：335 天
12 月 31 天
总计：335 + 31 = 366 天
```

输出：

```text
366
```

### 样例 2

输入：

```text
1982 3 4
```

1982 不是闰年：

```text
1 月 + 2 月 + 3 月前4天
= 31 + 28 + 4
= 63
```

输出：

```text
63
```

## 九、输入代码解释

```python
year, month, day = map(int, sys.stdin.readline().split())
```

这句代码完成三件事：

1. `readline()` 读取一行，例如 `2012 12 31`；
2. `split()` 按空格拆分成 `['2012', '12', '31']`；
3. `map(int, ...)` 把字符串数字转换成整数，并分别赋给 `year`、`month`、`day`。

## 十、复杂度

月份最多只有 12 个，因此：

- 时间复杂度：`O(12)`，可以看作 `O(1)`；
- 额外空间复杂度：`O(12)`，也可以看作 `O(1)`。

## 十一、记忆方式

```text
准备12个月的天数

闰年把2月改成29天
加上当前月份之前的所有天数
再加当前日期的日数
```
