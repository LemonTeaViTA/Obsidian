# HJ13 句子逆序

## 一、答案

```python
import sys


words = sys.stdin.readline().split()
reversed_words = words[::-1]

print(" ".join(reversed_words))
```

## 二、解题思路

题目要求以“单词”为单位反转句子，不是把每个字符都反转。

例如：

```text
Nowcoder Hello
```

包含两个单词：

```text
第一个单词：Nowcoder
第二个单词：Hello
```

只交换两个单词的位置，单词内部字母顺序不变：

```text
Hello Nowcoder
```

可以分成三步：

1. 使用 `split()` 将句子拆成单词列表；
2. 使用 `[::-1]` 反转单词列表；
3. 使用 `" ".join()` 将单词用空格重新连接。

## 三、什么叫“以单词为单位逆序”

假设输入是：

```text
I am a student
```

拆成单词后：

```python
["I", "am", "a", "student"]
```

反转的是这个列表中单词的位置：

```python
["student", "a", "am", "I"]
```

重新连接后：

```text
student a am I
```

每个单词内部没有改变：

```text
student 仍然是 student
am 仍然是 am
```

## 四、代码逐行解释

### 1. 读取句子并拆成单词

```python
words = sys.stdin.readline().split()
```

`sys.stdin.readline()` 读取输入的一整行。

例如输入：

```text
Nowcoder Hello
```

`split()` 按照空格拆分，得到：

```python
words = ["Nowcoder", "Hello"]
```

这里 `words` 是一个列表，列表中的每个元素都是一个完整单词。

### 2. 反转单词列表

```python
reversed_words = words[::-1]
```

`[::-1]` 表示倒序。

这里反转的是列表，不是原句子的所有字符。

例如：

```python
["Nowcoder", "Hello"][::-1]
```

得到：

```python
["Hello", "Nowcoder"]
```

### 3. 使用空格连接单词

```python
print(" ".join(reversed_words))
```

`join()` 用于将多个字符串连接起来。

```python
" ".join(reversed_words)
```

开头的引号中有一个空格：

```python
" "
```

表示使用一个空格连接列表中的单词。

例如：

```python
reversed_words = ["Hello", "Nowcoder"]
```

连接后：

```python
"Hello Nowcoder"
```

如果使用的是空字符串：

```python
"".join(reversed_words)
```

结果会变成：

```text
HelloNowcoder
```

中间没有空格，不符合题目要求。因此本题必须使用：

```python
" ".join(...)
```

## 五、示例 1 完整执行过程

输入：

```text
Nowcoder Hello
```

第一步，拆成单词：

```python
["Nowcoder", "Hello"]
```

第二步，反转列表：

```python
["Hello", "Nowcoder"]
```

第三步，用空格连接：

```text
Hello Nowcoder
```

最终输出：

```text
Hello Nowcoder
```

## 六、示例 2 完整执行过程

输入：

```text
A b C d
```

拆分后：

```python
["A", "b", "C", "d"]
```

反转单词顺序：


```text
d C b A
```

## 七、为什么不能直接反转整个字符串

如果对原始字符串直接执行：

```python
s[::-1]
```

会把所有字符都反转，包括单词内部的字母。

例如：

```python
"Nowcoder Hello"[::-1]
```

会得到：

```text
olleH redocwoN
```

这是错误结果，因为 `Hello` 和 `Nowcoder` 内部的字母也被反转了。

正确做法是：

```text
先 split 成完整单词；
再反转单词列表；
最后用空格 join。
```

## 八、只有一个单词的情况

输入：

```text
Hello
```

拆分后：

```python
["Hello"]
```

只有一个元素的列表反转后不变，所以输出：

```text
Hello
```

## 九、使用循环的写法

如果暂时不熟悉列表切片，也可以使用倒序下标循环：

```python
import sys


words = sys.stdin.readline().split()
result = []

for i in range(len(words) - 1, -1, -1):
    result.append(words[i])

print(" ".join(result))
```

假设有四个单词，下标是：

```text
0、1、2、3
```

循环会按下面的顺序取出：

```text
3、2、1、0
```

主答案中的：

```python
words[::-1]
```

就是完成相同工作的简洁写法。

## 十、和 HJ12 的区别

### HJ12 字符串反转

输入：

```text
abcde
```

按照字符反转：

```text
edcba
```

### HJ13 句子逆序

输入：

```text
abc de
```

按照单词反转：

```text
de abc
```

不是：

```text
ed cba
```

## 十一、复杂度

设句子总长度为 `n`：

- 时间复杂度：`O(n)`，需要拆分、反转和连接；
- 空间复杂度：`O(n)`，需要保存单词列表和结果字符串。

## 十二、记忆方式

```text
split() 把句子拆成单词列表；
words[::-1] 反转单词顺序；
" ".join(...) 用空格重新连接；
不要直接反转整个原字符串。
```
