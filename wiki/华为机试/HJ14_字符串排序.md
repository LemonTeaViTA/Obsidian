# HJ14 字符串排序

## 一、答案

```python
import sys


n = int(sys.stdin.readline())
words = []

for _ in range(n):
    word = sys.stdin.readline().strip()
    words.append(word)

sorted_words = sorted(words)

for word in sorted_words:
    print(word)
```

## 二、解题思路

题目输入 `n` 个单词，要求按照字典序从小到大排序，然后每行输出一个单词。

可以分成三步：

1. 使用列表保存所有单词；
2. 使用 `sorted()` 按照字典序排序；
3. 使用循环逐行输出。

例如输入单词：

```text
banana
apple
cat
```

排序后：

```text
apple
banana
cat
```

## 三、什么是字典序

字典序可以理解为查字典时的排列方式，从字符串的第一个字符开始比较。

例如比较：

```text
apple
banana
```

先比较第一个字符：

```text
a < b
```

所以：

```text
apple < banana
```

如果第一个字符相同，就继续比较第二个字符。

例如：

```text
apple
apply
```

前四个字符 `appl` 相同，比较第五个字符：

```text
e < y
```

所以：

```text
apple < apply
```

## 四、Python 为什么可以直接使用 `sorted()`

Python 默认比较字符串时，会从左到右逐个比较字符编码。

题目给出的大小写顺序是：

```text
A < B < ... < Z < a < b < ... < z
```

这正好符合 ASCII 编码顺序：

```text
A 的 ASCII 码是 65
Z 的 ASCII 码是 90
a 的 ASCII 码是 97
z 的 ASCII 码是 122
```

所以：

```python
sorted(words)
```

可以直接得到题目要求的排序结果，不需要自己编写比较规则。

## 五、代码逐行解释

### 1. 读取单词数量

```python
n = int(sys.stdin.readline())
```

第一行输入表示后面有多少个单词。

例如：

```text
3
```

表示接下来还有 `3` 行单词。

### 2. 创建空列表

```python
words = []
```

列表用于按照输入顺序保存所有单词。

本题不能使用集合，因为集合会删除重复单词，而题目没有要求去重。

例如输入中有两个 `apple`，排序以后仍然应该输出两个 `apple`。

### 3. 循环读取单词

```python
for _ in range(n):
    word = sys.stdin.readline().strip()
    words.append(word)
```

循环执行 `n` 次，每次读取一个单词。

```python
words.append(word)
```

将读取到的单词放到列表末尾。

例如依次读到：

```text
banana
apple
cat
```

列表最终是：

```python
words = ["banana", "apple", "cat"]
```

### 4. 对字符串列表排序

```python
sorted_words = sorted(words)
```

`sorted()` 会返回一个新的、排好序的列表。

原列表：

```python
["banana", "apple", "cat"]
```

排序后：

```python
["apple", "banana", "cat"]
```

### 5. 逐行输出

```python
for word in sorted_words:
    print(word)
```

每次从排序后的列表中取出一个单词，并使用 `print()` 输出。

每次调用 `print()` 都会自动换行，所以每个单词占一行。

## 六、大小写排序示例

假设输入单词是：

```text
apple
Banana
Apple
banana
```

因为所有大写字母的 ASCII 码都小于所有小写字母，所以排序结果是：

```text
Apple
Banana
apple
banana
```

不能先调用 `lower()`，因为题目要求按照原字符的 ASCII 码排序。

例如：

```text
A < a
B < b
Z < a
```

## 七、前缀相同时如何排序

如果一个单词是另一个单词的完整前缀，较短的单词排在前面。

例如：

```text
app
apple
```

前面三个字符完全相同，但 `app` 已经结束，所以：

```text
app < apple
```

排序结果为：

```text
app
apple
```

Python 的 `sorted()` 会自动处理这种情况。

## 八、完整示例

输入：

```text
5
banana
apple
cat
app
Apple
```

排序时：

```text
Apple 是大写 A 开头，排在小写字母开头的单词之前；
app 是 apple 的前缀，所以 app 排在 apple 前面；
banana 排在 cat 前面。
```

输出：

```text
Apple
app
apple
banana
cat
```

## 九、`sorted()` 和 `sort()` 的区别

本题也可以写成：

```python
words.sort()
```

二者区别是：

```python
sorted_words = sorted(words)
```

- 返回一个新的排序列表；
- 原来的 `words` 不变。

```python
words.sort()
```

- 直接修改原列表；
- 返回值是 `None`。

因此下面的写法是错误的：

```python
sorted_words = words.sort()
```

因为 `sorted_words` 会得到 `None`。

本题使用 `sorted()`，变量含义更容易看懂。

## 十、为什么不能使用 `set`

假设输入：

```text
3
apple
apple
banana
```

题目要求输出 `n` 行，重复单词也必须保留：

```text
apple
apple
banana
```

如果使用：

```python
set(words)
```

两个 `apple` 会被合并成一个，导致答案错误。

所以：

```text
HJ3 要求去重，可以使用 set；
HJ14 不要求去重，必须使用 list 保存全部单词。
```

## 十一、复杂度

设单词数量为 `n`：

- 排序时间复杂度：`O(n log n)`；
- 保存单词的空间复杂度：`O(n)`。

字符串之间的比较还与单词长度有关，但题目中每个单词最长只有 `100` 个字符，可以使用上述方式理解主要复杂度。

## 十二、记忆方式

```text
list 保存全部单词，重复单词也保留；
sorted(words) 按 ASCII 字典序升序排列；
for + print() 逐行输出；
大写字母排在小写字母前面。
```
