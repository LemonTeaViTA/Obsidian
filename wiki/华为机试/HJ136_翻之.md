# HJ136 翻之

## 一、答案

```python
import sys
from collections import Counter

n, m = map(int, sys.stdin.readline().split())
columns = [0] * m

for _ in range(n):
    row = sys.stdin.readline().strip()
    for j, ch in enumerate(row):
        columns[j] = (columns[j] << 1) | int(ch)

frequency = Counter(columns)
print(max(frequency.values()))
```

## 二、题目翻译成人话

矩阵中只有 `0` 和 `1`。每次可以选择一整行，把这一行全部翻转：`0` 变 `1`，`1` 变 `0`。问最多能让多少列最后全部变成 `1`。

## 三、关键观察

一行翻转两次会恢复原样，所以一行最终只有两种状态：翻转或不翻转。翻转很多次没有额外意义。

假设某列原来是：

```text
0
1
0
```

想把这一列变成全 `1`，就必须：

```text
第1行翻转：0 -> 1
第2行不翻：1 保持 1
第3行翻转：0 -> 1
```

所以，一列想变成全 `1`，会唯一决定每一行要不要翻转。

如果两列原始内容完全相同，它们需要的翻转方案也完全相同，因此可以同时变成全 `1`。

如果两列在某一行不同，例如一列是 `0`，另一列是 `1`，那么这一行无论翻不翻，都不可能让它们同时变成 `1`。

因此答案就是：

```text
统计相同列模式出现的次数，取最大值。
```

## 四、样例理解

样例：

```text
3 2
01
10
11
```

两列分别是：

```text
第1列：011
第2列：101
```

它们的模式不同，所以不能同时变成全 `1`。每种模式只出现 1 次，答案为 `1`。

## 五、代码中的 `columns`

```python
columns = [0] * m
```

`columns[j]` 表示第 `j` 列目前读到的二进制模式。

读取一行时：

```python
for j, ch in enumerate(row):
    columns[j] = (columns[j] << 1) | int(ch)
```

例如某列依次读到 `0、1、1`：

```text
开始：0
读0：0
读1：01（二进制）
读1：011（二进制）
```

二进制 `011` 对应整数 `3`。所以相同的列模式最终会得到相同的整数，不同模式会得到不同整数。

## 六、如果不熟悉位运算

`<< 1` 表示二进制左移一位，`|` 表示按位或。它们只是为了节省内存、提高处理速度。

也可以用更直观的字符串保存列模式：

```python
import sys
from collections import Counter

n, m = map(int, sys.stdin.readline().split())
rows = []

for _ in range(n):
    rows.append(sys.stdin.readline().strip())

patterns = []
for j in range(m):
    pattern = ''
    for i in range(n):
        pattern += rows[i][j]
    patterns.append(pattern)

print(max(Counter(patterns).values()))
```

这个版本的意思是逐列拼出字符串，例如 `011`、`101`，再统计相同字符串的数量。它更容易理解，但会占用更多内存。

## 七、为什么不是统计相同的行

操作对象虽然是“行”，但目标是让“列”全部变成 `1`。一列能否变成全 `1`，取决于它在每一行上的原始 0/1 模式，所以必须比较列，而不是比较行。

## 八、代码逐行解释

```python
n, m = map(int, sys.stdin.readline().split())
```

读取矩阵的行数和列数。

```python
columns = [0] * m
```

给每一列准备一个位置，用来保存该列的模式。

```python
columns[j] = (columns[j] << 1) | int(ch)
```

把当前字符接到这一列模式的末尾。

```python
frequency = Counter(columns)
```

统计每个列模式出现了多少次。

```python
print(max(frequency.values()))
```

取出现次数最大的模式数量，就是最多能同时变成全 `1` 的列数。

## 九、复杂度

设矩阵有 `n` 行、`m` 列：

- 时间复杂度：`O(nm)`；
- 使用整数编码时，额外空间复杂度：`O(m)`。

## 十一、这两行代码到底在做什么

```python
row = sys.stdin.readline().strip()

for j, ch in enumerate(row):
    columns[j] = (columns[j] << 1) | int(ch)
```

它们的任务是：读取当前这一行，把当前行的每一位依次加入对应列的模式中。

## 十二、`row` 表示当前行

```python
row = sys.stdin.readline().strip()
```

`readline()` 读取一行输入。例如当前行是 `01`，读取后原本可能是 `'01\n'`。末尾的 `\n` 是换行符，`strip()` 会把它去掉，所以最终：

```python
row == '01'
```

## 十三、`enumerate(row)` 是什么

```python
for j, ch in enumerate(row):
```

`enumerate` 遍历字符时，同时给出下标和字符。

对于 `row = '01'`，遍历结果是：

```text
第一次：j = 0，ch = '0'
第二次：j = 1，ch = '1'
```

`j` 是列下标，`ch` 是当前格子的字符。`columns[j]` 就是第 `j` 列已经记录的模式。

## 十四、位运算这一句怎么理解

```python
columns[j] = (columns[j] << 1) | int(ch)
```

初学时可以先把它看成：

```python
columns[j] = columns[j] * 2 + int(ch)
```

在这里两种写法效果相同。`<< 1` 表示二进制左移一位，相当于乘以 2；`int(ch)` 把字符 `'0'` 或 `'1'` 转成整数 0 或 1；最后把当前位接到模式末尾。

例如已经记录的是二进制 `01`，当前又读到 `1`：

```text
01 左移一位 -> 010
再加入当前位1 -> 011
```

十进制计算是：`1 × 2 + 1 = 3`，所以整数 `3` 代表二进制模式 `011`。

## 十五、完整运行示例

矩阵：

```text
3行2列
01
10
11
```

开始时：

```python
columns = [0, 0]
```

读取第1行 `01` 后：

```text
第1列：0
第2列：1
columns = [0, 1]
```

读取第2行 `10` 后：

```text
第1列：01，保存为整数1
第2列：10，保存为整数2
columns = [1, 2]
```

读取第3行 `11` 后：

```text
第1列：011，保存为整数3
第2列：101，保存为整数5
columns = [3, 5]
```

最后就等价于保存了两列模式：`011` 和 `101`。

## 十六、不使用位运算的写法

如果暂时不熟悉 `<<` 和 `|`，可以直接保存字符串：

```python
columns = [''] * m

for _ in range(n):
    row = sys.stdin.readline().strip()
    for j, ch in enumerate(row):
        columns[j] += ch
```

上面的例子最后得到 `columns = ['011', '101']`。这个版本更直观；整数写法主要是为了节省保存列模式时的空间。
