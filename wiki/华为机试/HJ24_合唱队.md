# HJ24 合唱队

## 一、答案

```python
import sys
from bisect import bisect_left


n = int(sys.stdin.readline())
heights = list(map(int, sys.stdin.readline().split()))


def get_increasing_lengths(sequence):
    tails = []
    lengths = []

    for height in sequence:
        position = bisect_left(tails, height)

        if position == len(tails):
            tails.append(height)
        else:
            tails[position] = height

        lengths.append(position + 1)

    return lengths


# 以每位同学结尾的最长严格递增子序列长度
left = get_increasing_lengths(heights)

# 将队伍反转后求递增，再反转结果，得到向右严格递减的长度
right = get_increasing_lengths(heights[::-1])[::-1]

maximum_choir = max(
    left[i] + right[i] - 1
    for i in range(n)
)

print(n - maximum_choir)
```

## 二、先把题目翻译成人话

老师只能让一些同学出列，不能交换剩余同学的位置。

最后留下的队伍要像一座山：

```text
越来越高 -> 山顶 -> 越来越矮
```

例如：

```text
150 186 200 160 130
```

满足：

```text
150 < 186 < 200 > 160 > 130
```

“最少出列”可以反过来理解为“最多留下”：

```text
最少出列人数 = 总人数 - 最长合唱队人数
```

## 三、使用的方法

这道题使用“最长递增子序列 + 二分查找”。

我们让每一位同学都尝试当一次山顶，并计算两个数字：

- left[i]：从左边到第 i 位同学，最多能留下多少位严格升高的同学；
- right[i]：从第 i 位同学到右边，最多能留下多少位严格降低的同学。

左右两部分合起来，就是以第 i 位同学为山顶的合唱队。

普通动态规划会让每位同学检查前面的所有同学，时间复杂度是 `O(n²)`。本答案使用 `tails` 数组和二分查找，把每位同学的处理时间降低为 `O(log n)`，总时间复杂度降低为 `O(n log n)`。

## 四、`tails` 数组是什么意思

```python
tails[length - 1]
```

表示：长度为 `length` 的严格递增子序列，目前能够拥有的最小结尾身高。

结尾越小，后面越容易接上更高的同学，因此只保留最小结尾就足够了。

例如依次处理：

```text
150 180 160 200
```

变化过程如下：

| 当前身高 | `tails` | 含义 |
| ---: | --- | --- |
| 150 | `[150]` | 长度 1 的最小结尾是 150 |
| 180 | `[150, 180]` | 可以组成 150、180 |
| 160 | `[150, 160]` | 用 160 替换 180，长度仍是 2，但更容易接后续身高 |
| 200 | `[150, 160, 200]` | 最长递增长度变为 3 |

注意：`tails` 主要用于记录“各个长度的最佳结尾”，不一定是原队伍中某一条真实子序列。

## 五、二分查找如何计算 `left`

```python
position = bisect_left(tails, height)
```

`bisect_left` 会在已经有序的 `tails` 中找到第一个“大于等于当前身高”的位置。

- 如果找不到，说明当前身高比所有结尾都高，可以接在最长递增序列后面；
- 如果找到，就用当前身高替换换掉那个位置，使相同长度的结尾尽量小。

```python
if position == len(tails):
    tails.append(height)
else:
    tails[position] = height
```

当前同学能够接出的递增长度就是：

```python
position + 1
```

所以将它加入 `lengths`：

```python
lengths.append(position + 1)
```

最终：

```python
left = get_increasing_lengths(heights)
```

得到以每个位置结尾的最长严格递增子序列长度。

## 六、`right` 数组怎么计算

`right[i]` 表示从第 `i` 位同学开始，向右最多能留下多少位严格变矮的同学。

把原队伍反转以后，原来的“向右严格递减”就可以转换为“反转后的严格递增”，于是复用同一个函数：

```python
right = get_increasing_lengths(heights[::-1])[::-1]
```

第一个 `[::-1]` 反转身高列表，第二个 `[::-1]` 将计算结果恢复到原来的位置顺序。

## 七、为什么左右相加还要减 1

```python
choir_size = left[i] + right[i] - 1
```

left[i] 包含山顶本人，right[i] 也包含山顶本人。

直接相加会把山顶计算两次，所以必须减 1。

例如：

```text
左边递增：150 180 200，共 3 人
右边递减：200 160 130，共 3 人
```

山顶 200 重复计算，因此总人数是：

```text
3 + 3 - 1 = 5
```

## 八、为什么最后是 n - maximum_choir

```python
print(n - maximum_choir)
```

maximum_choir 是最多能留下的人数，n 是原来总人数。

所以：

```text
需要出列的人数 = 原人数 - 最多留下的人数
```

## 九、官方示例

输入：

```text
8
186 186 150 200 160 130 197 200
```

最长合唱队可以是：

```text
186 200 160 130
```

也可以是：

```text
150 200 160 130
```

最多留下 4 人，原来有 8 人，所以：

```text
8 - 4 = 4
```

输出：

```text
4
```

## 十、严格递增和严格递减

严格递增要求相同身高不能增加序列长度。

`bisect_left(tails, height)` 找到的是第一个大于等于当前身高的位置，因此相同身高会替换原位置，而不会追加到 `tails` 末尾。

例如：

```text
186 186
```

第二个 `186` 只会替换第一个 `186` 的位置，最长递增长度仍是 `1`，符合严格递增要求。

## 十一、复杂度

每位同学通过二分查找在 `tails` 中定位：

- 每次二分查找需要 `O(log n)`；
- 左右各处理 `n` 位同学；
- 总时间复杂度：`O(n log n)`；
- 空间复杂度：`O(n)`。

相比原来的 `O(n²)` 双重循环，这个版本更适合严格的时间限制。

## 十二、记忆方式

```text
出列最少 = 留下最多；
每个人都尝试当山顶；
left 计算左边严格递增人数；
right 计算右边严格递减人数；
tails 保存各长度递增序列的最小结尾；
bisect_left 用 O(log n) 找到当前身高的位置；
山顶重复计算，所以左右相加减 1；
最后用 n 减去最长合唱队人数。
```
