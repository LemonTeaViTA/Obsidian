# HJ42 构造 C

## 一、答案

```python
import sys


a, b = map(int, sys.stdin.readline().split())

# 把 a、b 看作等差数列中相邻的两项
c = 2 * b - a

print(c)
```

## 二、题目翻译成人话

已知两个整数 `a` 和 `b`，再找一个整数 `c`。

把 `a、b、c` 从小到大排序后，要求相邻两项的差相同，也就是成为等差数列。

等差数列的特点是：

```text
后一项 - 前一项 = 固定的公差
```

例如：

```text
1、2、3
```

相邻两项的差都是 `1`，所以它是等差数列。

## 三、为什么可以使用 `c = 2 * b - a`

我们直接把 `a、b` 看成等差数列中前后相邻的两项。

那么公差就是：

```text
d = b - a
```

在 `b` 后面再加一个相同的公差：

```text
c = b + d
```

把 `d = b - a` 代入：

```text
c = b + (b - a)
c = 2 * b - a
```

所以代码是：

```python
c = 2 * b - a
```

## 四、为什么排序后仍然是等差数列

如果 `b > a`，那么：

```text
c = 2b - a > b
```

顺序是：

```text
a、b、c
```

相邻差为：

```text
b - a
c - b = (2b - a) - b = b - a
```

如果 `b < a`，那么：

```text
c = 2b - a < b < a
```

排序后顺序是：

```text
c、b、a
```

相邻差为：

```text
b - c = b - (2b - a) = a - b
a - b = a - b
```

仍然是等差数列。

## 五、示例一

输入：

```text
3 2
```

计算：

```text
c = 2 × 2 - 3 = 1
```

三个数是：

```text
3、2、1
```

排序后：

```text
1、2、3
```

相邻差都是 `1`，符合要求。

## 六、示例二为什么输出 4 也正确

输入仍然是：

```text
3 2
```

也可以把 `a、b` 看作等差数列的后两项。

公差为：

```text
3 - 2 = 1
```

前一项应为：

```text
c = 2 - 1 = 1
```

或者把 `2、3` 看成前两项，下一项是 `4`：

```text
2、3、4
```

所以输出 `1` 或 `4` 都可以，题目明确允许多个答案中的任意一个。

## 七、另一种也正确的写法

也可以把 `a、b` 看作等差数列的后两项，得到前一项：

```python
c = 2 * a - b
```

例如：

```text
a = 3，b = 2
c = 2 × 3 - 2 = 4
```

排序后是：

```text
2、3、4
```

同样满足要求。

## 八、输入代码是什么意思

```python
a, b = map(int, sys.stdin.readline().split())
```

假设输入：

```text
3 2
```

处理过程是：

```python
sys.stdin.readline().split()
```

得到字符串列表：

```python
['3', '2']
```

`map(int, ...)` 把它们转换成整数，最后分别赋给 `a` 和 `b`。

## 九、复杂度

只进行一次公式计算：

- 时间复杂度：`O(1)`；
- 空间复杂度：`O(1)`。
