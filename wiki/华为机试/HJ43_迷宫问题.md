# HJ43 迷宫问题

## 一、答案

```python
import sys


h, w = map(int, sys.stdin.readline().split())
maze = []

for _ in range(h):
    maze.append(list(map(int, sys.stdin.readline().split())))

visited = [[False] * w for _ in range(h)]
path = []

# 上、下、左、右四个方向
directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]


def dfs(row, col):
    # 越界、撞墙、或者走过的格子都不能走
    if row < 0 or row >= h or col < 0 or col >= w:
        return False
    if maze[row][col] == 1 or visited[row][col]:
        return False

    visited[row][col] = True
    path.append((row, col))

    # 到达终点
    if row == h - 1 and col == w - 1:
        return True

    # 尝试四个方向
    for dr, dc in directions:
        if dfs(row + dr, col + dc):
            return True

    # 四个方向都走不通，撤销当前格子
    path.pop()
    return False


dfs(0, 0)

for row, col in path:
    print(f'({row},{col})')
```

## 二、题目翻译成人话

给你一个由 `0` 和 `1` 组成的网格：

```text
0 表示可以走
1 表示墙，不能走
```

从左上角 `(0, 0)` 出发，走到右下角 `(h - 1, w - 1)`。每次只能向上、下、左、右移动一格。

题目保证一定存在且只有一条可行路径，所以找到路径后直接输出即可。

## 三、使用的方法：深度优先搜索 DFS

DFS 可以理解成：

```text
沿着一个方向一直走
走不通就退回来
再尝试另一个方向
```

站在一个格子上时，程序依次尝试上、下、左、右四个方向。如果某个方向能到达终点，就保留这条路；如果四个方向都走不通，就退回上一个格子。

## 四、读取迷宫

```python
h, w = map(int, sys.stdin.readline().split())
```

读取迷宫的行数和列数。

```python
maze = []

for _ in range(h):
    maze.append(list(map(int, sys.stdin.readline().split())))
```

逐行读取迷宫。例如：

```text
0 1 0
0 0 0
```

会保存为：

```python
[[0, 1, 0], [0, 0, 0]]
```

## 五、`visited` 的作用

```python
visited = [[False] * w for _ in range(h)]
```

`visited[row][col]` 表示一个格子是否已经走过。

如果不记录已经走过的格子，遇到环路时可能出现：

```text
A → B → C → A → B → C → …
```

程序可能一直绕圈。进入一个格子后，立即标记：

```python
visited[row][col] = True
```

## 六、`path` 的作用

```python
path = []
```

`path` 保存当前正在尝试的路径。

进入格子时：

```python
path.append((row, col))
```

如果后面走不通，就删除最后一个格子：

```python
path.pop()
```

这就是回溯：

```text
走不通 → 撤销最后一步 → 换一条路
```

## 七、`dfs` 函数的处理顺序

```python
def dfs(row, col):
```

表示尝试从 `(row, col)` 继续走到终点。

### 1. 越界

```python
if row < 0 or row >= h or col < 0 or col >= w:
    return False
```

行号或列号超出网格范围，不能走。

### 2. 撞墙或走过

```python
if maze[row][col] == 1 or visited[row][col]:
    return False
```

遇到墙，或者已经走过，也不能走。

### 3. 进入当前格子

```python
visited[row][col] = True
path.append((row, col))
```

标记当前格子，并把它加入路径。

### 4. 到达终点

```python
if row == h - 1 and col == w - 1:
    return True
```

返回 `True`，表示已经找到完整路径。

## 八、为什么要尝试四个方向

方向列表是：

```python
directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
```

每个方向由 `(行变化量, 列变化量)` 表示：

| 方向 | `dr` | `dc` | 新坐标 |
| --- | ---: | ---: | --- |
| 上 | -1 | 0 | `(row - 1, col)` |
| 下 | 1 | 0 | `(row + 1, col)` |
| 左 | 0 | -1 | `(row, col - 1)` |
| 右 | 0 | 1 | `(row, col + 1)` |

代码：

```python
for dr, dc in directions:
    if dfs(row + dr, col + dc):
        return True
```

如果某个方向找到终点，就立即返回 `True`，让上一层调用也返回 `True`。

## 九、为什么走不通时要 `path.pop()`

假设当前路径是：

```text
(0,0) → (1,0) → (1,1)
```

如果从 `(1,1)` 出发四个方向都走不通，它就不属于最终路径，需要删除：

```text
(0,0) → (1,0)
```

然后让上一个格子继续尝试其他方向。

对应代码：

```python
path.pop()
return False
```

## 十、为什么找到终点后不继续搜索

找到终点后：

```python
if row == h - 1 and col == w - 1:
    return True
```

此时 `path` 已经保存了从起点到终点的完整路径。返回 `True` 会让所有上一层调用一起返回，最终保留这条路径。

题目保证路径唯一，所以不需要继续寻找其他路径。

## 十一、输出格式

```python
for row, col in path:
    print(f'({row},{col})')
```

`f'({row},{col})'` 是格式化字符串。例如 `row = 2`、`col = 4` 时，输出：

```text
(2,4)
```

题目坐标从 `0` 开始，代码不需要把坐标加一。

## 十二、示例路径理解

示例一输出：

```text
(0,0)
(1,0)
(2,0)
(2,1)
(2,2)
(2,3)
(2,4)
(3,4)
(4,4)
```

相邻坐标每次只变化一个方向的一格，所有经过的格子都是 `0`，最后到达 `(4,4)`。

## 十三、复杂度

每个格子最多访问一次：

- 时间复杂度：`O(h × w)`；
- 空间复杂度：`O(h × w)`，用于迷宫、访问标记和路径。

题目中 `h、w <= 100`，最多只有 10000 个格子，完全可以通过。

## 十四、记忆方式

```text
DFS：走进去，标记，尝试四个方向
走不通：path.pop() 回退
走到终点：返回 True
最后输出 path
```
