# HJ84 统计大写字母个数

## 一、答案

~~~python
import sys


s = sys.stdin.readline().rstrip('\n')

count = 0

for ch in s:
    if ch.isupper():
        count += 1

print(count)
~~~

## 二、题目翻译成人话

输入一整行字符串，里面可能有：

```text
大写字母、小写字母、数字、符号、空格
```

只统计大写字母有多少个。

例如：

~~~text
A 1 b ! O
~~~

大写字母是 `A` 和 `O`，所以答案是 `2`。

## 三、为什么要读取整行

代码使用：

~~~python
s = sys.stdin.readline().rstrip('\n')
~~~

因为输入中包含空格，必须保留空格并逐个检查。

不能使用：

~~~python
s = sys.stdin.readline().split()
~~~

因为 `split()` 会按照空格拆分，并丢掉空格。

`rstrip('\n')` 只删除输入行末的换行符，不删除普通空格。

## 四、`isupper()` 是什么

~~~python
ch.isupper()
~~~

用于判断当前字符是不是大写字母。

例如：

~~~python
'A'.isupper()  # True
'Z'.isupper()  # True
'a'.isupper()  # False
'1'.isupper()  # False
'!'.isupper()  # False
' '.isupper()  # False
~~~

## 五、逐个字符统计

~~~python
count = 0

for ch in s:
    if ch.isupper():
        count += 1
~~~

开始时还没有检查字符，所以计数器为 `0`。

每遇到一个大写字母就加一：

~~~python
count += 1
~~~

这等价于：

~~~python
count = count + 1
~~~

## 六、手算示例

输入：

~~~text
A 1 0 1 1150175017(&^%&$vabovbaoadd 123#$%#%#O
~~~

其中只有两个大写字母：

~~~text
A 和 O
~~~

其它数字、小写字母、符号和空格都不计数，所以输出：

~~~text
2
~~~

## 七、为什么不需要自己判断 ASCII 范围

当然可以通过 ASCII 范围判断大写字母：

~~~python
if 'A' <= ch <= 'Z':
    count += 1
~~~

但 Python 的：

~~~python
ch.isupper()
~~~

已经直接表达了“是不是大写字母”，代码更容易理解。

## 八、不要把 `isupper` 写成 `isupper()`

正确调用方法：

~~~python
ch.isupper()
~~~

括号 `()` 表示真正执行判断。

如果写成：

~~~python
ch.isupper
~~~

得到的是方法本身，不是判断结果。

## 九、复杂度

字符串长度为 `n`：

- 每个字符只检查一次；
- 时间复杂度：`O(n)`；
- 额外空间复杂度：`O(1)`。

## 十、记忆方式

遍历每个字符
isupper() 判断大写
是大写就 count += 1
最后输出 count
~~~
