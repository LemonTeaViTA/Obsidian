# HJ156 走迷宫

## 一、答案

~~~python
import sys
from collections import deque


def bfs(n, m, start_row, start_col, target_row, target_col, grid):
    start = start_row * m + start_col
    target = target_row * m + target_col

    # bytearray 中的 0 表示没走过，1 表示走过
    visited = bytearray(n * m)
    visited[start] = 1

    # 队列中保存格子的编号，而不是保存二元组，节省一些空间
    queue = deque([start])
    directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
    steps = 0

    while queue:
        # 当前这一轮队列中的格子，距离起点都为 steps
        for _ in range(len(queue)):
            position = queue.popleft()

            if position == target:
                return steps

            row, col = divmod(position, m)

            for dr, dc in directions:
                next_row = row + dr
                next_col = col + dc

                if not (0 <= next_row < n and 0 <= next_col < m):
                    continue

                next_position = next_row * m + next_col

                if grid[next_row][next_col] == ord('*'):
                    continue
                if visited[next_position]:
                    continue

                visited[next_position] = 1
                queue.append(next_position)

        # 当前层全部检查完，下一层距离多 1 步
        steps += 1

    return -1


n, m = map(int, sys.stdin.buffer.readline().split())
xs, ys, xt, yt = map(int, sys.stdin.buffer.readline().split())

# 题目坐标从 1 开始，Python 下标从 0 开始
xs -= 1
ys -= 1
xt -= 1
yt -= 1

grid = [sys.stdin.buffer.readline().strip() for _ in range(n)]

print(bfs(n, m, xs, ys, xt, yt, grid))
~~~

## 二、题目翻译成人话

给你一个网格迷宫：

~~~text
. 表示可以走
* 表示障碍物，不能走
~~~

你从起点出发，每次可以向上、下、左、右移动一格，要求到达终点的最少步数。

如果完全走不到终点，输出 -1。

这道题和 HJ148 的区别是：

~~~text
HJ148：只问能不能到达，输出 Yes 或 No
HJ156：还要问最少走多少步
~~~

## 三、为什么用 BFS

BFS 是广度优先搜索，可以理解成从起点向四周一层一层扩散：

~~~text
第 0 层：起点，走 0 步
第 1 层：起点相邻的格子，走 1 步
第 2 层：再往外一层，走 2 步
……
~~~

因为每次移动的代价都相同，都是 1 步，所以终点第一次被取出时，走的步数一定最少。

如果使用 DFS，可能先找到一条很长的路，之后还要继续比较其它路线，不如 BFS 直接按步数搜索。

## 四、队列保存什么

~~~python
queue = deque([start])
~~~

队列中保存还没有检查的格子。

例如起点是 `(0, 0)`，可以先保存坐标；为了减少大网格下的内存占用，答案代码把坐标编码成一个数字：

~~~python
position = row * m + col
~~~

例如有 5 列时：

~~~text
(0, 0) → 0
(0, 1) → 1
(1, 0) → 5
(2, 3) → 13
~~~

取出编号后，用 `divmod` 还原坐标：

~~~python
row, col = divmod(position, m)
~~~

它等价于：

~~~python
row = position // m
col = position % m
~~~

## 五、为什么要按层统计 steps

代码中：

~~~python
steps = 0
while queue:
    for _ in range(len(queue)):
        position = queue.popleft()
    steps += 1
~~~

在每次 `while` 开始时，队列中当前这一层的格子距离起点都相同。

例如：

~~~text
第 0 层：距离起点 0 步
第 1 层：距离起点 1 步
第 2 层：距离起点 2 步
~~~

`range(len(queue))` 会把当前层原本的格子全部处理完。处理这些格子时新加入队列的格子属于下一层，因此这一轮结束后：

~~~python
steps += 1
~~~

步数加一。

## 六、起点和终点的坐标转换

题目中的坐标从 1 开始，例如左上角是：

~~~text
(1, 1)
~~~

Python 列表下标从 0 开始，所以必须减一：

~~~python
xs -= 1
ys -= 1
xt -= 1
yt -= 1
~~~

题目中的 `(1, 1)` 就会变成 Python 中的 `(0, 0)`。

## 七、`visited` 的作用

~~~python
visited = bytearray(n * m)
visited[start] = 1
~~~

它记录每个格子是否已经加入过搜索。

如果一个格子没有访问过：

~~~python
if visited[next_position]:
    continue
~~~

就跳过它；否则标记并加入队列：

~~~python
visited[next_position] = 1
queue.append(next_position)
~~~

标记时机要放在加入队列的时候，而不是取出时。这样同一个格子不会被多个相邻格子重复加入。

## 八、如何判断下一格能不能走

当前坐标是 `(row, col)`，四个方向是：

| 方向 | 行变化 | 列变化 |
| --- | ---: | ---: |
| 上 | -1 | 0 |
| 下 | 1 | 0 |
| 左 | 0 | -1 |
| 右 | 0 | 1 |

计算新坐标：

~~~python
next_row = row + dr
next_col = col + dc
~~~

新格子必须满足：

1. 行列没有越界；
2. 不是 `*` 障碍物；
3. 没有访问过。

## 九、到达终点时为什么直接返回

~~~python
if position == target:
    return steps
~~~

BFS 是按距离从小到大处理的。

因此第一次取到终点时，当前的 `steps` 就是最少步数，不需要再搜索其它路线。

如果队列全部检查完仍然没有取到终点：

~~~python
return -1
~~~

表示无法到达。

## 十、官方示例怎么理解

示例一从 `(1,1)` 出发，终点是 `(5,5)`。转换成 Python 坐标后是：

~~~text
起点：(0,0)
终点：(4,4)
~~~

BFS 会逐层扩散，找到终点时的层数是 `12`，所以输出：

~~~text
12
~~~

示例二和示例三中，障碍物把起点和终点隔开。队列最终为空，终点没有被搜索到，因此输出：

~~~text
-1
~~~

## 十一、为什么使用 `bytearray`

~~~python
visited = bytearray(n * m)
~~~

`n、m` 最大为 `1000`，最多有一百万个格子。

普通二维布尔列表也能表达访问状态，但会有较多 Python 对象和列表开销。`bytearray` 用一个字节保存一个格子的状态，适合这种大网格。

如果你正在学习算法，也可以先把它理解成：

~~~python
visited = [[False] * m for _ in range(n)]
~~~

它们的逻辑完全相同，只是答案代码的存储方式更省内存。

## 十二、复杂度

每个格子最多进入队列一次，每次最多检查四个方向：

- 时间复杂度：O(n × m)
- 空间复杂度：O(n × m)

## 十三、记忆方式

~~~text
最短步数 + 每步代价相同 → BFS
起点入队并标记
取出当前层的格子
尝试上下左右
合法且没访问过就入队
第一次到终点返回步数
队列空了还没到，返回 -1
~~~
