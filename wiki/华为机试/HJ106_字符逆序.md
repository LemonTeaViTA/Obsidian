# HJ106 字符逆序

## 一、答案

~~~python
import sys


s = sys.stdin.readline().rstrip('\n')

# [::-1] 表示从后往前取出整个字符串
print(s[::-1])
~~~

## 二、题目翻译成人话

输入一个由小写字母和空格组成的字符串，把整个字符串前后颠倒后输出。

例如：

~~~text
输入：hello nowcoder
输出：redocwon olleh
~~~

这里是“整个字符串”反转，空格也会跟着一起移动。

## 三、`s[::-1]` 是什么意思

Python 字符串切片的完整形式是：

~~~python
s[开始位置:结束位置:步长]
~~~

当省略开始位置和结束位置，步长写成 `-1` 时：

~~~python
s[::-1]
~~~

意思是：

~~~text
从字符串最后一个字符开始，倒着一个一个取，直到第一个字符
~~~

## 四、用下标理解

假设：

~~~python
s = 'abcde'
~~~

每个字符的下标是：

~~~text
字符：a  b  c  d  e
下标：0  1  2  3  4
~~~

执行：

~~~python
s[::-1]
~~~

会按照下标顺序：

~~~text
4 → 3 → 2 → 1 → 0
~~~

所以结果是：

~~~text
edcba
~~~

## 五、为什么空格也会反转

假设：

~~~text
hello nowcoder
~~~

它的字符整体倒过来后是：

~~~text
redocwon olleh
~~~

原来的空格在中间，反转后仍然位于相应的倒序位置。

题目要求的是字符整体反转，因此不能先用 `split()` 把单词拆开。

## 六、和 HJ31 单词倒排的区别

这两题很容易混淆：

| 题目 | 反转对象 | 示例结果 |
| --- | --- | --- |
| HJ106 字符逆序 | 每一个字符，包括空格 | `hello nowcoder` → `redocwon olleh` |
| HJ31 单词倒排 | 只反转单词顺序，单词内部不变 | `Nowcoder Hello` → `Hello Nowcoder` |

HJ106 可以直接写：

~~~python
print(s[::-1])
~~~

HJ31 则需要先分割单词，再反转单词列表：

~~~python
print(' '.join(words[::-1]))
~~~

两者的 `[::-1]` 作用对象不同：

~~~text
s[::-1]：反转字符
words[::-1]：反转单词列表
~~~

## 七、为什么使用 `rstrip('\n')`

~~~python
s = sys.stdin.readline().rstrip('\n')
~~~

`readline()` 读取一整行时，通常会把行末换行符 `\n` 一起读进来。

这里使用 `rstrip('\n')` 删除这个换行符，避免换行符也参与反转。

不能使用 `split()`，因为 `split()` 会去掉空格，而空格是字符串的一部分，需要参与反转。

本题保证字符串首尾没有空格，所以使用 `strip()` 也通常能通过，但 `rstrip('\n')` 更准确地保留原字符串。

## 八、也可以使用 `reversed`

另一种写法是：

~~~python
print(''.join(reversed(s)))
~~~

`reversed(s)` 会从后往前依次产生字符，`join` 再把它们连接起来。

不过 `s[::-1]` 更短，也更适合本题。

## 九、复杂度

字符串长度为 `n` 时：

- 每个字符只处理一次；
- 时间复杂度：`O(n)`；
- 反转结果需要 `O(n)` 空间。

## 十、记忆方式

~~~text
整句话按字符反转：s[::-1]
空格也要一起反转
不要 split
~~~
