# HJ29 字符串加解密

## 一、答案

```python
import sys


lowercase = 'abcdefghijklmnopqrstuvwxyz'
uppercase = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ'


def encrypt(text):
    answer = []

    for ch in text:
        if ch.islower():
            position = lowercase.index(ch)
            answer.append(uppercase[(position + 1) % 26])
        elif ch.isupper():
            position = uppercase.index(ch)
            answer.append(lowercase[(position + 1) % 26])
        else:
            answer.append(str((int(ch) + 1) % 10))

    return ''.join(answer)


def decrypt(text):
    answer = []

    for ch in text:
        if ch.islower():
            position = lowercase.index(ch)
            answer.append(uppercase[(position - 1) % 26])
        elif ch.isupper():
            position = uppercase.index(ch)
            answer.append(lowercase[(position - 1) % 26])
        else:
            answer.append(str((int(ch) - 1) % 10))

    return ''.join(answer)


s = sys.stdin.readline().strip()
t = sys.stdin.readline().strip()

print(encrypt(s))
print(decrypt(t))
```

## 二、题目翻译成人话

输入两个字符串：

- 第一行是明文，需要加密；
- 第二行是密文，需要解密。

每次只处理一个字符。

### 加密规则

```text
小写字母 → 向后移动一位 → 变成大写
大写字母 → 向后移动一位 → 变成小写
数字     → 加 1
```

例如：

```text
a → B
b → C
A → b
B → c
1 → 2
```

到达末尾时需要回到开头：

```text
z → A
Z → a
9 → 0
```

### 解密规则

解密是加密的相反过程：

```text
小写字母 → 向前移动一位 → 变成大写
大写字母 → 向前移动一位 → 变成小写
数字     → 减 1
```

例如：

```text
B → a
C → b
b → A
c → B
2 → 1
```

到达开头时需要回到末尾：

```text
A → z
a → Z
0 → 9
```

## 三、为什么定义两个字母表

```python
lowercase = 'abcdefghijklmnopqrstuvwxyz'
uppercase = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ'
```

两个字符串相同下标上的字母，只是大小写不同：

```text
下标       0  1  2  3       25
lowercase  a  b  c  d  ...  z
uppercase  A  B  C  D  ...  Z
```

可以先找到字符的位置，再加一或减一。

例如：

```python
position = lowercase.index('b')
```

得到：

```python
position = 1
```

`b` 加密后需要向后走一位，并变成大写：

```python
uppercase[position + 1]
```

也就是：

```python
uppercase[2]  # 'C'
```

所以：

```text
b → C
```

## 四、加密函数逐行解释

```python
def encrypt(text):
```

定义一个加密函数，`text` 是需要加密的字符串。

```python
answer = []
```

创建一个空列表，用来保存每个加密后的字符。

```python
for ch in text:
```

依次处理字符串中的每个字符。

### 当前字符是小写字母

```python
if ch.islower():
    position = lowercase.index(ch)
    answer.append(uppercase[(position + 1) % 26])
```

先找到它在小写字母表中的位置，然后向后移动一位，再从大写字母表中取出字符。

### 当前字符是大写字母

```python
elif ch.isupper():
    position = uppercase.index(ch)
    answer.append(lowercase[(position + 1) % 26])
```

先找到它在大写字母表中的位置，然后向后移动一位，再从小写字母表中取出字符。

### 当前字符是数字

```python
else:
    answer.append(str((int(ch) + 1) % 10))
```

题目保证字符串只包含字母和数字。前面已经排除了大小写字母，所以这里一定是数字。

先使用 `int(ch)` 把字符数字转换为整数，加一以后，再使用 `str()` 转回字符。

最后：

```python
return ''.join(answer)
```

把字符列表连接成完整字符串并返回。

## 五、`% 26` 是什么意思

字母表一共有 26 个字母，有效下标为：

```text
0 到 25
```

当字符是 `z` 时：

```python
position = 25
position + 1 = 26
```

但是字母表中没有下标 `26`，所以需要：

```python
(position + 1) % 26
```

计算结果为：

```python
26 % 26 == 0
```

于是重新回到下标 `0`，得到 `A`：

```text
z → A
```

同理，数字一共有 10 个，因此使用 `% 10`：

```python
(9 + 1) % 10 == 0
```

所以：

```text
9 → 0
```

## 六、为什么减一也能使用 `% 26`

解密 `A` 时，需要回到小写字母 `z`：

```python
position = 0
(position - 1) % 26
```

在 Python 中：

```python
-1 % 26 == 25
```

下标 `25` 对应字母 `z`，所以：

```text
A → z
```

数字同理：

```python
(0 - 1) % 10 == 9
```

所以：

```text
0 → 9
```

## 七、解密时为什么大小写看起来是反的

加密时：

```text
小写 a → 大写 B
大写 A → 小写 b
```

因此解密时必须反过来：

```text
大写 B → 小写 a
小写 b → 大写 A
```

所以解密函数中：

- 遇到小写密文，要从大写字母表中取出前一个字母；
- 遇到大写密文，要从小写字母表中取出前一个字母。

## 八、官方示例手算

明文：

```text
abcdefg1
```

逐个字符加密：

```text
a b c d e f g 1
B C D E F G H 2
```

得到：

```text
BCDEFGH2
```

密文：

```text
0BCDEFGH
```

逐个字符解密：

```text
0 B C D E F G H
9 a b c d e f g
```

得到：

```text
9abcdefg
```

## 九、复杂度

设两个字符串的总长度为 `n`：

- 每个字符只处理一次；
- 时间复杂度可以看作 `O(n)`；
- 保存结果需要 `O(n)` 空间。

题目中每个字符串最长为 1000，这个方法完全满足要求。

## 十、记忆方式

```text
加密：字母向后、大小写互换、数字加一
解密：字母向前、大小写互换、数字减一
越过末尾或开头时，用取余数回到另一端
```
