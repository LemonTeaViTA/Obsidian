# HJ34 图片整理

## 一、答案

```python
import sys


s = sys.stdin.readline().strip()

characters = sorted(s)

print(''.join(characters))
```

也可以合并成一句：

```python
import sys


s = sys.stdin.readline().strip()
print(''.join(sorted(s)))
```

## 二、题目翻译成人话

输入一个只包含以下字符的字符串：

```text
数字 0～9
大写字母 A～Z
小写字母 a～z
```

需要根据每个字符的 ASCII 码从小到大排序，再把排序结果输出。

常用字符的 ASCII 码顺序是：

```text
0～9：48～57
A～Z：65～90
a～z：97～122
```

所以整体顺序是：

```text
数字 < 大写字母 < 小写字母
```

例如：

```text
b2A1aB
```

排序后是：

```text
12ABab
```

## 三、`sorted(s)` 是什么意思

```python
characters = sorted(s)
```

`sorted()` 会把字符串中的字符从小到大排序。

对于英文字母和数字，Python 默认使用字符编码的顺序进行比较，正好符合题目要求。

例如：

```python
sorted('b2A1aB')
```

得到的不是字符串，而是一个字符列表：

```python
['1', '2', 'A', 'B', 'a', 'b']
```

## 四、为什么还要使用 `join`

题目要求输出一个字符串，但 `sorted()` 返回的是列表：

```python
['1', '2', 'A', 'B', 'a', 'b']
```

因此使用：

```python
''.join(characters)
```

`''` 表示字符之间不添加任何内容，连接后得到：

```text
12ABab
```

如果直接输出：

```python
print(sorted(s))
```

会得到类似：

```text
['1', '2', 'A', 'B', 'a', 'b']
```

其中包含方括号、引号和逗号，不是题目要求的格式。

## 五、手算示例

输入：

```text
Ihave1nose2hands10fingers
```

先按照 ASCII 码排序：

1. 数字排在最前面：`0112`；
2. 大写字母排在数字后面：`I`；
3. 小写字母继续按照 `a～z` 排序。

最终得到：

```text
0112Iaadeeefghhinnnorsssv
```

## 六、`sort()` 和 `sorted()` 的区别

字符串不能直接调用：

```python
s.sort()
```

这会报错，因为字符串没有 `sort()` 方法。

可以使用：

```python
sorted(s)
```

它接收字符串并返回一个新的列表。

如果原本就是列表，则两种方式都可能使用：

```python
numbers = [3, 1, 2]

new_numbers = sorted(numbers)  # 返回一个新列表
numbers.sort()                 # 直接修改原列表
```

这道题输入的是字符串，所以直接使用 `sorted(s)` 最方便。

## 七、需要自己使用 `ord()` 吗

不需要。

`ord()` 可以查看字符的编码值：

```python
ord('0')  # 48
ord('A')  # 65
ord('a')  # 97
```

但是 Python 的 `sorted()` 已经会按照字符编码顺序排序，因此不用自己逐个调用 `ord()`。

## 八、复杂度

设字符串长度为 `n`：

- 排序的时间复杂度是 `O(n log n)`；
- 字符列表和输出字符串需要 `O(n)` 空间。

本题字符串长度不超过 `1000`，完全满足要求。

## 九、记忆方式

```text
sorted(s)        字符排序，得到列表
''.join(...)     把字符列表重新连接成字符串
```

最终记住这一句即可：

```python
print(''.join(sorted(s)))
```
