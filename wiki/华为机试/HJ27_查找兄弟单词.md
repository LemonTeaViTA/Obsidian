# HJ27 查找兄弟单词

## 一、答案

```python
import sys


data = sys.stdin.read().split()

n = int(data[0])
words = data[1:n + 1]
x = data[n + 1]
k = int(data[n + 2])

# x 排序后的结果，用来判断两个单词的字母是否完全相同
x_sorted = ''.join(sorted(x))

brothers = []

for word in words:
    # 单词不能与 x 完全相同，但排序后必须与 x 相同
    if word != x and ''.join(sorted(word)) == x_sorted:
        brothers.append(word)

# 按字典序从小到大排序
brothers.sort()

# 第一行输出兄弟单词的数量
print(len(brothers))

# 如果存在第 k 个兄弟单词，才输出第二行
if k <= len(brothers):
    print(brothers[k - 1])
```

## 二、题目翻译成人话

假设要查找的单词是：

```text
abc
```

把 `abc` 的三个字母重新排列，可以得到：

```text
acb、bac、bca、cab、cba
```

这些都是 `abc` 的兄弟单词。

但是 `abc` 自己不是自己的兄弟单词，因为题目要求重新排列后得到的字符串必须与原字符串不同。

因此，判断 `word` 是不是 `x` 的兄弟单词，需要同时满足两个条件：

```text
1. word != x
2. word 和 x 包含完全相同的字母，而且每个字母的数量也相同
```

## 三、如何判断字母和数量完全相同

可以分别把两个单词中的字母排序。

例如：

```python
''.join(sorted('abc'))   # 'abc'
''.join(sorted('bca'))   # 'abc'
''.join(sorted('cab'))   # 'abc'
```

它们排序后的结果完全相同，说明它们拥有相同的字母和相同的字母数量。

再看一个不是兄弟单词的例子：

```python
''.join(sorted('abb'))   # 'abb'
''.join(sorted('abc'))   # 'abc'
```

排序后的结果不同，所以 `abb` 不是 `abc` 的兄弟单词。

## 四、输入代码是什么意思

题目的全部内容都在一行，可以一次性读入并按空白分开：

```python
data = sys.stdin.read().split()
```

对于示例输入：

```text
3 abc bca cab abc 1
```

`data` 是：

```python
['3', 'abc', 'bca', 'cab', 'abc', '1']
```

然后分别取出每部分：

```python
n = int(data[0])
```

`n` 是 `3`，代表接下来有三个待检查的单词。

```python
words = data[1:n + 1]
```

取下标 `1` 到下标 `n` 的内容：

```python
words = ['abc', 'bca', 'cab']
```

接下来是目标单词：

```python
x = data[n + 1]
```

得到：

```python
x = 'abc'
```

最后一个是要查找的名次：

```python
k = int(data[n + 2])
```

得到：

```python
k = 1
```

## 五、查找兄弟单词

先把目标单词 `x` 排序：

```python
x_sorted = ''.join(sorted(x))
```

再检查给出的每一个单词：

```python
for word in words:
    if word != x and ''.join(sorted(word)) == x_sorted:
        brothers.append(word)
```

这里有两个判断条件：

### 条件一

```python
word != x
```

候选单词不能和 `x` 完全相同。

例如 `word` 和 `x` 都是 `abc` 时，它不是兄弟单词。

### 条件二

```python
''.join(sorted(word)) == x_sorted
```

候选单词与 `x` 排序后的结果必须相同，说明它们包含的字母及每个字母的数量完全相同。

只有两个条件同时成立，才把它放进列表：

```python
brothers.append(word)
```

## 六、为什么不能使用 `set`

题目说明重复出现的兄弟单词需要分别计数。

例如输入的单词是：

```text
bca bca cab
```

这三个单词都需要计数，结果是 `3`。

如果使用 `set` 去重：

```python
{'bca', 'cab'}
```

就只剩两个单词了，不符合题意。因此答案使用列表 `brothers`，保留所有重复项。

## 七、排序和输出第 k 个

```python
brothers.sort()
```

将所有找到的兄弟单词按照字典序从小到大排序。

先输出总数：

```python
print(len(brothers))
```

如果兄弟单词的数量不少于 `k`，再输出第 `k` 个：

```python
if k <= len(brothers):
    print(brothers[k - 1])
```

题目中的名次从 `1` 开始，但 Python 列表下标从 `0` 开始，所以：

```text
题目第 1 个 → Python 下标 0
题目第 2 个 → Python 下标 1
题目第 k 个 → Python 下标 k - 1
```

如果不存在第 `k` 个，只输出数量，不能输出第二行。

## 八、手算示例一

输入：

```text
3 abc bca cab abc 1
```

目标单词是：

```text
x = abc
```

依次检查：

| 单词 | 与 `x` 相同吗 | 排序后的结果 | 是兄弟单词吗 |
| --- | --- | --- | --- |
| `abc` | 相同 | `abc` | 不是，不能是自己 |
| `bca` | 不同 | `abc` | 是 |
| `cab` | 不同 | `abc` | 是 |

所以：

```python
brothers = ['bca', 'cab']
```

兄弟单词一共有 `2` 个，字典序第 `1` 个是 `bca`，因此输出：

```text
2
bca
```

## 九、手算示例二

输入：

```text
3 a aa aaa a 1
```

- `a` 与目标单词完全相同，不算兄弟单词；
- `aa` 和 `aaa` 的字母数量与 `a` 不同，也不是兄弟单词。

兄弟单词数量为 `0`，不存在第一个兄弟单词，所以只输出：

```text
0
```

## 十、复杂度

设单词数量是 `n`，每个单词的最大长度是 `L`：

- 给每个单词的字母排序大约需要 `O(L log L)`；
- 检查全部单词需要 `O(nL log L)`；
- 最后给兄弟单词排序最多需要 `O(n log n)`。

题目中 `n <= 1000`、`L <= 10`，这套方法完全满足要求。

## 十一、记忆方式

```text
自己不能算兄弟
字母排序后必须相同
兄弟单词不能去重
排完字典序再取第 k - 1 个
```
