# HJ109 最小循环节

## 一、答案

```python
import sys

s = sys.stdin.readline().strip()

# 插入字符不会删除原字符，因此原字符串中的不同字符都必须出现在新字符串中。
# 最小循环节的长度就是不同字符的数量。
print(len(set(s)))
```

## 二、题目翻译成人话

可以在原字符串的任意位置插入任意字符，但不能删除或改变原来字符的先后顺序。

插入完成后，希望新字符串可以写成某个短字符串重复多次：

```text
新字符串 = a + a + a + ...
```

要求这个短字符串 `a` 尽可能短，输出它的长度。

## 三、这题的关键结论

答案是：

```text
原字符串中不同字符的数量
```

例如：

```text
s = abcabcD
```

不同字符是：

```text
a、b、c、D
```

一共有 4 种，所以答案是 4。

可以插入一个 `D`，把它变成：

```text
abcDabcD
```

它由 `abcD` 重复两次组成，循环节长度就是 4。

## 四、为什么答案不能更小

假设原字符串中有 `d` 种不同字符。

因为只能插入字符，不能删除原来的字符，所以新字符串中仍然必须包含这 `d` 种字符。

如果循环节长度是 `L`，那么一个循环节最多只有 `L` 个位置，也就最多包含 `L` 种不同字符。因此必须满足：

```text
L >= d
```

也就是说，循环节长度不可能小于原字符串的不同字符数量。

例如：

```text
s = abca
```

有 `a、b、c` 三种不同字符，所以循环节不可能是长度 1 或 2：

```text
长度1的循环节最多包含1种字符
长度2的循环节最多包含2种字符
都无法同时包含 a、b、c
```

## 五、为什么这个下界一定可以做到

把原字符串中每种字符第一次出现的顺序记录下来，作为循环节。

例如：

```text
s = abac
```

第一次出现的字符依次是：

```text
a、b、c
```

把 `abc` 重复，就得到：

```text
abcabc
```

原字符串 `abac` 可以按照顺序从中选出来：

```text
第1个字符 a：取第1个位置
第2个字符 b：取第2个位置
第3个字符 a：取第4个位置
第4个字符 c：取第6个位置
```

没有改变原字符的先后顺序，只是插入了字符，所以可以做到循环节长度为 3。

一般情况下也一样：把不同字符按第一次出现的顺序组成一个循环节，然后重复它，就能按顺序容纳原字符串中的所有字符。

因此：

```text
循环节长度至少是不同字符数量
循环节长度又确实可以做到不同字符数量
答案 = 不同字符数量
```

## 六、`set(s)` 是什么

```python
set(s)
```

`set` 表示集合，它会自动去掉重复字符。

例如：

```python
set("abcabcD")
```

结果包含：

```text
{'a', 'b', 'c', 'D'}
```

虽然 `a、b、c` 在字符串中重复出现，但集合中每种字符只保留一份。

## 七、`len(set(s))` 是什么意思

```python
len(set(s))
```

可以分成两步：

```python
unique_chars = set(s)       # 去重，得到不同字符集合
answer = len(unique_chars)  # 统计集合中有多少种字符
print(answer)
```

例如：

```python
s = "abcabcD"
unique_chars = {'a', 'b', 'c', 'D'}
len(unique_chars) = 4
```

所以输出 `4`。

## 八、代码逐行解释

```python
s = sys.stdin.readline().strip()
```

读取输入的一行字符串。

`readline()` 读入的内容末尾通常带有换行符 `\n`，`strip()` 会把它去掉。

```python
print(len(set(s)))
```

执行顺序是：

```text
先把 s 放进 set，去掉重复字符
再用 len 统计不同字符的数量
最后输出这个数量
```

## 九、样例解析

输入：

```text
abcabcD
```

不同字符为：

```text
a、b、c、D
```

数量为 4。

可以插入一个 `D`，得到：

```text
abcDabcD
```

这个新字符串由 `abcD` 重复组成，所以最小循环节长度为 4。

输出：

```text
4
```

## 十、容易误解的地方

### 1. 不是直接求原字符串的最小周期

原字符串 `abcabcD` 本身并不是完整的重复字符串，因为最后多了一个 `D`。

但题目允许插入字符，所以可以把它补成 `abcDabcD`。

### 2. 不需要真的构造新字符串

题目只要求输出循环节长度，不要求输出插入后的字符串。

根据上面的结论，只需要统计不同字符数量即可。

### 3. 大小写字符是不同字符

题目说明字符串由大小写字母组成，大小写要区分：

```text
'a' 和 'A' 是两种不同字符
```

例如：

```python
len(set("aA")) == 2
```

## 十一、复杂度

设字符串长度为 `n`：

- 遍历并去重：平均 `O(n)`；
- 统计集合大小：`O(1)`（最多只有 52 种大小写字母）；
- 总时间复杂度：`O(n)`；
- 额外空间复杂度：`O(1)`，因为字符种类最多 52 种。

## 十二、记忆方式

```text
只能插入，不能删除原字符
不同字符必须全部出现在循环节中
循环节长度至少是不同字符数
按第一次出现顺序重复，就一定能做到
所以答案 = len(set(s))
```
