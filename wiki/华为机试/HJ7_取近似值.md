# HJ7 取近似值

## 一、答案

```python
import sys


x = float(sys.stdin.readline())
answer = int(x + 0.5)

print(answer)
```

## 二、解题思路

题目要求按照下面的规则四舍五入：

```text
小数部分小于 0.5：向下取整；
小数部分大于等于 0.5：向上取整。
```

因为题目保证输入是正数，所以可以先给原数加上 `0.5`，再使用 `int()` 去掉小数部分：

```python
answer = int(x + 0.5)
```

例如 `x = 5.4`：

```text
5.4 + 0.5 = 5.9
int(5.9) = 5
```

所以 `5.4` 四舍五入后是 `5`。

例如 `x = 5.5`：

```text
5.5 + 0.5 = 6.0
int(6.0) = 6
```

所以 `5.5` 四舍五入后是 `6`。

## 三、为什么加 `0.5` 有效

可以把正实数写成：

```text
整数部分 + 小数部分
```

假设整数部分是 `5`。

当小数部分小于 `0.5` 时，例如 `5.3`：

```text
5.3 + 0.5 = 5.8
```

结果仍然没有到达 `6`，使用 `int()` 后得到 `5`。

当小数部分大于等于 `0.5` 时，例如 `5.7`：

```text
5.7 + 0.5 = 6.2
```

结果到达或超过 `6`，使用 `int()` 后得到 `6`。

最关键的边界是 `5.5`：

```text
5.5 + 0.5 = 6.0
```

正好得到 `6`，符合题目要求的“等于 `0.5` 时向上取整”。

## 四、代码逐行解释

### 1. 读取小数

```python
x = float(sys.stdin.readline())
```

`sys.stdin.readline()` 读取输入的一整行。

例如输入：

```text
5.5
```

读取到的原本是字符串，所以使用 `float()` 转换为小数：

```python
x = 5.5
```

### 2. 四舍五入

```python
answer = int(x + 0.5)
```

先加 `0.5`，然后使用 `int()` 去掉小数部分。

对于正数，`int()` 可以理解为直接删除小数点后面的内容：

```python
int(5.1)  # 5
int(5.9)  # 5
int(6.0)  # 6
```

注意，`int()` 本身不是四舍五入：

```python
int(5.9)
```

结果仍然是 `5`。本题是通过“先加 `0.5`，再使用 `int()`”实现四舍五入。

### 3. 输出结果

```python
print(answer)
```

输出四舍五入后的整数。

## 七、为什么不直接使用 `round()`

Python 的 `round()` 在数字正好位于两个整数中间时，使用的规则和本题不完全一样。

例如：

```python
round(4.5)  # 4
round(5.5)  # 6
```

Python 会倾向于取相邻的偶数，这种规则叫做“银行家舍入”。

但本题明确要求：

```text
小数部分大于等于 0.5，一律向上取整。
```

所以：

```text
4.5 应该得到 5
5.5 应该得到 6
```

因此本题不要直接使用 `round()`，而使用：

```python
int(x + 0.5)
```

## 八、适用范围

`int(x + 0.5)` 这个简单写法适用于本题，是因为题目保证：

```text
x 是正数
```

如果题目还包含负数，四舍五入的处理需要重新考虑，不能直接照搬这条公式。

- 时间复杂度：`O(1)`；
- 空间复杂度：`O(1)`。
