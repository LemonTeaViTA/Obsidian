# HJ26 字符串排序

## 一、答案

```python
import sys


s = sys.stdin.readline().rstrip('\n')

# 第一步：单独取出所有字母
letters = []
for ch in s:
    if ch.isalpha():
        letters.append(ch)

# 第二步：忽略大小写，按照字母表顺序排序
letters.sort(key=lambda ch: ch.lower())

# 第三步：把排好序的字母放回原来的字母位置
answer = []
letter_index = 0

for ch in s:
    if ch.isalpha():
        answer.append(letters[letter_index])
        letter_index += 1
    else:
        # 非字母字符保持原来的位置
        answer.append(ch)

print(''.join(answer))
```

## 二、题目翻译成人话

这道题要求完成两件事：

1. 所有字母按照 `a、b、c……z` 的顺序重新排列，排序时不区分大小写；
2. 空格、数字和标点等非字母字符不能移动。

例如：

```text
Hello NowCoder!
```

其中的空格和感叹号必须留在原来的位置，只有字母可以参加排序。

## 三、解题方法

可以分成三步：

```text
取出所有字母 → 给字母排序 → 把字母放回字母位置
```

### 第一步：取出所有字母

```python
letters = []

for ch in s:
    if ch.isalpha():
        letters.append(ch)
```

`ch.isalpha()` 用来判断 `ch` 是不是字母：

```python
'A'.isalpha()   # True
'b'.isalpha()   # True
'1'.isalpha()   # False
'!'.isalpha()   # False
' '.isalpha()   # False
```

所以空格、数字和标点不会放进 `letters`。

### 第二步：忽略大小写排序

```python
letters.sort(key=lambda ch: ch.lower())
```

`key=lambda ch: ch.lower()` 的意思是：比较字母顺序时，先把字母临时看成小写。

例如：

```text
B 被当成 b 比较
A 被当成 a 比较
```

这里只是用于比较，并不会真的把原来的大写字母改成小写。

Python 的排序是稳定排序。如果两个字母忽略大小写后相同，它们会保持输入时的先后顺序。

例如：

```text
输入顺序：B b
排序以后：B b
```

### 第三步：把字母放回去

```python
answer = []
letter_index = 0

for ch in s:
    if ch.isalpha():
        answer.append(letters[letter_index])
        letter_index += 1
    else:
        answer.append(ch)
```

再次从左向右检查原字符串：

- 原位置是字母，就从排好序的 `letters` 中取出一个字母；
- 原位置不是字母，就把原字符直接放回去。

`letter_index` 表示下一次应该拿 `letters` 中的第几个字母。

## 四、手算示例一

输入：

```text
BabA
```

取出所有字母：

```text
[B, a, b, A]
```

忽略大小写排序时，相当于比较：

```text
[b, a, b, a]
```

因此排序结果是：

```text
[a, A, B, b]
```

两个 `a` 对应的原字符是 `a、A`，保持原来的先后顺序；两个 `b` 对应的原字符是 `B、b`，也保持原来的先后顺序。

最终输出：

```text
aABb
```

## 五、非字母为什么不会移动

以这个简单字符串为例：

```text
b-a!
```

取出的字母为：

```text
[b, a]
```

排序后为：

```text
[a, b]
```

放回原字符串时：

| 原来的位置 | 原字符 | 处理方式 | 新字符 |
| ---: | :---: | --- | :---: |
| 0 | `b` | 字母位置，放入第一个排序后的字母 | `a` |
| 1 | `-` | 非字母，保持不变 | `-` |
| 2 | `a` | 字母位置，放入第二个排序后的字母 | `b` |
| 3 | `!` | 非字母，保持不变 | `!` |

结果是：

```text
a-b!
```

## 六、输入为什么使用 `rstrip('\n')`

```python
s = sys.stdin.readline().rstrip('\n')
```

`readline()` 会读取一整行，并且通常会把行末的换行符 `\n` 一起读进来。

这里只删除换行符，不能随便使用 `strip()`，因为本题中的空格属于原字符串的一部分，必须保留原来的位置。

也不能使用 `split()`，因为 `split()` 会把字符串按照空格拆开，并丢掉用于分隔的空格。

## 七、`''.join(answer)` 是什么意思

`answer` 是字符列表，例如：

```python
answer = ['a', '-', 'b', '!']
```

执行：

```python
''.join(answer)
```

会把列表里的字符连接成一个字符串：

```text
a-b!
```

## 八、复杂度

假设字符串长度是 `n`：

- 提取字母需要 `O(n)`；
- 排序最多需要 `O(n log n)`；
- 放回字符需要 `O(n)`。

总时间复杂度是 `O(n log n)`，空间复杂度是 `O(n)`。本题 `n ≤ 1000`，完全满足要求。
