# HJ127 小红的双生串

## 一、答案

~~~python
import sys
from collections import Counter

s = sys.stdin.readline().strip()
half = len(s) // 2

left = s[:half]
right = s[half:]

left_changes = len(left) - max(Counter(left).values())
right_changes = len(right) - max(Counter(right).values())

print(left_changes + right_changes)
~~~

## 二、题目翻译成人话

字符串长度一定是偶数。把它平均分成前半部分和后半部分。

双生串要求前半部分所有字符相同，后半部分所有字符相同。前后两半可以使用相同或不同的字符。

例如 `popipa` 分成：

~~~text
前半：pop
后半：ipa
~~~

前半可以改成 `ppp`，后半可以改成 `aaa`，一共需要修改 3 次。

## 三、这是什么类型的题目

这是“分组 + 频次统计 + 贪心”题。

每一半最终都必须统一成一个字符。为了修改次数最少，应保留这一半中出现次数最多的字符，只修改其它字符。

## 四、为什么保留最高频字符

假设一半是：

~~~text
a b a c a
~~~

`a` 出现 3 次，`b` 和 `c` 各出现 1 次。统一成 `a` 时只需要修改 `b、c`，共 2 次。

统一成其它字符需要修改 4 次，所以保留最高频字符最优。

这一半的修改次数是：

~~~text
这一半长度 - 最高频字符出现次数
~~~

## 五、为什么前后两半可以分别计算

题目没有要求前半和后半使用同一个字符，只要求各自内部相同。

因此前半的修改不会影响后半，后半的修改也不会影响前半，分别求最小值再相加即可。

## 六、样例 `popipa` 的计算

前半 `pop`：`p` 出现 2 次，保留 `p`，修改 `o`，需要 1 次。

后半 `ipa`：三个字符各出现 1 次，任选一个作为统一字符，需要修改另外 2 个，需 2 次。

总修改次数：

~~~text
1 + 2 = 3
~~~

## 七、`Counter` 是什么

~~~python
from collections import Counter
~~~

`Counter` 是 Python 标准库中用来统计次数的工具。

例如：

~~~python
Counter('pop')
~~~

结果相当于：

~~~python
{'p': 2, 'o': 1}
~~~

因此：

~~~python
max(Counter(left).values())
~~~

表示前半部分中，出现次数最多的字符出现了几次。

## 八、代码逐行解释

~~~python
half = len(s) // 2
~~~

字符串长度是偶数，整除 2 得到一半长度。

~~~python
left = s[:half]
right = s[half:]
~~~

切出前半和后半。例如 `popipa` 会得到 `pop` 和 `ipa`。

~~~python
len(left) - max(Counter(left).values())
~~~

这一半总长度减去保留字符的数量，就是需要修改的字符数。

## 九、不使用 `Counter` 的初学者写法

~~~python
import sys

s = sys.stdin.readline().strip()
half = len(s) // 2

left = s[:half]
right = s[half:]

def changes(part):
    counts = {}

    for ch in part:
        counts[ch] = counts.get(ch, 0) + 1

    max_count = 0
    for count in counts.values():
        if count > max_count:
            max_count = count

    return len(part) - max_count

print(changes(left) + changes(right))
~~~

这份代码把统计过程展开，更适合初学者。

## 十、为什么不用枚举 26 个字母

每一半只需要决定最终统一成哪个字符。保留出现次数最多的字符一定修改最少，所以不需要把 26 个字母全部枚举一遍。

## 十一、复杂度

- 时间复杂度：`O(n)`；
- 额外空间复杂度：`O(26)`，可以看作 `O(1)`。

## 十二、记忆方式

~~~text
从中间把字符串分成两半
每一半保留最高频字符
其它字符改掉
修改数 = 半段长度 - 最高频次数
前半答案 + 后半答案
~~~
