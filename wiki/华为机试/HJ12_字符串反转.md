# HJ12 字符串反转

## 一、答案

```python
import sys


s = sys.stdin.readline().strip()
reversed_string = s[::-1]

print(reversed_string)
```

## 二、解题思路

题目要求把字符串中的字符顺序完全颠倒。

例如：

```text
redocwonolleh
```

原来的字符顺序是从左到右，反转时改成从右到左读取：

```text
hellonowcoder
```

Python 可以使用字符串切片：

```python
s[::-1]
```

直接得到反转后的字符串。

## 三、`s[::-1]` 是什么意思

字符串切片的完整格式是：

```python
s[开始位置:结束位置:步长]
```

例如：

```python
s[0:5:1]
```

表示：

```text
从下标 0 开始；
到下标 5 之前结束；
每次向右移动 1 个位置。
```

本题使用：

```python
s[::-1]
```

其中：

```text
开始位置省略；
结束位置省略；
步长是 -1。
```

步长 `-1` 表示每次向左移动一位，所以 Python 会从最后一个字符开始，一直读取到第一个字符。

例如：

```python
s = "abcde"
```

每个字符的下标是：

```text
字符：a  b  c  d  e
下标：0  1  2  3  4
```

使用 `s[::-1]` 时，读取顺序是：

```text
下标：4、3、2、1、0
字符：e、d、c、b、a
```

因此结果是：

```python
"edcba"
```

## 四、代码逐行解释

### 1. 读取字符串

```python
s = sys.stdin.readline().strip()
```

`sys.stdin.readline()` 读取输入的一整行。

例如输入：

```text
redocwonolleh
```

读取时末尾通常带有换行符，`strip()` 删除换行符以后得到：

```python
s = "redocwonolleh"
```

题目保证字符串只包含小写字母，不包含空格，因此可以直接使用 `strip()`。

### 2. 反转字符串

```python
reversed_string = s[::-1]
```

从最后一个字符开始，向前读取到第一个字符。

```python
"redocwonolleh"[::-1]
```

得到：

```python
"hellonowcoder"
```

### 3. 输出结果

```python
print(reversed_string)
```

输出反转后的字符串。

## 五、示例 1 执行过程

输入：

```text
redocwonolleh
```

从右向左读取字符：

```text
h、e、l、l、o、n、o、w、c、o、d、e、r
```

连接以后得到：

```text
hellonowcoder
```

最终输出：

```text
hellonowcoder
```

## 六、示例 2 执行过程

输入：

```text
a
```

字符串只有一个字符，反转后仍然是它自己：

```text
a
```

## 七、使用循环的写法

如果暂时不熟悉 `[::-1]`，也可以使用循环实现：

```python
import sys


s = sys.stdin.readline().strip()
result = []

for i in range(len(s) - 1, -1, -1):
    result.append(s[i])

print("".join(result))
```

假设字符串长度为 `5`，有效下标是：

```text
0、1、2、3、4
```

```python
range(len(s) - 1, -1, -1)
```

就会产生：

```text
4、3、2、1、0
```

每次取出一个字符并加入列表：

```python
result.append(s[i])
```

最后使用：

```python
"".join(result)
```

将所有字符连接成一个新字符串。

`s[::-1]` 就是完成同样工作的简洁写法。

## 八、和 HJ11 的区别

### HJ11 数字颠倒

```text
输入内容是数字字符；
需要特别注意保留反转后开头的 0；
所以同样把输入当字符串处理。
```

### HJ12 字符串反转

```text
输入内容是小写字母；
只需要将所有字符顺序颠倒。
```

两道题的输入内容不同，但核心代码完全一样：

```python
s[::-1]
```

## 九、复杂度

设字符串长度为 `n`：

- 时间复杂度：`O(n)`，需要读取每个字符；
- 空间复杂度：`O(n)`，反转会生成新的字符串。
