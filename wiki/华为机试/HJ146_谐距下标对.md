# HJ146 谐距下标对

## 一、答案

```python
import sys


data = list(map(int, sys.stdin.buffer.read().split()))
n = data[0]
array = data[1:1 + n]

count = {}
answer = 0

# 下标按题目从 1 开始，所以使用 enumerate(..., start=1)
for index, value in enumerate(array, start=1):
    key = value - index

    # 当前 key 之前出现过多少次，就能和当前位置组成多少对
    answer += count.get(key, 0)
    count[key] = count.get(key, 0) + 1

print(answer)
```

## 二、题目翻译成人话

数组中选择两个下标 `i` 和 `j`，并且要求：

```text
i < j
a[j] - a[i] = j - i
```

这样的下标对 `(i, j)` 就叫做“谐距下标对”。题目要求统计一共有多少对。

例如数组：

```text
[1, 2, 3, 4, 5, 6]
```

任意 `i < j` 都满足：

```text
a[j] - a[i] = j - i
```

所以答案是所有下标对的数量：

```text
6 × 5 ÷ 2 = 15
```

## 三、为什么不能直接枚举两个下标

最直接的方法是：

```python
for i in range(n):
    for j in range(i + 1, n):
        # 检查条件
```

这样需要检查大约 `n²` 次。当 `n = 100000` 时，次数太多，会超时。

因此要把条件变形，降低复杂度。

## 四、最关键的等式变形

原条件是：

```text
a[j] - a[i] = j - i
```

把 `a[i]` 和 `i` 移到右侧：

```text
a[j] - j = a[i] - i
```

这说明：

> 只要两个位置的 `a[index] - index` 相同，它们就能组成一对谐距下标对。

因此，我们不需要拿每两个下标比较，只需要统计每个 `a[index] - index` 出现了多少次。

## 五、举例理解

对于数组：

```text
下标 i：  1  2  3  4  5  6
数组值：  1  2  3  4  5  6
```

计算 `a[i] - i`：

```text
1 - 1 = 0
2 - 2 = 0
3 - 3 = 0
4 - 4 = 0
5 - 5 = 0
6 - 6 = 0
```

值 `0` 一共出现 6 次。6 个位置中任意选择 2 个，都能组成一对：

```text
C(6, 2) = 6 × 5 ÷ 2 = 15
```

## 六、为什么遍历时可以直接累加

假设某个 `key` 到当前位置之前已经出现了 `3` 次。

当前元素的 `key` 如果也相同，那么它可以和之前的这 3 个位置分别组成一对，所以答案增加 `3`。

代码：

```python
answer += count.get(key, 0)
```

然后把当前位置记录进去：

```python
count[key] = count.get(key, 0) + 1
```

这样后面的元素就可以和当前位置配对。

这种写法天然保证了下标顺序 `i < j`：

- 只和“之前已经遍历过”的位置配对；
- 当前下标一定比之前的位置大。

## 七、代码逐行解释

### 1. 读取输入

```python
data = list(map(int, sys.stdin.buffer.read().split()))
```

输入可能是：

```text
6
1 2 3 4 5 6
```

这句代码会把所有数字读入列表：

```python
data = [6, 1, 2, 3, 4, 5, 6]
```

然后：

```python
n = data[0]
array = data[1:1 + n]
```

得到：

```text
n = 6
array = [1, 2, 3, 4, 5, 6]
```

### 2. 创建统计字典

```python
count = {}
answer = 0
```

- `count`：记录每种 `a[index] - index` 出现了多少次；
- `answer`：记录目前找到的下标对总数。

### 3. 从 1 开始枚举下标

```python
for index, value in enumerate(array, start=1):
```

Python 列表默认下标从 `0` 开始，但题目中的下标从 `1` 开始，所以使用：

```python
start=1
```

例如：

```python
array = [10, 20, 30]
```

遍历时得到：

```text
index=1, value=10
index=2, value=20
index=3, value=30
```

`start=1` 不是“从数组的第 1 个元素开始取”，而是“产生的编号从 1 开始”。数组中的所有元素仍然都会遍历。

下面两种写法是等价的：

```python
for index, value in enumerate(array, start=1):
    print(index, value)
```

```python
index = 1
for value in array:
    print(index, value)
    index += 1
```

如果不写 `start=1`，Python 默认从 `0` 开始：

```python
array = [10, 20, 30]

for index, value in enumerate(array):
    print(index, value)
```

输出为：

```text
0 10
1 20
2 30
```

而写成 `enumerate(array, start=1)` 后输出为：

```text
1 10
2 20
3 30
```

题目把数组下标记作 `1, 2, 3, ...`，所以代码使用 `start=1`，这样 `index` 就正好对应题目中的下标。

### 4. 计算关键值

```python
key = value - index
```

这个 `key` 就是：

```text
a[index] - index
```

两个位置的 `key` 相同，就说明它们满足题目的条件。

### 5. 统计配对数量

```python
answer += count.get(key, 0)
```

`count.get(key, 0)` 的意思是：

- 如果 `key` 在字典中，取出它的出现次数；
- 如果还没有出现过，就返回 `0`。

例如当前 `key` 之前出现了 2 次，那么当前位置新增 2 对。

把下面几行放在一起看：

```python
key = value - index
answer += count.get(key, 0)
count[key] = count.get(key, 0) + 1
```

它们的执行顺序是：

1. 算出当前位置的 `key`；
2. 看之前有多少个位置拥有同样的 `key`，这些位置都能和当前下标组成新的一对；
3. 把当前位置也加入统计，供后面的元素使用。

例如数组为 `[1, 2, 3]`：

| 当前下标 `index` | 数组值 `value` | `key = value - index` | 之前相同 `key` 的数量 | 新增配对数 | 当前答案 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 1 | 0 | 0 | 0 | 0 |
| 2 | 2 | 0 | 1 | 1 | 1 |
| 3 | 3 | 0 | 2 | 2 | 3 |

最终答案是 `3`，对应下标对 `(1,2)`、`(1,3)`、`(2,3)`。

## 八、一个不满足条件的例子

数组：

```text
[1, 3, 2]
```

对应的 `a[index] - index`：

```text
1 - 1 = 0
3 - 2 = 1
2 - 3 = -1
```

三个关键值都不相同，所以没有任何两个位置可以配对，答案是 `0`。

## 九、复杂度

只遍历数组一次，每次字典查询和更新的平均复杂度为 `O(1)`。

- 时间复杂度：`O(n)`；
- 额外空间复杂度：`O(n)`。

这可以满足 `n ≤ 100000` 的限制。

## 十、记忆方式

```text
原式：a[j] - a[i] = j - i
变形：a[j] - j = a[i] - i

遍历数组，计算 key = a[index] - index
统计相同 key 的数量
当前 key 之前出现几次，答案就增加几
```

## 十一、`sys.stdin.buffer` 是什么

代码中使用了：

```python
sys.stdin.buffer.read()
```

它表示从标准输入中读取“字节数据”。这是 Python 提供的一种较快的输入方式，输入数据很多时可以减少一些文本转换的开销。

普通写法是：

```python
sys.stdin.read()
```

它读取的是字符串文本。对于本题来说，两种写法都可以：

```python
data = list(map(int, sys.stdin.read().split()))
```

或者：

```python
data = list(map(int, sys.stdin.buffer.read().split()))
```

### 两种写法的区别

```python
sys.stdin.read()          # 得到字符串，例如 '6 1 2 3'
sys.stdin.buffer.read()   # 得到字节，例如 b'6 1 2 3'
```

虽然第二种得到的是字节，但 `int()` 可以直接把数字字节转换成整数：

```python
int(b'123')  # 结果是 123
```

所以 HJ146 中使用 `buffer` 不会影响计算。

### 初学者应该用哪一种

如果输入规模不大，推荐先使用更容易理解的普通写法：

```python
data = list(map(int, sys.stdin.read().split()))
```

`buffer` 只是输入优化，不是必须掌握的算法知识。只有在输入量很大、普通输入可能较慢时，再使用：

```python
sys.stdin.buffer.read()
```
