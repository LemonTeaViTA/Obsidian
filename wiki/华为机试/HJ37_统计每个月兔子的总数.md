# HJ37 统计每个月兔子的总数

## 一、答案

```python
import sys

n = int(sys.stdin.readline())

if n <= 2:
    print(1)
else:
    prev2 = 1
    prev1 = 1

    for _ in range(3, n + 1):
        current = prev2 + prev1
        prev2 = prev1
        prev1 = current

    print(prev1)
```

## 二、题目翻译成人话

一开始只有一只兔子。兔子出生后的前两个月不能生小兔子，从第三个月开始，每个月生一只；兔子不会死亡。

求第 `n` 个月一共有多少只兔子。

前几个月的兔子总数是：

```text
第1个月：1
第2个月：1
第3个月：2
第4个月：3
第5个月：5
第6个月：8
```

这就是斐波那契数列。

## 三、为什么是前两个月相加

设第 `n` 个月的兔子总数为 `f(n)`。

第 `n` 个月的兔子包括：

```text
上个月已经存在的兔子
这个月新出生的小兔子
```

上个月已经存在的数量是 `f(n - 1)`。

能够在这个月生小兔子的兔子，是两个月前已经存在的兔子，因此新出生的数量是 `f(n - 2)`。

所以：

```text
f(n) = f(n - 1) + f(n - 2)
```

例如：

```text
f(5) = f(4) + f(3) = 3 + 2 = 5
```

## 四、初始情况

第一个月和第二个月都只有初始兔子：

```text
f(1) = 1
f(2) = 1
```

所以代码先处理：

```python
if n <= 2:
    print(1)
```

## 五、两个变量是什么意思

```python
prev2 = 1
prev1 = 1
```

开始计算第三个月时：

```text
prev2 表示两个月前的兔子数
prev1 表示上个月的兔子数
```

计算当前月份：

```python
current = prev2 + prev1
```

然后让月份向前移动：

```python
prev2 = prev1
prev1 = current
```

意思是：

```text
上个月变成两个月前
当前月份变成上个月
```

## 六、输入 5 时的计算过程

开始时：

```text
prev2 = 1  # 第1个月
prev1 = 1  # 第2个月
```

依次计算：

```text
第3个月：1 + 1 = 2
第4个月：1 + 2 = 3
第5个月：2 + 3 = 5
```

因此输出 `5`。

## 七、`range(3, n + 1)` 为什么这样写

前两个月的结果已经知道，所以从第 3 个月开始计算：

```python
range(3, n + 1)
```

Python 的 `range` 不包含右端点，因此要写 `n + 1`，这样才能计算到第 `n` 个月。

例如：

```python
range(3, 6)
```

得到 `3、4、5`。

## 八、为什么只保存两个数字

计算下一个月份时，只需要前两个月的结果，更早的数字不再使用，因此不需要保存整个数列。

- 时间复杂度：`O(n)`；
- 空间复杂度：`O(1)`。

## 九、记忆方式

```text
第1个月是1，第2个月是1；
从第3个月开始，每个月等于前两个月相加。
```
