# HJ145 小红背单词

## 一、答案

~~~python
import sys
from collections import defaultdict


n = int(sys.stdin.readline())

# counts 记录还没有记住的单词已经背了多少次
counts = defaultdict(int)
remembered = set()
remembered_count = 0

for _ in range(n):
    word = sys.stdin.readline().strip()

    # 已经记住的单词不需要再次处理
    if word in remembered:
        continue

    counts[word] += 1

    # 当前已经记住 remembered_count 个单词，
    # 新单词需要出现 remembered_count + 1 次
    if counts[word] >= remembered_count + 1:
        remembered.add(word)
        remembered_count += 1

print(remembered_count)
~~~

## 二、题目翻译成人话

小红按顺序背很多单词。

如果当前已经记住了 `i` 个单词，那么一个还没记住的新单词需要累计背 `i + 1` 次，才算记住它。

例如：

~~~text
刚开始记住 0 个单词，新单词出现 1 次就能记住
记住 1 个单词后，新单词需要出现 2 次
记住 2 个单词后，新单词需要出现 3 次
~~~

求最后一共记住了多少个不同单词。

## 三、这是什么类型的题目

这是一道：

~~~text
顺序模拟 + 哈希集合 + 哈希计数
~~~

因为每读入一个单词，都要立刻根据当前状态判断是否记住它，所以必须按照输入顺序处理。

不能把所有单词读完后再统一统计，因为要求次数 `i + 1` 中的 `i` 会随着过程变化。

## 四、两个重要的数据结构

### 1. remembered 集合

~~~python
remembered = set()
~~~

保存已经记住的单词。

例如：

~~~python
{"you", "queue"}
~~~

判断一个单词是否已经记住：

~~~python
if word in remembered:
    continue
~~~

集合查找速度很快，而且不会保存重复元素。

### 2. counts 字典

~~~python
counts = defaultdict(int)
~~~

记录还没记住的每个单词出现了多少次。

例如输入过：

~~~text
thank、queue、queue、thank
~~~

可能记录为：

~~~python
{"thank": 2, "queue": 2}
~~~

`defaultdict(int)` 的特点是：第一次访问不存在的单词时，默认次数是 `0`，所以可以直接写：

~~~python
counts[word] += 1
~~~

## 五、为什么已经记住的单词要跳过

~~~python
if word in remembered:
    continue
~~~

一个单词一旦记住，就不再是“没有记住的新单词”。以后再次背它，不会让记住的单词数量增加。

例如 `you` 已经记住后，再出现 `you`，直接跳过即可。

## 六、为什么当前次数达到 `remembered_count + 1` 就能记住

题目规定：如果已经记住了 `i` 个单词，新单词需要背 `i + 1` 次。

代码中的：

~~~python
remembered_count
~~~

就是当前已经记住的单词数量，所以要求次数是：

~~~python
remembered_count + 1
~~~

每读到一次还没记住的单词，就增加它的次数：

~~~python
counts[word] += 1
~~~

如果达到要求：

~~~python
if counts[word] >= remembered_count + 1:
    remembered.add(word)
    remembered_count += 1
~~~

就把它加入已记住集合，并将已记住数量加一。

## 七、官方示例逐步执行

输入：

~~~text
5
you
thank
queue
queue
thank
~~~

开始时：

~~~text
remembered = {}
remembered_count = 0
~~~

### 第 1 个单词：you

当前需要 `0 + 1 = 1` 次。

~~~text
you 出现第 1 次，达到要求
记住 you
remembered_count = 1
~~~

### 第 2 个单词：thank

当前需要 `1 + 1 = 2` 次。

~~~text
thank 出现第 1 次，还不够
remembered_count 仍然是 1
~~~

### 第 3 个单词：queue

当前仍需要 `2` 次。

~~~text
queue 出现第 1 次，还不够
~~~

### 第 4 个单词：queue

~~~text
queue 出现第 2 次，达到要求
记住 queue
remembered_count = 2
~~~

### 第 5 个单词：thank

thank 之前已经出现过 1 次，这次是第 2 次。

但当前已经记住了 2 个单词，所以 thank 需要出现 `2 + 1 = 3` 次。

现在 thank 只出现了 2 次，还不能记住。

最终记住：

~~~text
you、queue
~~~

答案是：

~~~text
2
~~~

## 八、为什么次数要按单词分别记录

不同单词的背诵次数不能混在一起。

例如：

~~~text
apple、banana、apple
~~~

应该记录为：

~~~python
{"apple": 2, "banana": 1}
~~~

不能只使用一个总次数，因为题目问的是每个具体的新单词背了多少次。

## 九、为什么要边读边判断

假设输入顺序是：

~~~text
a、b、b、c、c、c
~~~

处理过程：

~~~text
开始已记住 0 个，a 出现 1 次，记住 a
现在已记住 1 个，b 需要 2 次，b 出现两次，记住 b
现在已记住 2 个，c 需要 3 次，c 出现三次，记住 c
~~~

每记住一个单词，后面新单词的要求次数就提高一。

如果不按顺序处理，就无法知道每次出现时的当前 `i`。

## 十、为什么使用 `>=` 而不是 `==`

代码写成：

~~~python
if counts[word] >= remembered_count + 1:
~~~

正常情况下次数会刚好达到要求，所以写 `==` 也可以。

使用 `>=` 更稳妥，表示只要已经达到或超过要求就记住，不会因为状态变化造成遗漏。

## 十一、复杂度

每个单词最多被处理一次，集合和字典的查找、插入平均都是 `O(1)`：

- 时间复杂度：平均 `O(n)`；
- 空间复杂度：`O(n)`，用于保存单词和计数。

题目中 `n <= 10000`，可以轻松通过。

## 十二、记忆方式

~~~text
remembered：已经记住的单词
counts：每个未记住单词出现次数
按输入顺序处理
出现次数达到 当前已记住数量 + 1，就记住它
最后输出 remembered 的数量
~~~
