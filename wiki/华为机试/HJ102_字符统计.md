# HJ102 字符统计

## 一、答案

~~~python
import sys
from collections import Counter

s = sys.stdin.readline().strip()
counts = Counter(s)

# 次数从多到少；次数相同时 ASCII 码从小到大
characters = sorted(counts, key=lambda ch: (-counts[ch], ord(ch)))

print(''.join(characters))
~~~

## 二、题目翻译成人话

统计字符串中每个不同字符出现了多少次，然后按照两条规则排序：

1. 出现次数多的排前面；
2. 出现次数相同时，ASCII 码小的排前面。

最后只输出字符，不输出次数。

例如 `aaddccdc`：

~~~text
a：2 次
d：3 次
c：3 次
~~~

`c` 和 `d` 都出现 3 次，但 `c` 的 ASCII 码更小，所以输出 `cda`。

## 三、这是什么类型的题目

这道题属于：

~~~text
哈希计数 + 自定义排序
~~~

计数可以用字典或 `Counter`，排序时按照题目规定的两个条件进行。

## 四、`Counter` 是什么

~~~python
from collections import Counter
counts = Counter(s)
~~~

`Counter` 是 Python 自带的计数工具。

如果 `s = 'aaddccdc'`，那么：

~~~python
Counter(s)
~~~

相当于：

~~~python
{'a': 2, 'd': 3, 'c': 3}
~~~

其中 `counts['d']` 就是字符 `d` 的出现次数 `3`。

## 五、`sorted(counts, key=...)` 排序的是什么

`counts` 遍历出来的是出现过的字符，所以排序对象是字符。

~~~python
characters = sorted(counts, key=lambda ch: (-counts[ch], ord(ch)))
~~~

这里的 `key` 告诉 Python 每个字符应该按照什么规则比较。

对于字符 `ch`，排序键是：

~~~python
(-counts[ch], ord(ch))
~~~

它是一个二元组，Python 会先比较第一个值；如果第一个值相同，再比较第二个值。

## 六、为什么次数前面要加负号

Python 默认从小到大排序，但题目要求次数从大到小。

假设：

~~~text
a 出现 2 次
c 出现 3 次
~~~

如果直接使用次数，`2` 会排在 `3` 前面，顺序错误。

加上负号后：

~~~text
a 的排序值是 -2
c 的排序值是 -3
~~~

从小到大排序时，`-3` 在 `-2` 前面，于是原次数多的字符先输出。

## 七、为什么使用 `ord(ch)`

`ord(ch)` 可以得到字符的 ASCII 码：

~~~python
ord('0')  # 48
ord('a')  # 97
ord('b')  # 98
~~~

题目要求次数相同时按照 ASCII 码从小到大，所以排序键的第二部分写成：

~~~python
ord(ch)
~~~

例如 `c` 和 `d` 都出现 3 次：

~~~text
c 的排序键：(-3, 99)
d 的排序键：(-3, 100)
~~~

第一项相同，再比较第二项，`99 < 100`，所以 `c` 在 `d` 前面。

## 八、为什么最后使用 `join`

`sorted` 返回的是列表，例如：

~~~python
['c', 'd', 'a']
~~~

题目要求输出字符串，所以使用：

~~~python
''.join(characters)
~~~

得到：

~~~text
cda
~~~

## 九、不使用 `Counter` 的写法

如果还没学过 `Counter`，可以使用普通字典：

~~~python
import sys

s = sys.stdin.readline().strip()
counts = {}

for ch in s:
    counts[ch] = counts.get(ch, 0) + 1

characters = sorted(counts, key=lambda ch: (-counts[ch], ord(ch)))
print(''.join(characters))
~~~

`counts.get(ch, 0)` 表示：如果字符以前没有出现过，就把次数当成 `0`。

## 十、复杂度

设字符串长度为 `n`，不同字符数量为 `k`：

- 计数需要 `O(n)`；
- 排序需要 `O(k log k)`；
- 总时间复杂度：`O(n + k log k)`；
- 空间复杂度：`O(k)`。

本题最多只有 36 种字符（10 个数字加 26 个小写字母）。

## 十一、记忆方式

~~~text
Counter 统计次数
排序键：(-出现次数, ASCII码)
负号让次数从大到小
ord 让相同次数按 ASCII 从小到大
join 输出字符
~~~
