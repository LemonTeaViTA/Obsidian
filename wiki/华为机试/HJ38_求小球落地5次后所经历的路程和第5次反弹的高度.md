# HJ38 求小球落地 5 次后所经历的路程和第 5 次反弹的高度

## 一、答案

```python
import sys

h = float(sys.stdin.readline())

distance = h
rebound_height = h / 2

# 第五次落地之前，完整经过前四次反弹
for _ in range(4):
    distance += 2 * rebound_height
    rebound_height /= 2

print(distance)
print(rebound_height)
```

## 二、题目翻译成人话

小球从 `h` 米高处落下。每次落地后，反弹高度变成上一次高度的一半。

题目要求输出：

1. 第五次落地时已经走过的总路程；
2. 第五次落地后反弹的高度。

## 三、为什么第一次路程是 `h`

小球一开始在 `h` 米高处，第一次直接落到地面，所以先走：

```python
distance = h
```

第一次落地后的反弹高度是：

```python
rebound_height = h / 2
```

## 四、为什么每次加 `2 * rebound_height`

一次反弹包含两段：

```text
从地面上升到反弹高度
从反弹高度再次落回地面
```

两段长度都等于 `rebound_height`，所以一次反弹的路程是：

```python
2 * rebound_height
```

之后下一次反弹高度减半：

```python
rebound_height /= 2
```

## 五、为什么循环 4 次

题目求的是“第五次落地时”的路程。第五次落地之前，只有前四次反弹已经完成了上升和下降：

```text
第一次反弹：上升、下降
第二次反弹：上升、下降
第三次反弹：上升、下降
第四次反弹：上升、下降
```

所以写成：

```python
for _ in range(4):
```

第五次反弹发生在第五次落地之后，只需要输出它的高度，不加入当前路程。

## 六、以 `h = 1` 手算

初始：

```text
distance = 1
rebound_height = 0.5
```

四次循环后：

```text
第1次：distance = 2，rebound_height = 0.25
第2次：distance = 2.5，rebound_height = 0.125
第3次：distance = 2.75，rebound_height = 0.0625
第4次：distance = 2.875，rebound_height = 0.03125
```

因此输出：

```text
2.875
0.03125
```

## 七、容易出错的地方

### 1. 把第五次反弹加入路程

第五次反弹发生在第五次落地后，不能加入“第五次落地时”的路程。

### 2. 每次只加一次反弹高度

一次反弹包含上升和下降两段，因此要加：

```python
2 * rebound_height
```

## 八、复杂度

反弹次数固定为 5 次：

- 时间复杂度：`O(1)`；
- 空间复杂度：`O(1)`。

## 九、记忆方式

```text
先加初始下落 h
前四次反弹各加 2 × 当前高度
每次高度除以 2
循环结束后的高度就是第五次反弹高度
```
