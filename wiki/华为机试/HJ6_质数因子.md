# HJ6 质数因子

## 一、答案

```python
import sys


n = int(sys.stdin.readline())
factors = []
factor = 2

while factor * factor <= n:
    while n % factor == 0:
        factors.append(factor)
        n //= factor

    factor += 1

if n > 1:
    factors.append(n)

print(" ".join(map(str, factors)))
```

## 二、解题思路

题目要求把一个整数分解成若干个质数相乘，并按照从小到大的顺序输出这些质数。

例如：

```text
180 = 2 × 2 × 3 × 3 × 5
```

可以从最小的因子 `2` 开始尝试：

1. 如果 `n` 能被当前因子整除，就记录这个因子；
2. 同时把 `n` 除以这个因子；
3. 继续判断是否还能被相同因子整除；
4. 除不动以后，再尝试下一个因子。

因为因子是按照 `2、3、4、5...` 的顺序尝试，所以记录的结果自然是从小到大的，不需要另外排序。

## 三、为什么相同因子要反复除

以 `180` 为例，它包含两个因子 `2`：

```text
180 ÷ 2 = 90
90 ÷ 2 = 45
```

如果只判断一次，就会漏掉第二个 `2`。

所以代码使用内层 `while`：

```python
while n % factor == 0:
    factors.append(factor)
    n //= factor
```

含义是：

```text
只要当前因子还能整除 n，
就继续记录并继续除。
```

## 四、代码逐行解释

### 1. 读取整数

```python
n = int(sys.stdin.readline())
```

读取题目输入，并使用 `int()` 转成整数。

例如输入：

```text
180
```

得到：

```python
n = 180
```

### 2. 准备结果列表和第一个因子

```python
factors = []
factor = 2
```

`factors` 用来保存找到的质因子。

质数中最小的是 `2`，所以从 `2` 开始尝试。

### 3. 外层循环

```python
while factor * factor <= n:
```

这表示只要：

```text
当前因子 × 当前因子 <= 剩余的 n
```

就继续尝试分解。

它等价于“当前因子不超过 `n` 的平方根”，但是不需要调用平方根函数。

为什么只需要尝试到平方根？

假设一个数可以写成：

```text
n = a × b
```

如果 `a` 和 `b` 都大于 `n` 的平方根，那么：

```text
a × b > n
```

这和 `a × b = n` 矛盾。因此一个合数至少有一个因子不大于它的平方根。

### 4. 判断能不能整除

```python
while n % factor == 0:
```

`%` 是取余运算。

如果余数是 `0`，说明可以整除：

```python
180 % 2 == 0
```

所以 `2` 是 `180` 的一个因子。

### 5. 记录因子并缩小问题

```python
factors.append(factor)
n //= factor
```

`append()` 把当前因子放入结果列表。

`n //= factor` 等价于：

```python
n = n // factor
```

`//` 表示整数除法。

例如：

```python
n = 180
factor = 2
n //= factor
```

执行后：

```python
n = 90
```

我们已经从 `180` 中取出了一个因子 `2`，接下来只需继续分解剩余的 `90`。

### 6. 尝试下一个因子

```python
factor += 1
```

当前因子除不动以后，就加 `1`，继续尝试下一个数：

```text
2、3、4、5、6……
```

这里即使尝试到 `4、6` 这样的合数也没有问题。

例如尝试到 `4` 时，其中的质因子 `2` 早已被除干净，所以剩余的 `n` 不会再被 `4` 整除。真正被记录下来的因子仍然都是质数。

### 7. 记录最后剩下的质数

```python
if n > 1:
    factors.append(n)
```

循环结束后，如果 `n` 仍然大于 `1`，它就是最后一个质因子，需要加入结果。

例如分解 `180` 时：

```text
180 ÷ 2 = 90
90 ÷ 2 = 45
45 ÷ 3 = 15
15 ÷ 3 = 5
```

最后剩下 `5`。

此时已经不需要继续尝试，因为 `5` 本身就是质数，所以把它加入列表。

### 8. 按空格输出

```python
print(" ".join(map(str, factors)))
```

这行分为两步。

先使用：

```python
map(str, factors)
```

把整数转换成字符串。

例如：

```python
[2, 2, 3, 3, 5]
```

转换后相当于：

```python
["2", "2", "3", "3", "5"]
```

然后：

```python
" ".join(...)
```

使用空格把它们连接起来：

```text
2 2 3 3 5
```

## 五、示例完整执行过程

输入：

```text
180
```

从 `factor = 2` 开始：

```text
180 可以除以 2：记录 2，n 变成 90
90 可以除以 2：记录 2，n 变成 45
45 不能除以 2：factor 变成 3
45 可以除以 3：记录 3，n 变成 15
15 可以除以 3：记录 3，n 变成 5
5 不能除以 3
```

此时：

```python
factor * factor = 4 * 4 = 16
n = 5
```

`16 <= 5` 不成立，外层循环结束。

剩余的 `5` 大于 `1`，把它加入结果：

```python
factors = [2, 2, 3, 3, 5]
```

最终输出：

```text
2 2 3 3 5
```

## 六、几个特殊情况

### 输入本身就是质数

输入：

```text
7
```

没有找到更小的因子，最后的 `n` 仍然是 `7`，所以输出：

```text
7
```

### 输入是质数的平方

输入：

```text
49
```

```text
49 ÷ 7 = 7
7 ÷ 7 = 1
```

输出：

```text
7 7
```

### 输入是 2 的多次方

输入：

```text
16
```

内层循环会一直除以 `2`：

```text
16 ÷ 2 = 8
8 ÷ 2 = 4
4 ÷ 2 = 2
2 ÷ 2 = 1
```

输出：

```text
2 2 2 2
```

## 七、复杂度

最坏情况下，输入本身是一个较大的质数，需要尝试到它的平方根：

- 时间复杂度：`O(sqrt(n))`；
- 空间复杂度：`O(log n)`，用于保存质因子结果。

题目中的 `n` 最大约为 `2 × 10^9`，平方根约为 `44722`，可以在时间限制内完成。

## 八、记忆方式

```text
从 2 开始试除；
能除就记录，并继续除同一个因子；
除不动就尝试下一个因子；
只需尝试到剩余数字的平方根；
最后大于 1 的剩余值也是质因子。
```
