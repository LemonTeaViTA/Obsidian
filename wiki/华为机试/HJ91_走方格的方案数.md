# HJ91 走方格的方案数

## 一、答案

~~~python
import sys

n, m = map(int, sys.stdin.readline().split())

# dp[i][j]：从左上角走到第 i 行、第 j 列格点的方案数
dp = [[0] * (m + 1) for _ in range(n + 1)]

# 第一行只能一直向右，第一列只能一直向下
for j in range(m + 1):
    dp[0][j] = 1

for i in range(n + 1):
    dp[i][0] = 1

# 其它位置可以从上方或左方到达
for i in range(1, n + 1):
    for j in range(1, m + 1):
        dp[i][j] = dp[i - 1][j] + dp[i][j - 1]

print(dp[n][m])
~~~

## 二、题目翻译成人话

从网格左上角出发，只允许向右或向下走，求到达右下角有多少条不同路线。

输入的 n 和 m 表示需要向下走 n 步、向右走 m 步。因此格点的下标范围是 0 到 n、0 到 m，共有 (n+1) × (m+1) 个格点。

## 三、dp[i][j] 表示什么

~~~text
dp[i][j] = 从起点走到第 i 行、第 j 列格点的方案数
~~~

终点是 (n,m)，所以答案是 dp[n][m]。

## 四、为什么是上方加左方

到达格点 (i,j) 的最后一步只有两种可能：

~~~text
从上方 (i-1,j) 向下走
从左方 (i,j-1) 向右走
~~~

这两类路线不会重复，因此：

~~~text
dp[i][j] = dp[i-1][j] + dp[i][j-1]
~~~

代码中的这一句就是这个公式：

~~~python
dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
~~~

## 五、为什么第一行和第一列都是 1

第一行没有上方，只能一直向右，因此只有 1 条路线。

第一列没有左方，只能一直向下，也只有 1 条路线。

~~~python
for j in range(m + 1):
    dp[0][j] = 1

for i in range(n + 1):
    dp[i][0] = 1
~~~

## 六、样例 n=2、m=2 的计算

初始化后：

~~~text
1 1 1
1 ? ?
1 ? ?
~~~

依次计算：

~~~text
dp[1][1] = 1 + 1 = 2
dp[1][2] = 1 + 2 = 3
dp[2][1] = 2 + 1 = 3
dp[2][2] = 3 + 3 = 6
~~~

最终表格：

~~~text
1 1 1
1 2 3
1 3 6
~~~

所以输出 6。

六条路线可以写成：

~~~text
右右下下
右下右下
右下下右
下右右下
下右下右
下下右右
~~~

## 七、代码逐行解释

~~~python
n, m = map(int, sys.stdin.readline().split())
~~~

读取需要向下走的步数 n 和向右走的步数 m。

~~~python
dp = [[0] * (m + 1) for _ in range(n + 1)]
~~~

创建二维表。行下标表示向下走了多少步，列下标表示向右走了多少步。加 1 是为了包含下标 0。

~~~python
for i in range(1, n + 1):
    for j in range(1, m + 1):
~~~

从左上到右下逐格计算，当前位置需要的上方和左方已经提前算好。

## 八、这是什么类型的题目

这是网格路径计数动态规划题。状态是二维位置，转移是上方方案数加左方方案数。

## 九、复杂度

- 时间复杂度：O(nm)；
- 额外空间复杂度：O(nm)。

## 十、记忆方式

~~~text
dp[i][j]：走到 (i,j) 的方案数
第一行、第一列都是 1
其它位置 = 上方 + 左方
答案 = dp[n][m]
~~~
