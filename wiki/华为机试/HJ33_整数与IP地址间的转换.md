# HJ33 整数与 IP 地址间的转换

## 一、答案

```python
import sys


ip = sys.stdin.readline().strip()
number = int(sys.stdin.readline())

# IP 地址转换成整数
ip_number = 0

for part in map(int, ip.split('.')):
    ip_number = ip_number * 256 + part

print(ip_number)

# 整数转换成 IP 地址
parts = []

for _ in range(4):
    parts.append(str(number % 256))
    number //= 256

# 取余数得到的顺序是从右向左，所以需要反转
print('.'.join(parts[::-1]))
```

## 二、题目翻译成人话

程序会输入两个内容：

1. 第一行输入一个普通 IP 地址，需要把它转换成整数；
2. 第二行输入一个整数，需要把它转换成普通 IP 地址。

例如：

```text
IP 地址：10.0.3.193
转换为：167773121
```

反过来也需要转换：

```text
整数：167969729
转换为：10.3.3.193
```

## 三、为什么可以把 IP 看成“256 进制数”

一个 IP 地址包含四段：

```text
10.0.3.193
```

每段数字的范围都是：

```text
0～255
```

也就是说，每一段一共有 `256` 种可能，所以可以把它看成一个“256 进制数”。

这和十进制数的计算方式非常相似。

例如十进制数字 `1234` 可以这样计算：

```text
((1 × 10 + 2) × 10 + 3) × 10 + 4
```

IP 地址 `10.0.3.193` 则可以这样计算：

```text
((10 × 256 + 0) × 256 + 3) × 256 + 193
```

最终得到：

```text
167773121
```

## 四、IP 转换成整数

首先用点号分开四段数字：

```python
ip.split('.')
```

对于：

```text
10.0.3.193
```

得到：

```python
['10', '0', '3', '193']
```

`map(int, ...)` 把每一段都转换成整数：

```python
map(int, ip.split('.'))
```

然后依次执行：

```python
ip_number = ip_number * 256 + part
```

手算过程如下：

```text
开始：ip_number = 0

读到 10：0 × 256 + 10 = 10
读到 0 ：10 × 256 + 0 = 2560
读到 3 ：2560 × 256 + 3 = 655363
读到 193：655363 × 256 + 193 = 167773121
```

因此输出：

```text
167773121
```

## 五、这和题目中的二进制有什么关系

题目说每一段 IP 都会转换成八位二进制。

八位二进制一共有：

```text
2⁸ = 256
```

种不同的数值。

将一个已经组合好的二进制数向左移动八位，相当于乘以 `2⁸`，也就是乘以 `256`。

因此下面两个过程本质上完全相同：

```text
拼接四段八位二进制
```

和：

```text
不断乘以 256，再加上下一段数字
```

所以代码不需要真的创建二进制字符串。

## 六、整数转换成 IP 地址

把整数转换回 IP，使用的是相反过程：

```python
parts = []

for _ in range(4):
    parts.append(str(number % 256))
    number //= 256
```

这里的两个符号很重要。

### `% 256`

```python
number % 256
```

计算除以 `256` 的余数，可以取出 IP 最右边的一段。

### `// 256`

```python
number //= 256
```

表示：

```python
number = number // 256
```

整除 `256`，去掉刚刚已经取出的最右边一段。

## 七、为什么最后需要反转

除以 `256` 取余数时，先得到的是 IP 最右边的数字。

例如将 `167969729` 转换成 IP，依次取出的结果是：

```text
193、3、3、10
```

但正确的 IP 顺序应该是：

```text
10、3、3、193
```

因此需要使用：

```python
parts[::-1]
```

把列表反转，再使用点号连接：

```python
'.'.join(parts[::-1])
```

最终得到：

```text
10.3.3.193
```

## 八、`for _ in range(4)` 是什么意思

```python
for _ in range(4):
```

表示循环四次，因为 IP 地址固定有四段。

这里不需要使用循环次数，所以变量名写成 `_`。在 Python 中，`_` 通常表示：

```text
这个变量必须存在，但我不会使用它
```

它与普通变量一样，只是一种常见写法。

## 九、为什么必须循环四次

即使最左边的 IP 段是 `0`，也必须保留完整的四段。

例如整数 `1` 对应：

```text
0.0.0.1
```

如果看到 `number` 变成 `0` 就提前停止，只会得到：

```text
1
```

这就不是完整的 IP 地址了。因此代码固定循环四次。

## 十、也可以直接使用二进制吗

可以。例如 IP 转整数可以写成：

```python
binary = ''

for part in map(int, ip.split('.')):
    binary += format(part, '08b')

print(int(binary, 2))
```

其中：

```python
format(part, '08b')
```

表示把数字转换成长度为八位、不足时在左边补 `0` 的二进制字符串。

但是这道题使用乘除 `256` 更短，也不用额外创建二进制字符串。

## 十一、复杂度

IP 地址永远只有四段，所以程序只进行固定次数的计算：

- 时间复杂度：`O(1)`；
- 空间复杂度：`O(1)`。

## 十二、记忆方式

```text
IP 转整数：从左往右，每次乘 256 再加当前段
整数转 IP：从右往左，每次对 256 取余，再整除 256
取出的顺序相反，所以最后需要反转
```
