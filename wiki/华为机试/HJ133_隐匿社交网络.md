# HJ133 隐匿社交网络

## 一、答案

~~~python
import sys

def find(parent, x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

def union(parent, size, a, b):
    root_a = find(parent, a)
    root_b = find(parent, b)
    if root_a == root_b:
        return
    if size[root_a] < size[root_b]:
        root_a, root_b = root_b, root_a
    parent[root_b] = root_a
    size[root_a] += size[root_b]

data = list(map(int, sys.stdin.buffer.read().split()))
index = 0
t = data[index]
index += 1
answers = []

for _ in range(t):
    n = data[index]
    index += 1
    weights = data[index:index + n]
    index += n

    parent = list(range(n))
    size = [1] * n
    owner = [-1] * 61

    for account, weight in enumerate(weights):
        for bit in range(61):
            if (weight >> bit) & 1:
                if owner[bit] == -1:
                    owner[bit] = account
                else:
                    union(parent, size, account, owner[bit])

    largest = 0
    for account in range(n):
        if find(parent, account) == account:
            largest = max(largest, size[account])

    answers.append(str(largest))

print('\\n'.join(answers))
~~~

## 二、题目翻译成人话

每个账号有一个整数权重。两个权重按位与的结果不为 0，就说明它们直接相连。

例如：

~~~text
2  = 010
6  = 110
2&6=010
~~~

结果不是 0，所以 2 和 6 相连。

如果 A 和 B 相连，B 和 C 相连，那么 A、B、C 属于同一个社交网络，即使 A 和 C 没有直接相连。题目要求最大的网络有多少个账号。

## 三、这是什么类型的题目

这是：

~~~text
位运算 + 连通分量 + 并查集
~~~

## 四、为什么不能枚举所有账号对

直接枚举每一对账号，需要平方级别的比较。n 最大为 100000，会超时。

一个权重最多只有 61 个二进制位，因此可以按位处理：如果多个权重的同一位都是 1，就把它们合并到同一个网络。

## 五、按位与如何判断连接

把两个数写成二进制后，同一位置都为 1 时，按位与结果的这一位才为 1。只要至少有一位同时为 1，结果就不为 0。

代码：

~~~python
if (weight >> bit) & 1:
~~~

表示检查 weight 的第 bit 位是不是 1。

## 六、owner 数组的作用

~~~python
owner = [-1] * 61
~~~

owner[bit] 保存“第 bit 位第一次为 1 的账号编号”。

如果后面又遇到一个账号的第 bit 位为 1，就把它和 owner[bit] 合并。这样不需要两两比较账号。

## 七、并查集是什么

并查集用来维护多个集合：

~~~text
find(x)：找到 x 所在集合的代表
union(a,b)：合并 a 和 b 所在的集合
~~~

本题中，一个集合就是一个社交网络。

parent 保存父节点，size 保存每个网络的账号数量。开始时每个账号都是一个大小为 1 的独立网络。

## 八、样例1

权重：

~~~text
2、1、6、7、16
~~~

二进制：

~~~text
2  = 00010
1  = 00001
6  = 00110
7  = 00111
16 = 10000
~~~

2、6、7 的第 1 位都是 1，所以它们属于同一个网络。1 和 7 的第 0 位都是 1，因此 1 也与 7 合并，进入这个网络。16 单独一个网络。

网络大小为 4 和 1，答案是 4。

## 九、样例2

2 和 16 的二进制没有相同位置同时为 1，所以它们不连接。两个网络大小都是 1，答案是 1。

## 十、为什么使用 61 个位

权重不超过 10 的 18 次方，检查 61 位可以覆盖所有输入。多检查一位不会影响答案。

## 十一、复杂度

每个账号检查 61 个二进制位，每次并查集合并接近常数时间：

- 时间复杂度：O(n × 61 × alpha(n))，可以看作 O(n)；
- 额外空间复杂度：O(n)。

## 十二、记忆方式

~~~text
按位与不为0：共享至少一个二进制位
共享同一位的账号进行合并
并查集维护社交网络
最后取最大集合大小
~~~
