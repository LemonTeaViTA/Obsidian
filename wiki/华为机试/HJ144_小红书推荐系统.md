# HJ144 小红书推荐系统

## 一、答案

    import sys
    from collections import Counter

    words = sys.stdin.readline().split()
    counts = Counter(words)

    # 只保留出现次数不少于 3 次的单词
    keywords = []
    for word, count in counts.items():
        if count >= 3:
            keywords.append(word)

    # 次数降序；次数相同时按单词字典序升序
    keywords.sort(key=lambda word: (-counts[word], word))

    # 每个关键词输出一行
    sys.stdout.write("\n".join(keywords))

## 二、题目翻译成人话

输入一整行搜索记录，单词之间用空格分隔。

如果一个单词出现次数不少于 3 次，就把它叫作关键词。最后要输出所有关键词：

1. 出现次数多的排前面；
2. 出现次数相同的，按字典序从小到大排列；
3. 每个关键词单独输出一行。

样例中主要单词的频次是：

    red  出现 5 次
    game 出现 3 次
    kou  出现 3 次

所以输出 red、game、kou。red 出现次数最多排第一；game 和 kou 次数相同，按字典序 game 在前。

## 三、这是什么类型的题目

这是一道“哈希计数 + 自定义排序”题。

整个过程分三步：

    1. 把输入行拆成单词
    2. 统计每个单词出现的次数
    3. 筛选并排序

## 四、为什么使用 split

    words = sys.stdin.readline().split()

输入中单词之间使用空格分隔，split 会按照空白字符拆分字符串。

例如：

    "red game red".split()

结果是：

    ['red', 'game', 'red']

本题不需要保留单词之间的空格，所以使用 split 很合适。

## 五、Counter 是什么

    from collections import Counter
    counts = Counter(words)

Counter 是 Python 标准库中专门用来计数的工具。

例如：

    Counter(['red', 'game', 'red'])

结果相当于：

    {'red': 2, 'game': 1}

如果不用 Counter，也可以手动用字典统计：

    counts = {}
    for word in words:
        counts[word] = counts.get(word, 0) + 1

Counter 只是把这种常见的计数过程封装起来了。

## 六、如何筛选关键词

    keywords = []
    for word, count in counts.items():
        if count >= 3:
            keywords.append(word)

counts.items 会依次得到“单词”和“这个单词的出现次数”。

只有 count >= 3 的单词才加入 keywords。例如：

    counts = {'red': 5, 'game': 3, 'ok': 1}

筛选结果为：

    ['red', 'game']

ok 只出现 1 次，不是关键词。

这段普通写法原来可以压缩成一行列表推导式：

    keywords = [word for word, count in counts.items() if count >= 3]

两种写法完全等价。初学时建议先使用多行写法，因为执行过程更清楚：

    keywords = []                         # 先准备一个空列表
    for word, count in counts.items():    # 逐个取出单词和次数
        if count >= 3:                    # 次数达到3次
            keywords.append(word)         # 把单词加入列表

## 七、排序代码怎么理解

    keywords.sort(key=lambda word: (-counts[word], word))

每个单词的排序依据是一个二元组：

    (-counts[word], word)

例如：

    red  出现5次 -> (-5, 'red')
    game 出现3次 -> (-3, 'game')
    kou  出现3次 -> (-3, 'kou')

Python 默认按升序排序，但题目要求次数大的排前面，因此把次数变成负数。-5 小于 -3，所以 5 次排在 3 次前面。

如果次数相同，就比较第二项单词。字符串默认按字典序升序比较，因此 game 排在 kou 前面。

## 八、输出代码怎么理解

    sys.stdout.write("\n".join(keywords))

假设 keywords 是 ['red', 'game', 'kou']，join 会把它们用换行符连接成：

    red
    game
    kou

然后一次性输出。

也可以写成更直观的形式：

    for word in keywords:
        print(word)

本题数据量不大，这两种写法都可以。

## 九、不使用 Counter 的初学者写法

    import sys

    words = sys.stdin.readline().split()

    counts = {}
    for word in words:
        counts[word] = counts.get(word, 0) + 1

    keywords = []
    for word, count in counts.items():
        if count >= 3:
            keywords.append(word)

    keywords.sort(key=lambda word: (-counts[word], word))

    for word in keywords:
        print(word)

这份代码和答案的逻辑完全一样，只是把计数过程展开写出来了。

## 十、样例解析

样例中：

    red  -> 5
    game -> 3
    kou  -> 3

其它单词出现次数都少于 3 次，会被过滤掉。

排序时，red 先按次数 5 排在前面；game 和 kou 都出现 3 次，再按字典序比较，game < kou。

最终输出：

    red
    game
    kou

## 十一、复杂度

设输入中一共有 L 个单词，不同单词数量为 D：

- 统计次数：平均 O(L)；
- 筛选关键词：O(D)；
- 排序：O(D log D)；
- 总时间复杂度：O(L + D log D)；
- 额外空间复杂度：O(D)。

## 十二、记忆方式

    split 拆成单词
    Counter 或字典统计次数
    次数 >= 3 才是关键词
    按 (-次数, 单词) 排序
    每行输出一个关键词
