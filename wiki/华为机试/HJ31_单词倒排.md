# HJ31 单词倒排

## 一、答案

```python
import sys


s = sys.stdin.readline().rstrip('\n')

# 把所有非字母字符替换为空格
characters = []

for ch in s:
    if ch.isalpha():
        characters.append(ch)
    else:
        characters.append(' ')

# 得到单词列表
words = ''.join(characters).split()

# 将单词顺序反转，并使用单个空格连接
print(' '.join(words[::-1]))
```

## 二、题目翻译成人话

输入一个句子，其中单词只包含大小写字母，但是单词之间不一定使用空格分隔。

所有非字母字符都相当于单词分隔符，例如：

```text
空格、!、#、$、*、1、2
```

题目要求：

1. 找到句子中的所有单词；
2. 只反转单词的顺序；
3. 不反转单词内部的字母；
4. 输出时，所有单词之间统一使用一个空格。

例如：

```text
$bo*y gi!r#l
```

找到的单词是：

```text
bo、y、gi、r、l
```

反转单词顺序后：

```text
l、r、gi、y、bo
```

输出：

```text
l r gi y bo
```

## 三、第一步：读取完整的一行

```python
s = sys.stdin.readline().rstrip('\n')
```

`readline()` 读取完整的一行。

`rstrip('\n')` 只去掉行末由输入产生的换行符。

这道题里也可以直接使用 `strip()`，因为开头或结尾的非字母字符本来就只起分隔作用。但是只删除换行符，更能保留原始输入，含义也更准确。

## 四、第二步：将非字母换成空格

```python
characters = []

for ch in s:
    if ch.isalpha():
        characters.append(ch)
    else:
        characters.append(' ')
```

`ch.isalpha()` 用来判断字符是不是字母：

```python
'A'.isalpha()   # True
'b'.isalpha()   # True
'!'.isalpha()   # False
'1'.isalpha()   # False
' '.isalpha()   # False
```

因此：

- 是字母，就原样保存；
- 不是字母，就替换成空格。

例如：

```text
原字符串：$bo*y gi!r#l
替换后：   bo y gi r l
```

## 五、第三步：分割出所有单词

```python
words = ''.join(characters).split()
```

这句分为两个动作。

### `''.join(characters)`

把字符列表连接成字符串。

例如：

```python
characters = [' ', 'b', 'o', ' ', 'y']
```

连接后得到：

```text
 bo y
```

### `.split()`

不传参数的 `split()` 会按照一个或多个空白字符进行分割，并自动忽略开头和结尾的空格。

例如：

```python
'  bo   y  '.split()
```

结果是：

```python
['bo', 'y']
```

所以即使原字符串中出现多个连续分隔符，也不会产生空单词。

## 六、第四步：反转并输出

```python
print(' '.join(words[::-1]))
```

`words[::-1]` 将列表倒过来。

例如：

```python
words = ['bo', 'y', 'gi', 'r', 'l']
```

反转后：

```python
['l', 'r', 'gi', 'y', 'bo']
```

`' '.join(...)` 使用单个空格连接这些单词，得到：

```text
l r gi y bo
```

## 七、为什么不能一开始直接使用 `s.split()`

直接执行：

```python
s.split()
```

默认只会按照空白字符分割，不能把 `!、#、$、*` 等标点看作分隔符。

例如：

```python
'$bo*y gi!r#l'.split()
```

得到的是：

```python
['$bo*y', 'gi!r#l']
```

这不符合题意。

所以必须先将全部非字母字符转换为空格，然后再使用 `split()`。

## 八、手算示例

输入：

```text
$bo*y gi!r#l
```

### 替换非字母字符

```text
 bo y gi r l
```

### 分割单词

```python
['bo', 'y', 'gi', 'r', 'l']
```

### 反转单词列表

```python
['l', 'r', 'gi', 'y', 'bo']
```

### 使用空格连接

```text
l r gi y bo
```

## 九、与字符串整体反转的区别

不能使用：

```python
s[::-1]
```

因为它会把单词内部的字母也反转。

例如：

```text
Nowcoder Hello
```

字符串整体反转会变成：

```text
olleH redoocwoN
```

题目要求的结果则是：

```text
Hello Nowcoder
```

只改变单词之间的顺序，不改变单词内部的字母顺序。

## 十、复杂度

设输入字符串长度为 `n`：

- 检查和替换每个字符需要 `O(n)`；
- 分割、反转和连接也需要 `O(n)`；
- 总时间复杂度是 `O(n)`；
- 空间复杂度是 `O(n)`。

```text
[::-1] 反转单词列表
join 用一个空格连接
```
