# HJ21 简单密码

## 一、答案

```python
import sys


keypad = {
    "a": "2", "b": "2", "c": "2",
    "d": "3", "e": "3", "f": "3",
    "g": "4", "h": "4", "i": "4",
    "j": "5", "k": "5", "l": "5",
    "m": "6", "n": "6", "o": "6",
    "p": "7", "q": "7", "r": "7", "s": "7",
    "t": "8", "u": "8", "v": "8",
    "w": "9", "x": "9", "y": "9", "z": "9"
}

s = sys.stdin.readline().strip()
result = []

for ch in s:
    if ch.islower():
        result.append(keypad[ch])
    elif ch.isupper():
        next_letter = chr((ord(ch) - ord("A") + 1) % 26 + ord("a"))
        result.append(next_letter)
    else:
        result.append(ch)

print("".join(result))
```

## 二、解题思路

题目要求逐个处理密码中的字符。

每个字符按照类型有三种处理方式：

```text
小写字母：按照九键手机键盘转换成数字；
大写字母：先转小写，再向后移动一位；
数字：保持不变。
```

例如输入：

```text
NowCoder123
```

处理结果：

```text
N -> o
o -> 6
w -> 9
C -> d
o -> 6
d -> 3
e -> 3
r -> 7
1 -> 1
2 -> 2
3 -> 3
```

最终输出：

```text
o69d6337123
```

## 三、小写字母的九键映射

九键手机键盘对应关系是：

| 字母 | 数字 |
| --- | ---: |
| `abc` | `2` |
| `def` | `3` |
| `ghi` | `4` |
| `jkl` | `5` |
| `mno` | `6` |
| `pqrs` | `7` |
| `tuv` | `8` |
| `wxyz` | `9` |

代码使用字典保存映射：

```python
keypad = {
    "a": "2", "b": "2", "c": "2",
    ...
}
```

例如：

```python
keypad["a"]  # "2"
keypad["s"]  # "7"
keypad["z"]  # "9"
```

## 四、大写字母如何向后移动一位

题目规定：

```text
A -> b
B -> c
...
Y -> z
Z -> a
```

先转成小写，再向后移动一位。

### 使用 `ord()` 和 `chr()`

`ord()` 可以把字符转换成编码数字，`chr()` 可以把编码数字转换回字符。

例如：

```python
ord("A")  # 65
chr(98)    # "b"
```

对于大写字母：

```python
next_letter = chr((ord(ch) - ord("A") + 1) % 26 + ord("a"))
```

公式分为几步：

```text
ord(ch) - ord("A")：把 A～Z 转成 0～25；
+ 1：向后移动一位；
% 26：Z 后面循环回 A；
+ ord("a")：转换成小写字母的编码；
chr(...)：把编码转换成字符。
```

例如 `C`：

```text
ord("C") - ord("A") = 2
2 + 1 = 3
3 + ord("a") = ord("d")
```

结果是：

```text
d
```

例如 `Z`：

```text
ord("Z") - ord("A") = 25
25 + 1 = 26
26 % 26 = 0
0 + ord("a") = ord("a")
```

结果是：

```text
a
```

## 五、代码逐行解释

### 1. 读取密码

```python
s = sys.stdin.readline().strip()
```

读取输入的一整行密码，并删除末尾换行符。

例如：

```python
s = "NowCoder123"
```

### 2. 创建结果列表

```python
result = []
```

每处理一个字符，就把转换后的结果放进列表。

最后再使用 `join()` 将它们连接成一个字符串。

### 3. 逐个处理字符

```python
for ch in s:
```

循环会依次取出密码中的每个字符。

例如 `NowCoder123` 会依次得到：

```text
N、o、w、C、o、d、e、r、1、2、3
```

### 4. 处理小写字母

```python
if ch.islower():
    result.append(keypad[ch])
```

`islower()` 判断当前字符是不是小写字母。

如果是，就从九键字典中找到对应数字。

例如：

```python
keypad["o"]  # "6"
```

### 5. 处理大写字母

```python
elif ch.isupper():
    next_letter = chr((ord(ch) - ord("A") + 1) % 26 + ord("a"))
    result.append(next_letter)
```

大写字母不直接查九键，而是先按照循环规则转换成小写字母。

例如：

```text
N -> o
C -> d
Z -> a
```

### 6. 处理数字

```python
else:
    result.append(ch)
```

题目保证输入字符只有大写字母、小写字母和数字。

前面两种情况已经处理了字母，所以这里的 `else` 就表示数字，直接原样加入结果。

### 7. 拼接并输出

```python
print("".join(result))
```

假设结果列表是：

```python
["o", "6", "9", "d", "6", "3", "3", "7", "1", "2", "3"]
```

使用空字符串连接后：

```text
o69d6337123
```

## 八、另一种大写字母写法

也可以先使用 `lower()` 转成小写，再通过字母表下标移动：

```python
import sys


keypad = {
    ch: str(number)
    for letters, number in [
        ("abc", 2), ("def", 3), ("ghi", 4), ("jkl", 5),
        ("mno", 6), ("pqrs", 7), ("tuv", 8), ("wxyz", 9)
    ]
    for ch in letters
}

s = sys.stdin.readline().strip()
result = []

for ch in s:
    if "a" <= ch <= "z":
        result.append(keypad[ch])
    elif "A" <= ch <= "Z":
        index = (ord(ch) - ord("A") + 1) % 26
        result.append(chr(ord("a") + index))
    else:
        result.append(ch)

print("".join(result))
```

主答案把九键映射完整写出来，更容易直接查阅；这个版本使用列表推导式自动生成映射，适合熟悉 Python 以后再看。

## 九、复杂度

设密码长度为 `n`：

- 时间复杂度：`O(n)`，每个字符只处理一次；
- 空间复杂度：`O(n)`，需要保存转换结果。
