# HJ36 字符串加密

## 一、答案

```python
import sys


s = sys.stdin.readline().strip()
t = sys.stdin.readline().strip()

alphabet = 'abcdefghijklmnopqrstuvwxyz'

# 构造新的加密字母表
new_alphabet = []

# 先按照 s 中的出现顺序添加字母，并去掉重复字母
for ch in s:
    if ch not in new_alphabet:
        new_alphabet.append(ch)

# 再补充 s 中没有出现的字母
for ch in alphabet:
    if ch not in new_alphabet:
        new_alphabet.append(ch)

# 加密明文 t
answer = []

for ch in t:
    position = alphabet.index(ch)
    answer.append(new_alphabet[position])

print(''.join(answer))
```

## 二、题目翻译成人话

这道题分为两个步骤：

```text
用第一行字符串制作新字母表
使用新字母表加密第二行字符串
```

普通字母表是：

```text
abcdefghijklmnopqrstuvwxyz
```

假设第一行输入：

```text
trailblazers
```

先去掉重复字母，并且保留字母第一次出现时的顺序，得到：

```text
trailbzes
```

然后按照 `a` 到 `z` 的顺序，补充还没有出现的字母，得到新的加密字母表：

```text
trailbzescdfghjkmnopquvwxy
```

## 三、加密对照表

普通字母表和新字母表的相同位置形成加密关系：

```text
普通字母表：abcdefghijklmnopqrstuvwxyz
新字母表：  trailbzescdfghjkmnopquvwxy
```

所以：

```text
a → t
b → r
c → a
d → i
e → l
……
```

需要加密明文中的每一个字母时：

1. 找到这个字母在普通字母表中的位置；
2. 取出新字母表中相同位置的字母。

## 四、为什么不能直接使用 `set(s)` 去重

题目要求保留每个字母第一次出现时的顺序。

例如：

```text
trailblazers
```

正确的去重结果是：

```text
trailbzes
```

但是普通的集合 `set` 主要用于判断元素是否重复，它不应该被用来表达题目要求的出现顺序：

```python
set(s)
```

因此这里使用循环：

```python
for ch in s:
    if ch not in new_alphabet:
        new_alphabet.append(ch)
```

第一次遇到某个字母时把它添加进去，以后再遇到相同字母就跳过。

## 五、构造新字母表

### 先添加 `s` 中第一次出现的字母

```python
new_alphabet = []

for ch in s:
    if ch not in new_alphabet:
        new_alphabet.append(ch)
```

以 `trailblazers` 为例，变化过程为：

```text
t        → t
r        → tr
a        → tra
i        → trai
l        → trail
b        → trailb
l 重复   → 不添加
a 重复   → 不添加
z        → trailbz
e        → trailbze
r 重复   → 不添加
s        → trailbzes
```

最终得到：

```text
trailbzes
```

### 再补充剩余字母

```python
for ch in alphabet:
    if ch not in new_alphabet:
        new_alphabet.append(ch)
```

按照普通字母表从 `a` 到 `z` 依次检查：

- 已经存在的字母跳过；
- 还不存在的字母添加到末尾。

最后 `new_alphabet` 一定包含全部 26 个小写字母，并且没有重复。

## 六、加密代码是什么意思

```python
answer = []

for ch in t:
    position = alphabet.index(ch)
    answer.append(new_alphabet[position])
```

假设当前需要加密的字母是：

```python
ch = 'a'
```

先找到 `a` 在普通字母表中的位置：

```python
position = alphabet.index('a')
```

得到：

```python
position = 0
```

然后从新字母表中取出相同位置的字母：

```python
new_alphabet[0]
```

得到：

```text
t
```

所以明文 `a` 会被加密成 `t`。

最后：

```python
print(''.join(answer))
```

把加密后的字符列表连接成完整字符串。

## 七、手算示例二

输入：

```text
nihao
ni
```

### 第一步：对 `nihao` 去重

`nihao` 本身没有重复字母，所以得到：

```text
nihao
```

### 第二步：补充剩余字母

新字母表的开头是：

```text
nihao...
```

对照普通字母表：

```text
普通字母表：a b c d e ... i ... n ...
新字母表：  n i h a o ... e ... l ...
```

因此：

```text
n → l
i → e
```

最终输出：

```text
le
```

## 八、容易混淆的地方

### 不是按照明文字母在 `s` 中的位置转换

查找位置时必须使用完整的普通字母表：

```python
position = alphabet.index(ch)
```

不能使用：

```python
s.index(ch)
```

因为加密关系是普通字母表和构造后的新字母表之间的位置对应关系。

### `new_alphabet` 是列表

它的内容类似：

```python
['t', 'r', 'a', 'i', ...]
```

最后要得到字符串时，需要：

```python
''.join(new_alphabet)
```

不过本题只需要从列表中按照下标取字符，所以不用提前连接成字符串。

## 九、复杂度

字母表固定只有 26 个字母，字符串长度最多是 100。

按照通常的复杂度表示：

- 构造字母表和加密都与输入长度成正比；
- 时间复杂度可以看作 `O(len(s) + len(t))`；
- 空间复杂度是 `O(len(t))`，用于保存答案。

## 十、记忆方式

```text
s 去重，保留第一次出现顺序
补上没有出现的 a～z
明文字母在普通字母表找位置
去新字母表的相同位置取密文字母
```
