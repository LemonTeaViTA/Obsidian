# HJ32 密码截取

## 一、答案

```python
import sys


s = sys.stdin.readline().strip()


def expand(s, left, right):
    # 只要左右字符相同，就继续向两边扩大
    while left >= 0 and right < len(s) and s[left] == s[right]:
        left -= 1
        right += 1

    # 循环结束时，left 和 right 已经多走了一步
    return right - left - 1


longest = 1

for center in range(len(s)):
    # 奇数长度：以一个字符为中心，例如 ABA
    odd_length = expand(s, center, center)

    # 偶数长度：以两个字符中间为中心，例如 ABBA
    even_length = expand(s, center, center + 1)

    longest = max(longest, odd_length, even_length)

print(longest)
```

## 二、题目翻译成人话

这道题要从输入字符串中找出一段**连续的字符串**，要求它正着读和倒着读完全相同，并求出最长长度。

这种字符串叫作“回文字符串”。

例如：

```text
A        长度 1
ABA      长度 3
ABBA     长度 4
123321   长度 6
```

注意，截取的字符必须连续。

例如在：

```text
12ABBA34
```

可以连续截取出 `ABBA`，所以最长回文串至少是 `4`。

## 三、使用的方法：从中心向两边扩展

任何一个回文字符串都有中心。

例如 `ABA`：

```text
A B A
  ↑
 中心
```

从中间的 `B` 开始，比较左右两边：

```text
A == A
```

所以 `ABA` 是回文字符串。

再看 `ABBA`：

```text
A B | B A
    ↑
   中心
```

它的中心在两个 `B` 中间。先比较两个 `B`，再比较外面的两个 `A`。

因此，每个位置都要检查两种中心：

```text
奇数长度：中心是一个字符
偶数长度：中心是两个字符之间的位置
```

## 四、`expand` 函数是什么意思

```python
def expand(s, left, right):
```

这个函数接收三个内容：

- `s`：整个字符串；
- `left`：左指针的位置；
- `right`：右指针的位置。

只要左右字符相同，就继续向外扩大：

```python
while left >= 0 and right < len(s) and s[left] == s[right]:
    left -= 1
    right += 1
```

三个条件分别表示：

```text
left >= 0          左指针没有跑出字符串
right < len(s)     右指针没有跑出字符串
s[left] == s[right] 左右字符相同
```

只有三个条件全部成立，才可以继续向两边扩大。

## 五、用 `ABA` 手算奇数长度

字符串及下标是：

```text
字符：A B A
下标：0 1 2
```

以 `B` 为中心调用：

```python
expand(s, 1, 1)
```

第一次比较：

```text
s[1] == s[1]
B == B
```

相同，向两边走：

```text
left = 0
right = 2
```

第二次比较：

```text
s[0] == s[2]
A == A
```

相同，继续向两边走：

```text
left = -1
right = 3
```

这时指针已经越界，循环结束。找到的回文字符串是 `ABA`，长度为 `3`。

## 六、用 `ABBA` 手算偶数长度

字符串及下标是：

```text
字符：A B B A
下标：0 1 2 3
```

中心位于下标 `1` 和 `2` 之间，所以调用：

```python
expand(s, 1, 2)
```

第一次比较：

```text
s[1] == s[2]
B == B
```

相同，向外移动：

```text
left = 0
right = 3
```

第二次比较：

```text
s[0] == s[3]
A == A
```

相同，再向外移动：

```text
left = -1
right = 4
```

循环结束，找到的回文字符串是 `ABBA`，长度为 `4`。

## 七、为什么长度是 `right - left - 1`

```python
return right - left - 1
```

循环结束时，两个指针已经分别多走了一步。

以 `ABBA` 为例，循环结束时：

```text
left = -1
right = 4
```

真正的回文范围是下标 `0` 到 `3`，所以长度是：

```python
right - left - 1
= 4 - (-1) - 1
= 4
```

也可以把它记成：

```text
两个越界位置之间的距离，再减去一个位置
```

## 八、为什么每个中心要检查两次

```python
odd_length = expand(s, center, center)
even_length = expand(s, center, center + 1)
```

### 奇数长度

```python
expand(s, center, center)
```

左右指针从同一个字符出发，适合：

```text
A、ABA、ABCBA
```

### 偶数长度

```python
expand(s, center, center + 1)
```

左右指针从两个相邻字符出发，适合：

```text
AA、ABBA、123321
```

如果只检查其中一种，就会漏掉另一种回文字符串。

## 九、主循环是什么意思

```python
longest = 1

for center in range(len(s)):
    odd_length = expand(s, center, center)
    even_length = expand(s, center, center + 1)
    longest = max(longest, odd_length, even_length)
```

让字符串中的每个位置都尝试成为一次中心。

`longest` 保存目前发现的最长回文长度：

```python
longest = max(longest, odd_length, even_length)
```

它会从三个数中选择最大的一个：

- 以前找到的最长长度；
- 当前中心找到的奇数回文长度；
- 当前中心找到的偶数回文长度。

题目保证字符串至少有一个字符，所以一开始：

```python
longest = 1
```

因为单独一个字符一定是回文字符串。

## 十、手算示例二

输入：

```text
12HHHHA
```

中间四个 `H` 可以组成：

```text
HHHH
```

它是一个偶数长度的回文字符串：

```text
H H | H H
```

从中间两个 `H` 开始向两边扩展，可以得到长度 `4`。

外面的 `2` 和 `A` 不相同，不能继续扩大，因此最终输出：

```text
4
```

## 十一、为什么不能把整个字符串直接反转比较

下面的代码只能判断整个字符串是不是回文：

```python
if s == s[::-1]:
```

但是题目要在整个字符串中截取一段最长的回文字符串。

例如：

```text
12ABBA34
```

整个字符串不是回文，但其中的 `ABBA` 是回文。因此只比较整个字符串会漏掉答案。

## 十二、复杂度

字符串一共有 `n` 个位置，每个位置都尝试向两边扩展：

- 时间复杂度：`O(n²)`；
- 空间复杂度：`O(1)`，不计算输入字符串和少量变量。

本题最多有 `2500` 个字符，这种方法可以满足要求，而且比更复杂的高级算法更容易理解和书写。

## 十三、记忆方式

```text
回文一定有中心
每个位置检查两次
一次查奇数，一次查偶数
左右相同就继续向外走
```
