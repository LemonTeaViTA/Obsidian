# HJ110 宝石手串

## 一、答案

```python
import sys


T = int(sys.stdin.readline())

for _ in range(T):
    n = int(sys.stdin.readline())
    s = sys.stdin.readline().strip()

    # 记录每种属性第一次和最近一次出现的位置
    first_position = {}
    last_position = {}

    # answer 等于 n，表示暂时还没找到两颗相同宝石
    answer = n

    for index, ch in enumerate(s):
        if ch in last_position:
            # 摘掉这两颗相同宝石中间的所有宝石
            removed = index - last_position[ch] - 1
            answer = min(answer, removed)
        else:
            # 这个属性第一次出现
            first_position[ch] = index

        # 更新这个属性最近一次出现的位置
        last_position[ch] = index

    # 手串是环形的，还要计算最后一次出现位置到第一次出现位置
    for ch in first_position:
        if first_position[ch] != last_position[ch]:
            removed = first_position[ch] + n - last_position[ch] - 1
            answer = min(answer, removed)

    if answer == n:
        print(-1)
    else:
        print(answer)
```

## 二、题目翻译成人话

手串是一个环。如果两颗相邻宝石的属性相同，手串就会因为排斥而断开。

每摘掉一颗宝石，它左右两边的宝石会连接起来。因此我们的目标是：

```text
找两颗属性相同的宝石
摘掉它们中间的宝石
让这两颗相同宝石变成相邻宝石
```

题目问最少要摘掉多少颗。

例如：

```text
a b c a
```

因为手串是环形的，最后一个 `a` 和第一个 `a` 本来就相邻，所以不需要摘，答案为 `0`。

如果所有宝石的属性都不相同，就永远不能让两颗相同宝石相邻，因此输出 `-1`。

## 三、这是什么类型的题目

这是一道：

```text
环形数组 + 哈希表记录位置
```

核心不是模拟每一种摘法，而是直接计算两颗相同宝石之间有多少颗宝石。

## 四、两颗相同宝石之间要摘几颗

假设两颗相同宝石的下标分别是 `left` 和 `right`，并且：

```text
left < right
```

它们之间的宝石数量是：

```text
right - left - 1
```

例如：

```text
位置：0 1 2 3 4
属性：a b c d a
```

两个 `a` 的位置是 0 和 4，中间有位置 1、2、3 三颗宝石：

```text
4 - 0 - 1 = 3
```

把这三颗摘掉，两个 `a` 就会相邻。

不过这只是沿字符串从左到右的距离。因为它是环形手串，还要考虑从位置 4 跨过末尾回到位置 0；在这个例子中，它们沿环的另一边本来就相邻，所以实际答案是 0。

## 五、第一次和最近一次位置是什么

代码使用两个字典：

```python
first_position = {}
last_position = {}
```

`first_position[ch]` 记录字符 `ch` 第一次出现的位置。

`last_position[ch]` 记录目前为止字符 `ch` 最近一次出现的位置。

例如遍历：

```text
a b a c a
```

字符 `a` 的出现位置是：

```text
0、2、4
```

它的第一次位置是 0，最后一次位置是 4。遍历过程中，还会依次计算相邻两次出现之间的距离：

```text
位置0和位置2：中间1颗
位置2和位置4：中间1颗
```

## 六、遍历时发生了什么

关键代码：

```python
for index, ch in enumerate(s):
    if ch in last_position:
        removed = index - last_position[ch] - 1
        answer = min(answer, removed)
    else:
        first_position[ch] = index

    last_position[ch] = index
```

每看到一颗宝石：

1. 如果之前见过相同属性，就计算它与上一次相同属性之间隔了几颗；
2. 用 `min` 保留目前最小的摘除数量；
3. 把当前位置更新成这个属性最近出现的位置。

如果第一次见到这个属性，则记录它的第一次位置。

## 七、为什么只和上一次相同属性比较

假设 `a` 出现在位置：

```text
0、3、8
```

从位置 8 向左看：

```text
位置8和位置3之间，比位置8和位置0之间更近
```

因此只要比较相邻的两次出现位置即可。跳过中间同属性宝石去比较更远的位置，不可能需要摘得更少。

## 八、为什么还要计算首尾距离

字符串虽然是从左到右存储的，但手串是环形的：

```text
最后一颗宝石和第一颗宝石相连
```

对于同一种属性，跨过首尾的相邻两次出现是：

```text
这个属性的最后一次出现位置
这个属性的第一次出现位置
```

它们之间要摘除的数量是：

```python
first_position[ch] + n - last_position[ch] - 1
```

例如：

```text
n = 5
字符串 = abcda
第一个 a 在位置0
最后一个 a 在位置4
```

代入公式：

```text
0 + 5 - 4 - 1 = 0
```

说明两个 `a` 在环上本来就相邻，答案是 0。

## 九、为什么没有相同属性就输出 -1

如果一个属性只出现一次，删除其它宝石也不会凭空产生第二颗相同属性的宝石。

如果所有属性都只出现一次，那么即使最后只剩两颗，它们仍然不同，手串不会断开。题目规定这种情况输出 `-1`。

代码开始时：

```python
answer = n
```

正常的摘除数量最多是 `n - 2`，不可能等于 `n`。如果程序结束后 `answer` 仍然是 `n`，说明从未找到两颗相同宝石：

```python
if answer == n:
    print(-1)
```

## 十、样例解析

### 第一组

```text
n = 2
s = ac
```

`a` 和 `c` 都只出现一次。剩下两颗宝石仍然不会断开，因此输出：

```text
-1
```

### 第二组

```text
n = 3
s = aac
```

前两颗宝石都是 `a`，已经相邻：

```text
位置1 - 位置0 - 1 = 0
```

不需要摘宝石，手串已经会断开，所以输出：

```text
0
```

## 十一、再看一个例子

```text
s = abcad
```

两个 `a` 在位置 0 和 3。

沿字符串中间需要摘：

```text
3 - 0 - 1 = 2
```

也就是摘掉 `b、c`。

沿环的另一边只隔着最后的 `d`：

```text
0 + 5 - 3 - 1 = 1
```

只摘掉 `d`，两个 `a` 就会跨过首尾相邻，所以答案是 1。

## 十二、复杂度

每颗宝石只遍历一次。最后最多检查 26 种小写字母：

- 时间复杂度：`O(n)`；
- 额外空间复杂度：`O(1)`，因为只有 26 种小写字母。

所有测试数据的长度之和不超过 `100000`，可以通过。

## 十四、先只理解题目，不看代码

把字符串想象成一条首尾相连的圆环。例如：

```text
a - b - c - a
|           |
└───────────┘
```

这里有 4 颗宝石，属性依次是 `a、b、c、a`。因为首尾相连，第一个 `a` 和最后一个 `a` 已经相邻，它们会互相排斥，手串马上断开，所以不需要摘宝石，答案是 `0`。

再看：

```text
a - b - c - a - d
```

两个 `a` 之间有两条路：

```text
第一条：a - b - c - a，中间有 b、c 两颗
第二条：a - d - a，中间有 d 一颗
```

只需要摘掉 `d`，两个 `a` 就会相邻，所以答案是 `1`，不是 `2`。

这就是本题的本质：

```text
找两颗属性相同的宝石；
看看它们沿环的两条路分别隔着多少颗宝石；
摘掉较短的那一段；
在所有相同属性的宝石对中取最小值。
```

如果所有属性都只出现一次，例如：

```text
a - c
```

就没有两颗相同属性的宝石可以配对。摘掉宝石也不会凭空产生新的属性，因此无法破坏，输出 `-1`。

## 十五、题目中几个词的意思

### 1. 环形

第一颗和最后一颗相连。例如 `abc` 中：

```text
a 和 b 相邻，b 和 c 相邻，c 和 a 也相邻
```

### 2. 摘掉宝石

摘掉宝石后，它左右两边的宝石会连接起来：

```text
a - b - a
```

摘掉 `b` 后变成：

```text
a - a
```

两个相同的 `a` 相邻，手串断开，操作次数为 `1`。

### 3. 最少摘掉多少个

如果有多种方法，选择摘除数量最少的那一种。相同宝石已经相邻时，答案就是 `0`。

### 4. 为什么剩下两个仍未断开要输出 -1

如果只剩两颗宝石且属性不同，手串仍然不会断。此时也没有第二颗相同属性的宝石可以配对，所以题目规定输出 `-1`。
## 十六、最直观的解法：先保存每种字母的位置

如果一开始觉得“第一次位置、上一次位置”比较绕，可以先把每种字母出现的所有位置保存下来。

```python
import sys

data = sys.stdin.read().split()
t = int(data[0])
index = 1
answers = []

for _ in range(t):
    n = int(data[index])
    index += 1
    s = data[index]
    index += 1

    positions = {}

    # positions[ch] 保存字符 ch 出现过的下标
    for i, ch in enumerate(s):
        if ch not in positions:
            positions[ch] = []
        positions[ch].append(i)

    answer = n

    # 逐种字符检查相邻出现位置之间的距离
    for pos_list in positions.values():
        if len(pos_list) < 2:
            continue

        # 字符串内部的间隔
        for j in range(1, len(pos_list)):
            removed = pos_list[j] - pos_list[j - 1] - 1
            answer = min(answer, removed)

        # 跨过字符串末尾和开头的环形间隔
        removed = pos_list[0] + n - pos_list[-1] - 1
        answer = min(answer, removed)

    if answer == n:
        answers.append('-1')
    else:
        answers.append(str(answer))

print('\n'.join(answers))
```

这份代码和前面的单次遍历代码得到的结果相同，只是把每种字母的所有位置明确保存下来，更适合第一次理解。

例如 `s = abaca` 时：

```text
位置：0 1 2 3 4
字符：a b a c a
```

`a` 的位置列表是 `[0, 2, 4]`。

检查内部间隔：

```text
0 和 2：2 - 0 - 1 = 1
2 和 4：4 - 2 - 1 = 1
```

检查跨首尾的间隔：

```text
0 + 5 - 4 - 1 = 0
```

所以第一个和最后一个 `a` 在环上已经相邻，答案是 `0`。
