# HJ103 Redraiment 的走法

## 一、答案

```python
import sys

n = int(sys.stdin.readline())
heights = list(map(int, sys.stdin.readline().split()))

# dp[i] 表示以第 i 根梅花桩作为最后一根时，最多经过多少根桩
dp = [1] * n

for i in range(n):
    for j in range(i):
        # 只能从前面较矮的梅花桩跳到当前梅花桩
        if heights[j] < heights[i]:
            dp[i] = max(dp[i], dp[j] + 1)

print(max(dp))
```

## 二、题目翻译成人话

有一排梅花桩，每根桩有一个高度。Redraiment 可以任选一根桩开始，只能向后跳，并且下一根桩必须比当前桩高。求最多能经过多少根桩。

例如：

```text
2 5 1 5 4 5
```

可以选择路线：

```text
2 -> 4 -> 5
```

高度严格变大，而且位置一直向后，所以一共经过 3 根桩。

题目要统计的是经过的桩子数量，包含起点。经过 3 根桩，实际跳跃次数是 2 次。

## 三、这是什么类型的题目

这题属于“动态规划”和“最长严格递增子序列”。

所谓递增子序列，就是从原数组中按原来的前后顺序挑出一些数，并且挑出的数越来越大。这里挑出的数就对应经过的梅花桩。

## 四、`dp[i]` 表示什么

```python
dp = [1] * n
```

`dp[i]` 表示：以第 `i` 根梅花桩作为最后一根桩时，最多能经过多少根桩。

每一根桩都可以自己作为起点，所以最少经过 1 根桩，初始值全部设为 1。

## 五、状态转移

计算第 `i` 根桩时，检查它前面的每一根桩 `j`。

如果：

```python
heights[j] < heights[i]
```

就可以从第 `j` 根桩跳到第 `i` 根桩。如果到第 `j` 根桩时最多经过 `dp[j]` 根，那么加上当前桩后就是：

```python
dp[j] + 1
```

所以更新：

```python
dp[i] = max(dp[i], dp[j] + 1)
```

意思是在所有可以跳到 `i` 的路线中，保留最长的那一条。

## 六、为什么要检查所有前面的桩

Redraiment 可以跳到后面任意一根更高的桩，不要求必须跳到相邻的桩。

例如：

```text
2 1 3
```

虽然 2 后面紧挨着的是 1，不能跳，但可以跳过 1，直接从 2 跳到 3。因此内层循环要检查当前位置前面的所有桩。

```python
for i in range(n):
    for j in range(i):
```

`j < i` 保证第 `j` 根桩在第 `i` 根桩前面，符合“只能向后跳”。

## 七、样例计算

高度：

```text
2 5 1 5 4 5
```

动态规划结果为：

```text
dp = [1, 2, 1, 2, 2, 3]
```

最后一个 `3` 对应路线 `2 -> 4 -> 5`。因此：

```python
max(dp) = 3
```

输出 `3`。

## 八、为什么输出 `max(dp)`

`dp[i]` 是以第 `i` 根桩结束的最长路线。最长路线不一定结束在最后一根桩，所以不能只输出 `dp[n - 1]`，而要在所有位置中取最大值：

```python
print(max(dp))
```

## 九、一个简单例子

数组：

```text
1 2 3
```

计算得到：

```text
dp[0] = 1       # 1
dp[1] = 2       # 1 -> 2
dp[2] = 3       # 1 -> 2 -> 3
```

答案是 3。

如果数组是：

```text
1 2 3 1
```

最长路线仍然是 `1 -> 2 -> 3`，长度为 3，最后的 1 不能接在后面。因此必须使用 `max(dp)`。

## 十、输入代码解释

```python
n = int(sys.stdin.readline())
heights = list(map(int, sys.stdin.readline().split()))
```

第一句读取梅花桩数量；第二句读取所有高度，并把它们转换成整数列表。

`range(i)` 会产生 `0` 到 `i - 1`，所以：

```python
for j in range(i):
```

正好遍历当前桩前面的所有位置。

## 十一、复杂度

- 时间复杂度：`O(n²)`；
- 额外空间复杂度：`O(n)`。

题目限制 `n ≤ 200`，所以双重循环完全可以通过。

## 十二、记忆方式

```text
dp[i]：以第 i 根桩结尾的最长递增路线
遍历 i 前面的 j
如果 heights[j] < heights[i]：
    dp[i] = max(dp[i], dp[j] + 1)
最后输出 max(dp)
```

## 十三、这题是贪心还是动态规划

上面的代码使用的是动态规划，不是贪心。

### 贪心是什么

贪心的想法是：

> 每一步都选择当前看起来最好的方案，并且选择后通常不再改变。

例如，假设规定“每次都跳到后面最高的梅花桩”，数组为：

```text
1 5 2 3 4 6
```

从 `1` 开始时，后面最高的是 `5`，再跳到 `6`，只能经过：

```text
1 -> 5 -> 6
```

一共 3 根桩。

但更好的选择是：

```text
1 -> 2 -> 3 -> 4 -> 6
```

一共 5 根桩。

这说明“当前看起来最高”不一定能得到全局最优答案。

### 这段代码为什么是动态规划

代码不会只保留一条当前路线，而是给每个位置都记录一个结果：

```python
dp[i]
```

它表示“以第 `i` 根桩结束时的最长路线”。计算第 `i` 根桩时，会检查前面的所有位置：

```python
for j in range(i):
    if heights[j] < heights[i]:
        dp[i] = max(dp[i], dp[j] + 1)
```

也就是说，它会把所有可能的前一步都考虑一遍，再选择其中结果最大的。这是动态规划的典型特点：

```text
把大问题拆成很多小问题
保存小问题的最优结果
利用已经保存的结果计算更大的问题
```

### 这道题能不能用更快的贪心思想

最长递增子序列确实存在 `O(n log n)` 的“贪心 + 二分查找”做法，但它需要维护一个 `tails` 数组，含义比本题的 `dp` 更绕。题目 `n ≤ 200`，所以当前 `O(n²)` 的动态规划已经足够，先掌握这种写法更合适。

简单记忆：

```text
当前代码：动态规划，尝试所有前面的可能位置
贪心：每一步只选一个当前方案，通常不回头

## 十四、按照程序实际运行一遍

使用样例：

```text
高度：2 5 1 5 4 5
位置：0 1 2 3 4 5
```

这里使用的是 Python 下标，从 0 开始；题目中的编号从 1 开始，只是编号方式不同。

### 1. 初始化

```python
dp = [1] * 6
```

得到：

```text
dp = [1, 1, 1, 1, 1, 1]
```

每根桩都可以自己作为起点，所以至少经过 1 根桩。

### 2. 计算位置 0，高度 2

前面没有梅花桩，因此不能跳过来：

```text
dp[0] = 1
```

### 3. 计算位置 1，高度 5

前面只有位置 0，高度 2 小于 5，可以跳：

```text
dp[1] = max(dp[1], dp[0] + 1)
       = max(1, 1 + 1)
       = 2
```

路线是 `2 -> 5`，所以目前：

```text
dp = [1, 2, 1, 1, 1, 1]
```

### 4. 计算位置 2，高度 1

前面的高度是 2 和 5，都不小于 1，因此没有桩可以跳到高度 1：

```text
dp[2] = 1
```

### 5. 计算位置 3，高度 5

检查前面的位置：

```text
2 < 5，可以跳，得到 dp[0] + 1 = 2
5 < 5，不成立，高度相同不能跳
1 < 5，可以跳，得到 dp[2] + 1 = 2
```

因此：

```text
dp[3] = 2
```

### 6. 计算位置 4，高度 4

前面只有高度 2 和 1 比 4 矮：

```text
dp[0] + 1 = 2
dp[2] + 1 = 2
```

所以：

```text
dp[4] = 2
```

### 7. 计算位置 5，高度 5

检查前面所有位置：

```text
从位置0来：dp[0] + 1 = 2
从位置1来：5 < 5 不成立
从位置2来：dp[2] + 1 = 2
从位置3来：5 < 5 不成立
从位置4来：dp[4] + 1 = 2 + 1 = 3
```

最大值是 3，因此：

```text
dp[5] = 3
```

对应路线是 `2 -> 4 -> 5`。

### 8. 得到最终答案

最终 `dp` 数组为：

```text
[1, 2, 1, 2, 2, 3]
```

最长路线可能结束在任意位置，所以取最大值：

```python
max(dp) = 3
```

最终输出 `3`。

## 十五、把代码翻译成中文

```python
for i in range(n):
    for j in range(i):
        if heights[j] < heights[i]:
            dp[i] = max(dp[i], dp[j] + 1)
```

可以理解为：

```text
选定当前要到达的第 i 根桩
查看它前面的每一根桩 j
如果 j 比 i 矮，就尝试从 j 跳到 i
比较原来的路线和经过 j 再到 i 的路线
保留更长的路线
```

这里 `dp[j] + 1` 表示“到达第 j 根桩时经过的桩数，再加上当前第 i 根桩”，不是跳跃次数。
