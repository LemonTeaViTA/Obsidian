# HJ96 表示数字

## 一、答案

~~~python
import sys

s = sys.stdin.readline().strip()
answer = []

for i, ch in enumerate(s):
    if ch.isdigit():
        # 当前数字是数字子串的开头
        if i == 0 or not s[i - 1].isdigit():
            answer.append('*')

        answer.append(ch)

        # 当前数字是数字子串的结尾
        if i == len(s) - 1 or not s[i + 1].isdigit():
            answer.append('*')
    else:
        answer.append(ch)

print(''.join(answer))
~~~

## 二、题目翻译成人话

找出字符串中每一段连续的数字，并在数字段前后各加一个星号。其它字母保持不变。

例如：

~~~text
Jkdi234klowe90a3
~~~

数字段是 `234`、`90`、`3`，所以结果是：

~~~text
Jkdi*234*klowe*90*a*3*
~~~

## 三、什么叫连续数字子串

`123` 是一整段连续数字，不是三个独立数字；`45` 是另一段数字。

例如：

~~~text
abc123def45x6
~~~

输出：

~~~text
abc*123*def*45*x*6*
~~~

## 四、如何判断数字段的开头

当前字符是数字，并且：

- 它是第一个字符；或者
- 它前面的字符不是数字。

代码：

~~~python
if i == 0 or not s[i - 1].isdigit():
    answer.append('*')
~~~

例如 `a234` 中的 `2`，前面是字母 `a`，所以它是数字段开头，要先加 `*`。

## 五、如何判断数字段的结尾

当前字符是数字，并且：

- 它是最后一个字符；或者
- 它后面的字符不是数字。

代码：

~~~python
if i == len(s) - 1 or not s[i + 1].isdigit():
    answer.append('*')
~~~

例如 `234b` 中的 `4`，后面是字母 `b`，所以它是数字段结尾，要在后面加 `*`。

## 六、`enumerate` 是什么

~~~python
for i, ch in enumerate(s):
~~~

`i` 是当前字符下标，`ch` 是当前字符。

例如字符串 `a12b`：

~~~text
i=0, ch='a'
i=1, ch='1'
i=2, ch='2'
i=3, ch='b'
~~~

有了下标 `i`，才能检查前一个字符 `s[i - 1]` 和后一个字符 `s[i + 1]`。

## 七、为什么连续数字中间不加星号

输入：

~~~text
234
~~~

处理 `2` 时，它是开头，加前面的 `*`；处理 `3` 时，前面是数字，不是开头；处理 `4` 时，它是结尾，加后面的 `*`。

最终只有：

~~~text
*234*
~~~

## 八、`answer` 列表和 `join`

~~~python
answer = []
~~~

依次保存最终输出的字符和星号。最后：

~~~python
''.join(answer)
~~~

把列表连接成一个字符串。

例如：

~~~python
['a', '*', '1', '2', '*']
~~~

连接后是：

~~~text
a*12*
~~~

## 九、边界情况

字符串开头是数字：

~~~text
123abc → *123*abc
~~~

字符串结尾是数字：

~~~text
abc123 → abc*123*
~~~

全部是数字：

~~~text
12345 → *12345*
~~~

## 十、复杂度

每个字符只遍历一次：

- 时间复杂度：`O(n)`；
- 空间复杂度：`O(n)`，用于保存结果。

## 十一、记忆方式

~~~text
数字段开始：前面没有数字，加 *
数字段结束：后面没有数字，加 *
字母原样保留
最后 join
~~~
