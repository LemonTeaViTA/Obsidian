# HJ40 统计字符

## 一、答案

```python
import sys


s = sys.stdin.readline().rstrip('\n')

letter_count = 0
space_count = 0
digit_count = 0
other_count = 0

for ch in s:
    if ch.isalpha():
        letter_count += 1
    elif ch == ' ':
        space_count += 1
    elif ch.isdigit():
        digit_count += 1
    else:
        other_count += 1

print(letter_count)
print(space_count)
print(digit_count)
print(other_count)
```

## 二、题目翻译成人话

把字符串中的每个字符分成四类并统计数量：

```text
1. 英文字母
2. 空格
3. 数字
4. 其它字符
```

例如：

```text
a 1 !
```

其中：

```text
字母：a        1 个
空格：两个空格 2 个
数字：1        1 个
其它：!        1 个
```

## 三、为什么要使用 `readline()` 而不是 `split()`

输入中包含空格，空格本身需要被统计，所以要读取整行：

```python
s = sys.stdin.readline().rstrip('\n')
```

不能使用：

```python
s = sys.stdin.readline().split()
```

因为 `split()` 会按照空格切分字符串，并且不会保留这些空格，导致空格数量无法统计。

`rstrip('\n')` 只删除输入行末的换行符，不会删除字符串中间或两端的普通空格。

## 四、逐个字符分类

```python
for ch in s:
```

表示从左到右依次取出字符串中的每个字符。

### 判断字母

```python
if ch.isalpha():
    letter_count += 1
```

`isalpha()` 用来判断字符是否是字母：

```python
'A'.isalpha()  # True
'z'.isalpha()  # True
'1'.isalpha()  # False
'!'.isalpha()  # False
```

### 判断空格

```python
elif ch == ' ':
    space_count += 1
```

普通空格的写法是：

```python
' '
```

注意它和空字符串 `''` 不一样：

```text
' '  表示一个空格
''   表示没有字符
```

### 判断数字

```python
elif ch.isdigit():
    digit_count += 1
```

`isdigit()` 用来判断字符是否是数字：

```python
'0'.isdigit()  # True
'9'.isdigit()  # True
'a'.isdigit()  # False
```

### 其它字符

```python
else:
    other_count += 1
```

题目中的字符都是 ASCII 码 `32` 到 `126` 的可见字符，所以前面三类都不是时，剩下的就是标点符号等其它字符，例如：

```text
! @ # $ % & *
```

## 五、为什么使用 `elif`

```python
if ch.isalpha():
    ...
elif ch == ' ':
    ...
elif ch.isdigit():
    ...
else:
    ...
```

`if / elif / else` 只会执行其中一个分支。

每个字符只能属于四类中的一类，因此这样写正好：

```text
是字母就统计字母
否则如果是空格就统计空格
否则如果是数字就统计数字
否则统计其它
```

## 六、手算示例

假设输入：

```text
Ab 3!
```

逐个字符统计：

| 字符 | 类型 | 统计结果 |
| :---: | --- | --- |
| `A` | 字母 | 字母 `1` |
| `b` | 字母 | 字母 `2` |
| 空格 | 空格 | 空格 `1` |
| `3` | 数字 | 数字 `1` |
| `!` | 其它 | 其它 `1` |

最终输出：

```text
2
1
1
1
```

## 七、计数器为什么一开始是 0

```python
letter_count = 0
space_count = 0
digit_count = 0
other_count = 0
```

开始还没有检查任何字符，因此四类数量都是 `0`。

每遇到一个对应类型的字符，就加一：

```python
letter_count += 1
```

这等价于：

```python
letter_count = letter_count + 1
```

## 八、输出顺序

题目要求输出顺序固定为：

```text
字母数量
空格数量
数字数量
其它字符数量
```

因此代码也必须按照这个顺序输出：

```python
print(letter_count)
print(space_count)
print(digit_count)
print(other_count)
```

## 九、复杂度

设字符串长度为 `n`：

- 每个字符只检查一次；
- 时间复杂度：`O(n)`；
- 除输入字符串外只使用四个计数器，额外空间复杂度：`O(1)`。
