# HJ85 最长回文子串

## 一、答案

~~~python
import sys


s = sys.stdin.readline().strip()


def expand(left, right):
    # 从中心向左右扩展
    while left >= 0 and right < len(s) and s[left] == s[right]:
        left -= 1
        right += 1

    # 循环结束时左右指针各多走了一步
    return right - left - 1


longest = 1

for center in range(len(s)):
    # 奇数长度回文，例如 aba
    odd_length = expand(center, center)

    # 偶数长度回文，例如 abba
    even_length = expand(center, center + 1)

    longest = max(longest, odd_length, even_length)

print(longest)
~~~

## 二、题目翻译成人话

从字符串中截取一段连续的字符，要求这段字符正着读和倒着读完全一样，求最长长度。

这样的字符串叫回文串：

~~~text
a、aba、abba、123321
~~~

例如：

~~~text
cdabbacc
~~~

其中 `abba` 是回文串，长度为 4，所以答案是 4。

## 三、这是什么类型的题目

这是一道：

~~~text
字符串 + 回文判断 + 中心扩展
~~~

回文串一定有中心，可以从中心向左右两边检查。

## 四、奇数长度和偶数长度

### 奇数长度

例如 `aba`：

~~~text
a b a
  ↑
 中心是一个字符
~~~

中心是中间的 `b`，调用：

~~~python
expand(center, center)
~~~

其它例子：

~~~text
a、aba、abcba
~~~

### 偶数长度

例如 `abba`：

~~~text
a b | b a
    ↑
  中心在两个字符之间
~~~

中心在两个 `b` 之间，调用：

~~~python
expand(center, center + 1)
~~~

其它例子：

~~~text
aa、abba、123321
~~~

如果只检查一种中心，就会漏掉另一种回文串。

## 五、`expand` 函数是什么意思

~~~python
def expand(left, right):
~~~

它接收左右两个下标，从这两个位置开始向两边扩展。

只要满足：

1. 左指针没有越界；
2. 右指针没有越界；
3. 左右字符相同；

就继续向外走：

~~~python
while left >= 0 and right < len(s) and s[left] == s[right]:
    left -= 1
    right += 1
~~~

## 六、`ABA` 的扩展过程

字符串：

~~~text
字符：A B A
下标：0 1 2
~~~

从中心 `B` 开始：

~~~python
expand(1, 1)
~~~

第一次比较中心字符，`B == B`，然后左右移动：

~~~text
left = 0，right = 2
~~~

比较 `A == A`，继续移动：

~~~text
left = -1，right = 3
~~~

越界后结束，得到长度：

~~~text
3
~~~

## 七、`ABBA` 的扩展过程

字符串：

~~~text
字符：A B B A
下标：0 1 2 3
~~~

从两个 B 中间开始：

~~~python
expand(1, 2)
~~~

比较：

~~~text
B == B，继续向外
A == A，继续向外
~~~

得到长度：

~~~text
4
~~~

## 八、为什么返回 `right - left - 1`

循环结束时，指针已经多走了一步。

以 `ABBA` 为例，结束时：

~~~text
left = -1，right = 4
~~~

真正的回文范围是下标 0 到 3，长度为：

~~~text
right - left - 1 = 4 - (-1) - 1 = 4
~~~

## 九、主循环是什么意思

~~~python
for center in range(len(s)):
~~~

让每个字符都尝试作为回文中心。

当前中心同时检查两种情况：

~~~python
odd_length = expand(center, center)
even_length = expand(center, center + 1)
~~~

保存目前最大的结果：

~~~python
longest = max(longest, odd_length, even_length)
~~~

`max` 会从三个数字中选出最大的：之前的最长值、当前奇数回文长度、当前偶数回文长度。

## 十、官方示例

输入：

~~~text
cdabbacc
~~~

可能找到的回文串有：

~~~text
d、a、b、bb、abba、cc
~~~

其中最长的是 `abba`，长度 4，因此输出：

~~~text
4
~~~

## 十一、为什么不能只判断整个字符串

下面的代码：

~~~python
if s == s[::-1]:
~~~

只能判断整个字符串是不是回文，不能找出其中最长的回文子串。

例如 `xxabba` 整体不是回文，但其中有 `abba`。

## 十二、为什么不能使用 `split`

回文子串不一定是完整单词，也不一定被空格分开。

例如：

~~~text
cdabbacc
~~~

`abba` 就是中间截取出来的连续子串，所以要按字符下标检查，不能按单词分割。

## 十三、复杂度

字符串长度为 `n`：

- 一共有 `n` 个奇数中心和 `n` 个偶数中心；
- 每次扩展最坏需要 `O(n)`；
- 总时间复杂度：`O(n²)`；
- 额外空间复杂度：`O(1)`。

题目中 n <= 350，完全可以通过。

## 十四、和 HJ32 的关系

HJ32 密码截取和 HJ85 最长回文子串本质相同，都是求最长回文子串。

两道题都可以使用同一个中心扩展模板：

~~~text
每个位置检查奇数中心和偶数中心
左右相同就继续扩展
记录最大长度
~~~

## 十五、记忆方式

~~~text
回文一定有中心
一个字符中心：奇数回文
两个字符之间中心：偶数回文
左右相等就扩展
记录最大长度
~~~
