# HJ9 提取不重复的整数

## 一、答案

```python
import sys


s = sys.stdin.readline().strip()
seen = set()
result = []

for digit in s[::-1]:
    if digit not in seen:
        seen.add(digit)
        result.append(digit)

print("".join(result))
```

## 二、解题思路

题目要求按照从右向左的顺序读取数字，并且相同数字只保留第一次遇到的那个。

例如：

```text
9876673
```

从右向左读取：

```text
3、7、6、6、7、8、9
```

遇到重复数字时跳过：

```text
3：第一次出现，保留
7：第一次出现，保留
6：第一次出现，保留
6：已经出现，跳过
7：已经出现，跳过
8：第一次出现，保留
9：第一次出现，保留
```

最终得到：

```text
37689
```

程序需要使用两种数据结构：

- `set` 集合：记录某个数字以前是否出现过；
- `list` 列表：按照正确顺序保存结果。

## 三、为什么不能只使用集合

集合可以去重，但集合不是用来保存题目要求的输出顺序的。

例如：

```python
set("3766789")
```

可以得到不重复的字符，但不应该依赖集合的遍历顺序来产生：

```text
37689
```

所以本题中：

```text
seen 只负责判断是否重复；
result 负责按从右到左的顺序保存答案。
```

## 四、代码逐行解释

### 1. 把输入当作字符串读取

```python
s = sys.stdin.readline().strip()
```

虽然题目输入的是整数，但我们只需要逐个处理其中的数字字符，所以直接当作字符串更方便。

例如输入：

```text
9876673
```

读取后：

```python
s = "9876673"
```

这样可以直接使用 `for` 循环遍历每一位数字。

### 2. 创建集合和结果列表

```python
seen = set()
result = []
```

`seen` 用来保存已经遇到过的数字。

`result` 用来按照读取顺序保存第一次出现的数字。

初始时：

```python
seen = set()
result = []
```

都为空。

### 3. 从右向左遍历

```python
for digit in s[::-1]:
```

`s[::-1]` 表示将字符串反转。

切片的一般写法是：

```python
s[开始位置:结束位置:步长]
```

这里开始位置和结束位置都省略，步长是 `-1`，表示从后向前每次移动一位。

例如：

```python
"9876673"[::-1]
```

得到：

```python
"3766789"
```

所以循环会依次得到：

```text
3、7、6、6、7、8、9
```

### 4. 判断数字是否出现过

```python
if digit not in seen:
```

如果当前数字不在 `seen` 集合中，说明这是从右向左第一次遇到它，应该保留。

如果已经在集合中，说明它重复了，不执行下面的代码，相当于跳过。

### 5. 记录第一次出现的数字

```python
seen.add(digit)
result.append(digit)
```

```python
seen.add(digit)
```

把数字放进集合，表示以后再遇到它时需要跳过。

```python
result.append(digit)
```

把数字追加到结果列表末尾，保存正确的输出顺序。

### 6. 把结果连接成一个整数形式

```python
print("".join(result))
```

假设结果列表是：

```python
["3", "7", "6", "8", "9"]
```

```python
"".join(result)
```

使用空字符串把它们连接起来，得到：

```python
"37689"
```

然后使用 `print()` 输出：

```text
37689
```

虽然这里输出的是字符串形式，但显示效果和输出整数完全相同。题目只判断输出内容，所以可以直接这样输出。

## 五、示例完整执行过程

输入：

```text
9876673
```

反转后：

```text
3766789
```

处理过程：

| 当前数字 | 是否出现过 | 操作 | `result` |
| --- | --- | --- | --- |
| `3` | 否 | 保留 | `3` |
| `7` | 否 | 保留 | `37` |
| `6` | 否 | 保留 | `376` |
| `6` | 是 | 跳过 | `376` |
| `7` | 是 | 跳过 | `376` |
| `8` | 否 | 保留 | `3768` |
| `9` | 否 | 保留 | `37689` |

最终输出：

```text
37689
```

## 六、几个特殊情况

### 所有数字都不重复

输入：

```text
12345
```

从右向左读取后没有重复数字，输出：

```text
54321
```

### 所有数字都相同

输入：

```text
1111
```

第一个 `1` 被保留，其他 `1` 都被跳过，输出：

```text
1
```

### 数字中间包含 `0`

输入：

```text
1020301
```

从右向左读取：

```text
1、0、3、0、2、0、1
```

去重后：

```text
1、0、3、2
```

输出：

```text
1032
```

题目保证原数最后一位不为 `0`，所以反转后的结果不会以 `0` 开头。

## 七、也可以使用数字运算

还可以通过 `% 10` 每次取得最右边的数字：

```python
import sys


n = int(sys.stdin.readline())
seen = set()
answer = 0

while n > 0:
    digit = n % 10
    n //= 10

    if digit not in seen:
        seen.add(digit)
        answer = answer * 10 + digit

print(answer)
```

其中：

```python
n % 10
```

取得最右边的一位数字。

```python
n //= 10
```

删除最右边的一位数字。

字符串版本更容易观察“从右向左遍历”的过程，所以主答案使用字符串版本。

## 八、复杂度

设输入数字共有 `n` 位：

- 时间复杂度：`O(n)`，每位数字只检查一次；
- 空间复杂度：`O(1)`，十进制数字最多只有 `10` 种，集合和结果最多保存 `10` 个字符。

## 九、记忆方式

```text
s[::-1] 从右向左读取；
seen 记录数字是否出现过；
第一次出现就加入 result；
"".join(result) 拼接输出。
```
