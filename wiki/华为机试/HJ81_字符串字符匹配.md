# HJ81 字符串字符匹配

## 一、答案

```python
import sys


s = sys.stdin.readline().strip()
t = sys.stdin.readline().strip()

# set(t) 中保存 t 里出现过的不同字符
t_chars = set(t)

# s 中的每个字符都能在 t_chars 中找到，才输出 true
if all(ch in t_chars for ch in s):
    print("true")
else:
    print("false")
```

## 二、题目翻译成人话

题目给出两个字符串 `s` 和 `t`，要求检查：

> `s` 里的每一种字符，是否都曾经在 `t` 里出现过？

如果全部都出现过，输出 `true`；只要有一个字符没有在 `t` 中出现，就输出 `false`。

这里比较的是“是否出现过”，不是出现次数。

例如：

```text
s = "bc"
t = "abc"
```

`s` 中有 `b`、`c`，它们都在 `t` 中，所以输出 `true`。

再例如：

```text
s = "ab"
t = "ac"
```

`a` 在 `t` 中，但 `b` 不在 `t` 中，所以输出 `false`。

## 三、`set` 是什么

`set` 表示集合，它有两个重要特点：

1. 同一个元素只保留一份，会自动去重；
2. 使用 `in` 检查元素是否存在很方便。

例如：

```python
set("abca")
```

结果相当于：

```text
{'a', 'b', 'c'}
```

虽然字符串中有两个 `a`，集合里只保留一个 `a`。但本题不关心重复次数，因此正好适用。

代码：

```python
t_chars = set(t)
```

就是把 `t` 中出现过的字符整理成一个“字符集合”。

## 四、`ch in t_chars` 是什么意思

```python
ch in t_chars
```

表示检查字符 `ch` 是否存在于集合 `t_chars` 中。

例如：

```python
t_chars = {'a', 'b', 'c'}

'a' in t_chars  # True
'd' in t_chars  # False
```

因此，对于 `s = "bc"`，程序实际会检查：

```text
'b' 是否在 t_chars 中？
'c' 是否在 t_chars 中？
```

## 五、`all(...)` 是什么意思

`all` 可以理解为“所有”。

```python
all([True, True, True])   # True
all([True, False, True])  # False
```

只要列表中有一个 `False`，`all` 的结果就是 `False`；只有全部为 `True` 时，结果才是 `True`。

下面这句：

```python
all(ch in t_chars for ch in s)
```

可以展开理解成：

```python
result = True
for ch in s:
    if ch not in t_chars:
        result = False
        break
```

也就是说，它会逐个检查 `s` 中的字符，只要发现一个字符不在 `t` 中，就可以判定答案为 `false`。

如果你还不熟悉 `all`，也可以使用下面这种更直观的写法：

```python
import sys


s = sys.stdin.readline().strip()
t = sys.stdin.readline().strip()

t_chars = set(t)
answer = True

for ch in s:
    if ch not in t_chars:
        answer = False
        break

print("true" if answer else "false")
```

这两个程序的效果完全相同，第二种更适合刚开始学习的情况。

## 六、为什么不比较出现次数

题目说的是：`s` 中的所有字符是否都在 `t` 中出现。

它没有说 `s` 中某个字符出现几次，`t` 中就必须出现几次。因此：

```text
s = "aa"
t = "a"
```

仍然输出：

```text
true
```

因为 `s` 中的字符只有 `a` 这一种，而 `a` 确实在 `t` 中出现过。

如果题目要求比较次数，才需要使用字典统计频率；本题只需要集合 `set`。

## 七、样例解析

样例：

```text
输入：
bc
abc
```

先得到：

```python
t_chars = set("abc")
```

然后检查：

```text
b 在 {'a', 'b', 'c'} 中，结果为 True
c 在 {'a', 'b', 'c'} 中，结果为 True
```

所有检查结果都是 `True`，所以输出：

```text
true
```

## 八、输入代码解释

```python
s = sys.stdin.readline().strip()
t = sys.stdin.readline().strip()
```

- `readline()`：读取一行输入；
- `strip()`：去掉行末的换行符；
- 第一行保存到 `s`，第二行保存到 `t`。

本题字符串只由小写字母组成，没有需要保留的空格，所以使用 `strip()` 没有问题。

## 九、复杂度

假设 `s` 长度为 `n`，`t` 长度为 `m`：

- 创建 `set(t)` 需要 `O(m)` 时间；
- 检查 `s` 中字符需要 `O(n)` 时间；
- 总时间复杂度：`O(n + m)`；
- 集合占用的额外空间复杂度：`O(m)`。

## 十、记忆方式

```text
把 t 放进 set
逐个检查 s 的字符是否在这个 set 中
全部存在：true
有一个不存在：false
```
