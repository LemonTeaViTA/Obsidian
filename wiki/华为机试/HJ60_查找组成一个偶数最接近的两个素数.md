# HJ60 查找组成一个偶数最接近的两个素数

## 题目意思

给定一个偶数 `n`，找两个素数 `a`、`b`，满足：

```text
a + b = n
```

并且 `|a - b|` 最小。

例如 `n = 20` 时，可以尝试：

```text
10 + 10   10 不是素数
9 + 11    9 不是素数
8 + 12    8、12 都不是素数
7 + 13    7、13 都是素数
```

所以答案是 `7` 和 `13`。

## 解题思路

因为两个数的和固定为 `n`，所以它们越接近，差值越小。

因此可以从中间开始尝试：

```python
a = n // 2
b = n - a
```

如果 `a`、`b` 都是素数，就找到了答案。

如果不满足，就让 `a` 每次减 1。由于 `a + b` 必须保持为 `n`，所以 `b` 会自动增加 1：

```text
a 变小，b 变大
两数差值变大
```

所以从中间往外找到的第一组素数，一定是差值最小的那一组。

## 判断素数

一个大于 1 的数，如果只能被 `1` 和它本身整除，就是素数。

判断 `x` 是否为素数时，不需要尝试除到 `x - 1`，只需要检查到平方根即可。代码中用：

```python
while i * i <= x:
```

如果 `x` 有一个大于平方根的因数，那么它一定还有一个小于平方根的因数，前面已经可以检查到。

## Python 答案

```python
import sys


def is_prime(x):
    # 0 和 1 都不是素数
    if x < 2:
        return False

    # 只检查到平方根
    i = 2
    while i * i <= x:
        if x % i == 0:
            return False
        i += 1

    return True


n = int(sys.stdin.readline())

# 从 n/2 附近开始向较小的一侧查找
for a in range(n // 2, 1, -1):
    b = n - a

    if is_prime(a) and is_prime(b):
        print(a)
        print(b)
        break
```

## 代码运行过程

以 `n = 20` 为例：

```text
a = 10，b = 10，10 不是素数
a = 9， b = 11，9 不是素数
a = 8， b = 12，8 不是素数
a = 7， b = 13，7、13 都是素数
```

输出：

```text
7
13
```

以 `n = 4` 为例：

```text
a = 2，b = 2
```

两个数都是素数，直接输出：

```text
2
2
```

## 复杂度

最多尝试约 `n / 2` 个候选数，每次判断素数最多检查到平方根，因此在本题 `n <= 1000` 的范围内运行非常快。

```text
时间复杂度：O(n√n)
空间复杂度：O(1)
```
