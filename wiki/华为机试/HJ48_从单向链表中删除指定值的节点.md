# HJ48 从单向链表中删除指定值的节点

## 一、题目到底在做什么

题目不会直接给出链表顺序，而是给出一种“插入规则”。

输入格式是：

```text
n h a1 b1 a2 b2 ... a(n-1) b(n-1) k
```

- `n`：链表一共有多少个结点；
- `h`：最开始的头结点值；
- 每个 `(a, b)`：把新结点 `a` 插入到值为 `b` 的结点后面；
- `k`：最后要删除的结点值。

注意：`(a, b)` 的意思不是把 `a` 和 `b` 组成一对，而是：

```text
在 b 后面插入 a
```

## 二、样例 1 的构造过程

输入：

```text
5 2 3 2 4 3 5 2 1 4 3
```

拆开看：

```text
n = 5
h = 2
(3, 2)
(4, 3)
(5, 2)
(1, 4)
k = 3
```

开始只有头结点：

```text
[2]
```

执行 `(3, 2)`：在 2 后面插入 3：

```text
[2, 3]
```

执行 `(4, 3)`：在 3 后面插入 4：

```text
[2, 3, 4]
```

执行 `(5, 2)`：在 2 后面插入 5：

```text
[2, 5, 3, 4]
```

执行 `(1, 4)`：在 4 后面插入 1：

```text
[2, 5, 3, 4, 1]
```

最后删除值为 `3` 的结点：

```text
[2, 5, 4, 1]
```

## 三、最简单的思路

虽然题目说的是“单向链表”，但在 Python 中可以先使用列表模拟：

1. 列表初始为 `[h]`；
2. 对每一组 `(a, b)`：
   - 找到 `b` 的位置；
   - 把 `a` 插入到这个位置后面；
3. 删除值为 `k` 的元素；
4. 输出剩余元素。

Python 列表的下标从 `0` 开始，`list.index(x)` 可以找到值 `x` 的下标，`list.insert(pos, value)` 可以在指定下标前插入元素。

例如：

```python
values = [2, 3, 4]
position = values.index(2)       # 0
values.insert(position + 1, 5)   # 在 2 后面插入 5
```

结果：

```python
[2, 5, 3, 4]
```

## 四、Python 答案

```python
import sys

data = list(map(int, sys.stdin.buffer.read().split()))

index = 0
n = data[index]
index += 1

# 初始链表只有头结点
values = [data[index]]
index += 1

# 一共 n-1 次插入
for _ in range(n - 1):
    new_value = data[index]
    after_value = data[index + 1]
    index += 2

    # 找到 after_value 的位置，并在它后面插入 new_value
    position = values.index(after_value)
    values.insert(position + 1, new_value)

# 读取要删除的结点值
delete_value = data[index]

# 删除指定值的结点
values.remove(delete_value)

# 结点之间用一个空格输出
print(*values)
```

## 五、删除操作解释

```python
values.remove(delete_value)
```

表示从列表中删除值为 `delete_value` 的元素。

题目保证结点值互不相同，所以只会删除一个结点。

例如：

```python
values = [2, 5, 3, 4, 1]
values.remove(3)
```

结果是：

```python
[2, 5, 4, 1]
```

## 六、为什么是 `position + 1`

假设：

```python
values = [2, 3, 4]
```

值 `2` 的下标是 `0`：

```python
position = 0
```

如果想插入到 `2` 后面，就要插入下标 `1` 的位置：

```python
values.insert(position + 1, 5)
```

结果是：

```text
[2, 5, 3, 4]
```

如果直接写 `values.insert(position, 5)`，就会插到 `2` 的前面，结果变成：

```text
[5, 2, 3, 4]
```

这就不符合“在 2 后面插入”的要求了。

## 七、输入读取解释

```python
data = list(map(int, sys.stdin.buffer.read().split()))
```

由于所有输入都是整数，可以一次性读入：

```python
data = [5, 2, 3, 2, 4, 3, 5, 2, 1, 4, 3]
```

然后通过 `index` 指针依次读取：

```text
data[0]：n
data[1]：头结点 h
之后每两个数是一组 (a,b)
最后一个数是 k
```

## 八、复杂度

`n` 最大为 `1000`，使用列表模拟完全足够。

- `index` 查找最多需要 `O(n)`；
- `insert` 插入时移动元素最多需要 `O(n)`；
- 一共插入 `n-1` 次。

总复杂度约为 `O(n²)`，在 `n <= 1000` 时可以通过。

如果以后要处理非常大的链表，可以用字典记录 `next` 指针，把插入优化到 `O(1)`，但这道题没有必要先引入更复杂的写法。
