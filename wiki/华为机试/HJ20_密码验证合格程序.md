# HJ20 密码验证合格程序

## 一、答案

```python
import sys


def has_repeated_substring(password):
    for i in range(len(password) - 2):
        substring = password[i:i + 3]

        if substring in password[i + 3:]:
            return True

    return False


for line in sys.stdin:
    password = line.rstrip("\n")

    if len(password) < 8:
        print("NG")
        continue

    category_count = 0
    category_count += any(ch.isupper() for ch in password)
    category_count += any(ch.islower() for ch in password)
    category_count += any(ch.isdigit() for ch in password)
    category_count += any(not ch.isalnum() for ch in password)

    if category_count < 3:
        print("NG")
        continue

    if has_repeated_substring(password):
        print("NG")
        continue

    print("OK")
```

## 二、解题思路

每个密码需要依次通过三项检查：

```text
1. 长度不少于 8；
2. 四种字符类型中至少包含三种；
3. 不能存在两个相同且互不重叠的、长度至少为 3 的连续子串。
```

只要有一项不合格，就输出：

```text
NG
```

三项全部合格，才输出：

```text
OK
```

## 三、为什么需要一直读取到文件结尾

题目没有在第一行给出密码数量，所以使用：

```python
for line in sys.stdin:
```

它表示：

```text
输入还有下一行，就继续检查下一组密码；
所有输入读完后，循环自动结束。
```

每读取一个密码，就输出一行 `OK` 或 `NG`。

## 四、第一项：检查密码长度

```python
if len(password) < 8:
    print("NG")
    continue
```

题目要求长度不少于 `8`，所以：

```text
长度小于 8：不合格；
长度等于 8：通过长度检查；
长度大于 8：通过长度检查。
```

`continue` 表示当前密码已经确定不合格，直接处理下一行，不必再做后面的检查。

## 五、第二项：统计字符类型

密码字符分为四种类型：

```text
大写字母；
小写字母；
数字；
特殊字符。
```

代码分别检查每一种类型是否出现过：

```python
category_count = 0
category_count += any(ch.isupper() for ch in password)
category_count += any(ch.islower() for ch in password)
category_count += any(ch.isdigit() for ch in password)
category_count += any(not ch.isalnum() for ch in password)
```

### `isupper()`

```python
ch.isupper()
```

判断字符是不是大写字母。

例如：

```python
"A".isupper()  # True
"a".isupper()  # False
```

### `islower()`

```python
ch.islower()
```

判断字符是不是小写字母。

### `isdigit()`

```python
ch.isdigit()
```

判断字符是不是数字。

### `isalnum()`

```python
ch.isalnum()
```

判断字符是不是字母或数字。

因此：

```python
not ch.isalnum()
```

表示这个字符既不是字母，也不是数字，也就是题目中的特殊字符。

例如：

```text
$、#、@、!、%
```

## 六、`any()` 是什么意思

例如：

```python
any(ch.isupper() for ch in password)
```

它会依次检查密码中的字符，只要找到一个大写字母，就返回：

```python
True
```

如果一个大写字母都没有，就返回：

```python
False
```

在 Python 中：

```text
True 参与加法时相当于 1；
False 参与加法时相当于 0。
```

所以四次检查相加后，`category_count` 就是密码包含的字符类型数量。

例如：

```text
021Abc9000
```

包含：

```text
大写字母：有，A；
小写字母：有，b、c；
数字：有，0、2、1、9；
特殊字符：没有。
```

所以：

```python
category_count = 3
```

符合至少三种的要求。

如果类型不足三种：

```python
if category_count < 3:
    print("NG")
    continue
```

## 七、第三项：检查重复连续子串

题目不允许出现两个相同、互不重叠、长度大于 `2` 的连续子串。

长度大于 `2`，也就是长度至少为 `3`。

代码定义：

```python
def has_repeated_substring(password):
```

专门检查是否存在这种重复子串。

### 1. 依次截取长度为 3 的子串

```python
for i in range(len(password) - 2):
    substring = password[i:i + 3]
```

例如：

```python
password = "021Abc9Abc1"
```

当 `i = 3` 时：

```python
substring = password[3:6]
          = "Abc"
```

### 2. 只在不重叠的后半部分寻找

```python
if substring in password[i + 3:]:
    return True
```

当前子串占用的位置是：

```text
i、i+1、i+2
```

为了保证第二个子串和它独立、不重叠，只能从：

```text
i+3
```

之后开始寻找。

例如第一次 `Abc` 位于：

```text
password[3:6]
```

后面的：

```python
password[6:]
```

中还包含另一个 `Abc`，所以密码不合格。

## 八、为什么只检查长度 3 就够了

题目禁止的是所有长度至少为 `3` 的重复子串。

假设存在两个相同的长度 `5` 子串：

```text
ABCDE ... ABCDE
```

那么它们开头的前三个字符也一定相同：

```text
ABC ... ABC
```

因此：

```text
只要存在长度大于 3 的重复子串，
就一定也存在长度为 3 的重复子串。
```

所以只检查长度为 `3` 的子串，就能够发现所有不合格情况。

## 九、“独立子串”为什么很重要

独立表示两个子串不能占用同一个字符位置。

例如：

```text
1111
```

其中可以看到两个文字上相同的 `111`：

```text
第一个：位置 0、1、2
第二个：位置 1、2、3
```

但它们重叠了位置 `1、2`，不是两个独立子串，所以不能仅凭这两个重叠的 `111` 判定失败。

代码使用：

```python
password[i + 3:]
```

而不是整个后续字符串，正是为了避免把重叠子串误判为两个独立子串。


## 十一、为什么读取时使用 `rstrip("\n")`

```python
password = line.rstrip("\n")
```

`for line in sys.stdin` 读到的每一行通常包含末尾换行符 `\n`。

密码本身由 ASCII 可见字符组成，不包含换行符，因此要把换行符删除。

这里使用：

```python
rstrip("\n")
```

只删除右侧换行符，不会误删密码中的其他可见字符。

## 十二、代码执行顺序

一组密码的完整判断流程是：

```text
读取密码
   ↓
长度是否至少 8？——否→ NG
   ↓是
字符类型是否至少 3 种？——否→ NG
   ↓是
是否存在重复的独立三字符子串？——是→ NG
   ↓否
   OK
```

先失败就立即输出并进入下一组，不再做无用检查。

## 十三、复杂度

设密码长度为 `n`，题目保证 `n <= 100`。

- 长度和类型检查需要 `O(n)`；
- 重复子串检查最坏需要 `O(n²)`；
- 额外空间复杂度为 `O(1)`，不计算切片产生的临时字符串。

`n` 最大只有 `100`，这个复杂度完全可以通过。

## 十四、记忆方式

```text
长度至少 8；
大写、小写、数字、特殊字符至少三种；
截取每个长度为 3 的子串；
只在 i+3 之后寻找，保证两个子串不重叠；
任一规则失败输出 NG，全部通过输出 OK。
```
