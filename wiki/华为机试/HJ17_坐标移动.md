# HJ17 坐标移动

## 一、答案

```python
import sys


commands = sys.stdin.readline().strip().split(";")
x = 0
y = 0

for command in commands:
    if len(command) not in (2, 3):
        continue

    direction = command[0]
    distance_text = command[1:]

    if direction not in "ADWS" or not distance_text.isdigit():
        continue

    distance = int(distance_text)

    if not 1 <= distance < 100:
        continue

    if direction == "A":
        x -= distance
    elif direction == "D":
        x += distance
    elif direction == "W":
        y += distance
    else:
        y -= distance

print(f"{x},{y}")
```

## 二、解题思路

小人初始位于：

```text
(0, 0)
```

四种方向对坐标的影响是：

| 指令  | 方向 | 坐标变化      |
| ----- | ---- | ------------- |
| `A` | 向左 | `x -= 距离` |
| `D` | 向右 | `x += 距离` |
| `W` | 向上 | `y += 距离` |
| `S` | 向下 | `y -= 距离` |

输入中多个指令使用分号分隔，因此可以先执行：

```python
split(";")
```

把它们拆开。

然后依次处理每一段：

1. 检查长度是否合法；
2. 检查方向是否合法；
3. 检查距离部分是否全是数字；
4. 检查距离是否在 `1` 到 `99`；
5. 合法时才修改坐标，非法时直接忽略。

## 三、先理解输入拆分

例如输入：

```text
A10;S20;W10;D30;
```

执行：

```python
commands = s.split(";")
```

会得到：

```python
["A10", "S20", "W10", "D30", ""]
```

最后一个元素是空字符串，是因为原输入末尾也有一个分号。

空字符串会在长度检查时被忽略，不会影响答案。

## 四、一条合法指令长什么样

原题说合法指令由三至四个符号组成，其中最后一个符号是分号。

使用 `split(";")` 后，分号已经被删除，所以一段合法指令只剩：

```text
方向 + 一位数字
```

或者：

```text
方向 + 两位数字
```

因此长度只能是 `2` 或 `3`：

```python
if len(command) not in (2, 3):
    continue
```

合法例子：

```text
A1
W09
D30
S99
```

非法例子：

```text
A       没有距离
A100    距离部分有三位
X10     方向错误
A1A     距离不是纯数字
```

## 五、代码逐段解释

### 1. 读取并拆分所有指令

```python
commands = sys.stdin.readline().strip().split(";")
```

这一行可以拆成三步理解：

```python
line = sys.stdin.readline()
line = line.strip()
commands = line.split(";")
```

它读取整行，删除换行符，然后按照分号拆成多个指令片段。

### 2. 初始化坐标

```python
x = 0
y = 0
```

题目规定起点是 `(0, 0)`。

### 3. 依次处理每个指令

```python
for command in commands:
```

每次循环处理一个分号之间的内容。

### 4. 检查指令长度

```python
if len(command) not in (2, 3):
    continue
```

`continue` 表示：

```text
当前指令不合法，不再执行本轮后面的代码，直接处理下一条指令。
```

例如 `A100` 的长度为 `4`，会直接被跳过。

### 5. 分离方向和距离

```python
direction = command[0]
distance_text = command[1:]
```

例如：

```python
command = "A10"
```

那么：

```python
direction = "A"
distance_text = "10"
```

`command[0]` 取第一个字符，`command[1:]` 取第一个字符之后的全部内容。

### 6. 检查方向和数字格式

```python
if direction not in "ADWS" or not distance_text.isdigit():
    continue
```

```python
direction not in "ADWS"
```

检查方向是否为 `A、D、W、S` 之一。

```python
distance_text.isdigit()
```

检查距离部分是否全部由数字组成。

例如：

```python
"10".isdigit()  # True
"09".isdigit()  # True
"1A".isdigit()  # False
```

因此 `A1A` 会被忽略。

### 7. 转换距离并检查范围

```python
distance = int(distance_text)

if not 1 <= distance < 100:
    continue
```

题目要求距离大于 `0` 且小于 `100`，所以只有 `1` 到 `99` 合法。

例如：

```text
A0   不合法
A00  不合法
A01  合法，距离是 1
A99  合法
A100 不合法
```

虽然长度检查已经会排除 `A100`，这里仍然检查数值范围，使合法规则表达得更完整。

### 8. 根据方向修改坐标

```python
if direction == "A":
    x -= distance
elif direction == "D":
    x += distance
elif direction == "W":
    y += distance
else:
    y -= distance
```

因为前面已经保证方向一定属于 `ADWS`，所以最后的 `else` 只可能是 `S`。

可以记成：

```text
A：x 减少
D：x 增加
W：y 增加
S：y 减少
```

### 9. 按要求输出

```python
print(f"{x},{y}")
```

`f"{x},{y}"` 会把坐标拼成使用逗号分隔的字符串。

例如：

```python
x = 10
y = -10
```

输出：

```text
10,-10
```

## 六、官方示例完整执行过程

输入：

```text
A10;S20;W10;D30;X;A1A;B10A11;;A10;
```

初始坐标：

```text
(0, 0)
```

依次处理：

| 指令       | 是否合法 | 操作    | 新坐标         |
| ---------- | -------- | ------- | -------------- |
| `A10`    | 合法     | 向左 10 | `(-10, 0)`   |
| `S20`    | 合法     | 向下 20 | `(-10, -20)` |
| `W10`    | 合法     | 向上 10 | `(-10, -10)` |
| `D30`    | 合法     | 向右 30 | `(20, -10)`  |
| `X`      | 不合法   | 忽略    | `(20, -10)`  |
| `A1A`    | 不合法   | 忽略    | `(20, -10)`  |
| `B10A11` | 不合法   | 忽略    | `(20, -10)`  |
| 空字符串   | 不合法   | 忽略    | `(20, -10)`  |
| `A10`    | 合法     | 向左 10 | `(10, -10)`  |

最终输出：

```text
10,-10
```

## 七、前导零为什么合法

题目说明，小于 `10` 的距离可能带一个前导零。

例如：

```text
A01
W09
```

```python
int("01")
```

结果是整数 `1`。

```python
int("09")
```

结果是整数 `9`。

所以当前代码能够自然处理前导零，不需要额外逻辑。

## 八、为什么不直接使用正则表达式

这道题也可以使用正则表达式判断合法格式，但对于初学者并不是必需的。

本题合法规则很少，使用：

```text
长度检查
方向检查
isdigit() 检查
数值范围检查
```

已经足够清楚，也更容易逐步调试。

## 九、复杂度

设输入字符串总长度为 `n`：

- 时间复杂度：`O(n)`，每段指令只检查一次；
- 空间复杂度：`O(n)`，`split()` 会保存拆分后的指令列表。
