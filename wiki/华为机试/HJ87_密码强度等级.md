# HJ87 密码强度等级

## 一、答案

~~~python
import sys


password = sys.stdin.readline().strip()

length_score = 0
letter_score = 0
digit_score = 0
symbol_score = 0

has_lower = False
has_upper = False
digit_count = 0
symbol_count = 0

for ch in password:
    if ch.islower():
        has_lower = True
    elif ch.isupper():
        has_upper = True
    elif ch.isdigit():
        digit_count += 1
    else:
        symbol_count += 1

# 1. 密码长度得分
if len(password) <= 4:
    length_score = 5
elif len(password) <= 7:
    length_score = 10
else:
    length_score = 25

# 2. 字母得分
if has_lower and has_upper:
    letter_score = 20
elif has_lower or has_upper:
    letter_score = 10

# 3. 数字得分
if digit_count == 1:
    digit_score = 10
elif digit_count > 1:
    digit_score = 20

# 4. 符号得分
if symbol_count == 1:
    symbol_score = 10
elif symbol_count > 1:
    symbol_score = 25

score = length_score + letter_score + digit_score + symbol_score

# 5. 奖励，只取最高的一种
if has_lower and has_upper and digit_count > 0 and symbol_count > 0:
    score += 5
elif (has_lower or has_upper) and digit_count > 0 and symbol_count > 0:
    score += 3
elif (has_lower or has_upper) and digit_count > 0:
    score += 2

if score >= 90:
    print('VERY_SECURE')
elif score >= 80:
    print('SECURE')
elif score >= 70:
    print('VERY_STRONG')
elif score >= 60:
    print('STRONG')
elif score >= 50:
    print('AVERAGE')
elif score >= 25:
    print('WEAK')
else:
    print('VERY_WEAK')
~~~

## 二、题目翻译成人话

给密码打分，分为五个部分：

1. 长度得分；
2. 字母得分；
3. 数字得分；
4. 符号得分；
5. 奖励分。

最后根据总分输出等级：

| 总分 | 等级 |
| ---: | --- |
| >= 90 | VERY_SECURE |
| >= 80 | SECURE |
| >= 70 | VERY_STRONG |
| >= 60 | STRONG |
| >= 50 | AVERAGE |
| >= 25 | WEAK |
| < 25 | VERY_WEAK |

## 三、先统计密码中有哪些字符

代码遍历密码中的每个字符：

~~~python
has_lower = False
has_upper = False
digit_count = 0
symbol_count = 0
~~~

其中：

- `has_lower`：是否出现过小写字母；
- `has_upper`：是否出现过大写字母；
- `digit_count`：数字出现次数；
- `symbol_count`：符号出现次数。

遍历：

~~~python
for ch in password:
    if ch.islower():
        has_lower = True
    elif ch.isupper():
        has_upper = True
    elif ch.isdigit():
        digit_count += 1
    else:
        symbol_count += 1
~~~

题目保证输入是可见字符，所以前面三类都不是时，剩下的就是符号。

## 四、长度得分

~~~python
if len(password) <= 4:
    length_score = 5
elif len(password) <= 7:
    length_score = 10
else:
    length_score = 25
~~~

对应题目：

~~~text
长度 <= 4：5 分
长度 5～7：10 分
长度 >= 8：25 分
~~~

## 五、字母得分

~~~python
if has_lower and has_upper:
    letter_score = 20
elif has_lower or has_upper:
    letter_score = 10
~~~

对应：

- 没有字母：0 分；
- 只有一种大小写：10 分；
- 大小写都有：20 分。

这里 `or` 表示只要有小写或大写中的一种即可，`and` 表示两种都必须有。

## 六、数字得分

~~~python
if digit_count == 1:

elif digit_count > 1:
    digit_score = 20
~~~

对应：

~~~text
没有数字：0 分
1 个数字：10 分
超过 1 个数字：20 分
~~~

## 七、符号得分

~~~python
if symbol_count == 1:

~~~

对应：

~~~text
没有符号：0 分
1 个符号：10 分
~~~

## 八、奖励分为什么要从高到低判断

奖励只能选择一种，不能重复累加。

最高奖励是：

~~~text
大小写字母 + 数字 + 符号 → 5 分
~~~

所以先判断最高条件：

~~~python
if has_lower and has_upper and digit_count > 0 and symbol_count > 0:
    score += 5
~~~

如果不满足，再判断：

~~~python
elif (has_lower or has_upper) and digit_count > 0 and symbol_count > 0:
    score += 3
~~~

最后判断：

~~~python
elif (has_lower or has_upper) and digit_count > 0:
    score += 2
~~~

使用 `elif` 可以保证最多只进入一个奖励分支。

## 九、官方示例一

输入：

~~~text
38$@NoNoN
~~~

统计：

~~~text
长度 >= 8：25 分
大小写字母都有：20 分
数字有 2 个：20 分
符号有 2 个：25 分
大小写字母 + 数字 + 符号：5 分
~~~

总分：

~~~text
25 + 20 + 20 + 25 + 5 = 95
~~~

所以输出：

~~~text
VERY_SECURE
~~~

## 十一、为什么最后使用 `elif` 判断等级

等级是从高到低的区间：

~~~python
if score >= 90:
    ...
elif score >= 80:
    ...
elif score >= 70:
    ...
~~~

例如分数是 `95`，第一个条件已经成立，输出 `VERY_SECURE`，后面的条件不会再检查。

如果从低到高判断，容易出现分数 `95` 先被 `score >= 25` 匹配的问题。

## 十二、复杂度

密码只需要遍历一次：

- 时间复杂度：`O(n)`；
- 额外空间复杂度：`O(1)`。

## 十三、记忆方式

~~~text
分别计算长度、字母、数字、符号分数
奖励从 5 分到 2 分从高到低判断
总分从 90 分往下判断等级
~~~
