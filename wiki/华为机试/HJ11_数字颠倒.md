# HJ11 数字颠倒

## 一、答案

```python
import sys


s = sys.stdin.readline().strip()
reversed_number = s[::-1]

print(reversed_number)
```

## 二、解题思路

题目要求把输入数字的所有字符完全颠倒。

例如：

```text
1516000
```

从右向左读取就是：

```text
0006151
```

因为题目明确要求保留颠倒后开头的 `0`，所以应该把输入当作字符串，而不是整数。

Python 可以使用：

```python
s[::-1]
```

将字符串倒序。

## 三、为什么要当作字符串处理

如果把结果当作整数，开头的 `0` 会消失。

例如：

```python
int("0006151")
```

结果是：

```text
6151
```

但是题目要求输出：

```text
0006151
```

所以本题需要直接保存并输出字符串，不能把反转结果转换成整数。

## 四、代码逐行解释

### 1. 读取输入

```python
s = sys.stdin.readline().strip()
```

`sys.stdin.readline()` 读取一整行输入。

虽然题目说输入是一个非负整数，但读取时可以不使用 `int()`，直接保留字符串形式。

例如输入：

```text
1516000
```

读取后：

```python
s = "1516000"
```

`strip()` 用来删除行末的换行符。

### 2. 反转字符串

```python
reversed_number = s[::-1]
```

切片的一般格式是：

```python
字符串[开始位置:结束位置:步长]
```

这里：

```text
开始位置省略；
结束位置省略；
步长是 -1。
```

步长 `-1` 表示从字符串末尾开始，每次向左移动一位。

例如字符串：

```python
s = "12345"
```

执行：

```python
s[::-1]
```

得到：

```python
"54321"
```

对于本题示例：

```python
"1516000"[::-1]
```

得到：

```python
"0006151"
```

### 3. 输出结果

```python
print(reversed_number)
```

`reversed_number` 是字符串，所以开头的 `0` 会被完整保留。

## 五、示例完整执行过程

输入：

```text
1516000
```

把每一位写出来：

```text
原顺序：1 5 1 6 0 0 0
反顺序：0 0 0 6 1 5 1
```

连接后得到：

```text
0006151
```

最终输出：

```text
0006151
```

## 六、特殊情况

### 输入为 `0`

输入：

```text
0
```

反转后仍然是：

```text
0
```

### 输入只有一位

输入：

```text
7
```

反转后仍然是：

```text
7
```

### 输入末尾没有 `0`

输入：

```text
12345
```

输出：

```text
54321
```

### 输入末尾有多个 `0`

输入：

```text
12000
```

输出必须保留三个开头的 `0`：

```text
00021
```

## 七、使用循环的写法

如果还不熟悉 `[::-1]`，可以使用循环从最后一个字符开始读取：

```python
import sys


s = sys.stdin.readline().strip()
result = []

for i in range(len(s) - 1, -1, -1):
    result.append(s[i])

print("".join(result))
```

这里：

```python
range(len(s) - 1, -1, -1)
```

表示从最后一个下标开始，每次减 `1`，一直走到下标 `0`。

例如字符串长度为 `5`，下标是：

```text
0、1、2、3、4
```

循环顺序就是：

```text
4、3、2、1、0
```

主答案中的 `s[::-1]` 是这个循环的简洁写法。

## 八、和 HJ9 的区别

### HJ9 提取不重复的整数

```text
从右向左读取；
遇到重复数字需要跳过；
需要使用 set 去重。
```

### HJ11 数字颠倒

```text
只需要从右向左读取；
所有数字都要保留，包括重复数字和 0；
不需要使用 set。
```

例如输入：

```text
1220
```

HJ9 会去重，结果是：

```text
021
```

HJ11 不去重，结果是：

```text
0221
```

## 九、复杂度

设输入数字字符串长度为 `n`：

- 时间复杂度：`O(n)`，需要反转整个字符串；
- 空间复杂度：`O(n)`，反转会生成一个新的字符串。

## 十、记忆方式

```text
数字末尾的 0 需要保留，所以当字符串处理；
s[::-1] 表示完整反转字符串；
不要把反转结果转换成 int。
```
