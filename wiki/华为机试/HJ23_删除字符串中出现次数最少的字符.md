# HJ23 删除字符串中出现次数最少的字符

## 一、答案

```python
import sys


s = sys.stdin.readline().strip()
counts = {}

for ch in s:
    counts[ch] = counts.get(ch, 0) + 1

minimum_count = min(counts.values())
result = []

for ch in s:
    if counts[ch] != minimum_count:
        result.append(ch)

print("".join(result))
```

## 二、解题思路

题目要求删除出现次数最少的所有字符，同时保持其他字符的原有顺序。

可以分为三步：

1. 统计每个字符出现了多少次；
2. 找出最小的出现次数；
3. 再次遍历原字符串，只保留出现次数不是最小值的字符。

例如：

```text
aabcddd
```

字符出现次数：

```text
a：2 次
b：1 次
c：1 次
d：3 次
```

最小次数是 `1`，所以删除所有出现一次的字符：

```text
b、c
```

剩余字符按照原顺序连接：

```text
aaddd
```

## 三、为什么要先统计再删除

当第一次看到一个字符时，我们还不知道它后面会不会继续出现。

例如：

```text
abca
```

第一次看到 `a` 时，它暂时只出现了一次，但后面还有另一个 `a`。

所以不能一边读取一边马上决定是否删除。

正确过程是：

```text
先完整统计所有字符；
知道最小次数以后；
再决定每个字符是否保留。
```

## 四、代码逐行解释

### 1. 读取字符串

```python
s = sys.stdin.readline().strip()
```

读取输入的一整行，并删除末尾换行符。

题目保证字符串只包含小写字母，不包含空格，所以可以直接使用 `strip()`。

例如输入：

```text
aabcddd
```

读取后：

```python
s = "aabcddd"
```

### 2. 创建计数字典

```python
counts = {}
```

字典用来保存：

```text
键：字符
值：字符出现次数
```

例如统计完成后：

```python
counts = {
    "a": 2,
    "b": 1,
    "c": 1,
    "d": 3
}
```

### 3. 统计字符次数

```python
for ch in s:
    counts[ch] = counts.get(ch, 0) + 1
```

`counts.get(ch, 0)` 的意思是：

```text
如果字符已经在字典中，取得原来的次数；
如果字符还不在字典中，使用默认值 0。
```

然后加 `1`。

#### 字符第一次出现

假设 `counts` 为空，读到字符 `a`：

```python
counts.get("a", 0)  # 0
counts["a"] = 0 + 1
```

结果：

```python
counts = {"a": 1}
```

#### 字符再次出现

再次读到 `a`：

```python
counts.get("a", 0)  # 1
counts["a"] = 1 + 1
```

结果：

```python
counts = {"a": 2}
```

### 4. 找到最小次数

```python
minimum_count = min(counts.values())
```

`counts.values()` 取出字典中的所有次数。

例如：

```python
counts.values()
```

相当于：

```text
2、1、1、3
```

使用 `min()` 找最小值：

```python
minimum_count = 1
```

注意，我们找的是“最小出现次数”，不是字母中最小的字符。

### 5. 再次遍历原字符串

```python
result = []

for ch in s:
    if counts[ch] != minimum_count:
        result.append(ch)
```

再次按照原字符串的顺序查看每个字符。

如果当前字符的出现次数等于最小次数，就不加入结果，相当于删除它。

如果出现次数不等于最小次数，就加入结果列表。

例如 `aabcddd`：

```text
a 的次数是 2，不是最小值，保留；
a 的次数是 2，不是最小值，保留；
b 的次数是 1，是最小值，删除；
c 的次数是 1，是最小值，删除；
d 的次数是 3，不是最小值，保留；
d 保留；
d 保留。
```

结果列表：

```python
["a", "a", "d", "d", "d"]
```

### 6. 连接并输出

```python
print("".join(result))
```

使用空字符串把结果字符连接起来：

```python
"".join(["a", "a", "d", "d", "d"])
```

得到：

```text
aaddd
```

## 五、为什么多个最少字符会全部删除

代码判断的是：

```python
if counts[ch] != minimum_count:
```

所有出现次数等于最小值的字符都会被跳过。

例如：

```text
aabcddd
```

`b` 和 `c` 的出现次数都是 `1`，都等于 `minimum_count`，所以它们都会被删除。

不需要先单独找出只有一个“最少字符”。

## 六、为什么要再次遍历原字符串

题目要求其他字符保持原来的顺序。

例如：

```text
cbacbaaa
```

如果只遍历字典，我们只能知道每个字符的次数，但不能依靠字典来重新构造原字符串中的排列。

再次遍历 `s`：

```python
for ch in s:
```

可以保证留下来的字符和原字符串顺序完全一致。

## 七、示例完整执行过程

输入：

```text
aabcddd
```

第一遍统计：

| 字符 | 出现次数 |
| --- | ---: |
| `a` | 2 |
| `b` | 1 |
| `c` | 1 |
| `d` | 3 |

最小次数：

```text
1
```

需要删除：

```text
b、c
```

按照原顺序保留剩余字符：

```text
a、a、d、d、d
```

最终输出：

```text
aaddd
```

## 八、其他例子

### 只有一种字符

输入：

```text
aaaa
```

只有字符 `a`，它的次数也是最小次数。如果严格删除最少字符，结果会为空。

不过题目保证最终答案至少包含一个字符，因此测试数据不会出现需要删除唯一字符后变为空串的情况。

### 三种字符次数不同

输入：

```text
aaabcc
```

次数：

```text
a：3
b：1
c：2
```

删除 `b`，输出：

```text
aaacc
```

### 多个字符并列最少

输入：

```text
abbc
```

次数：

```text
a：1
b：2
c：1
```

`a` 和 `c` 都删除，输出：

```text
bb
```

## 九、使用 `Counter` 的写法

Python 还提供了专门统计次数的工具 `Counter`：

```python
import sys
from collections import Counter


s = sys.stdin.readline().strip()
counts = Counter(s)
minimum_count = min(counts.values())

result = [ch for ch in s if counts[ch] != minimum_count]
print("".join(result))
```

其中：

```python
Counter(s)
```

会自动完成字符次数统计。

主答案使用普通字典，是为了复习前面题目已经学过的：

```python
counts.get(ch, 0) + 1
```

## 十、复杂度

设字符串长度为 `n`：

- 第一遍统计需要 `O(n)`；
- 第二遍筛选需要 `O(n)`；
- 总时间复杂度：`O(n)`；
- 空间复杂度：`O(n)`，用于保存结果。计数字典最多只有 `26` 个键。

## 十一、记忆方式

```text
第一遍用字典统计次数；
min(counts.values()) 找最小次数；
第二遍按原顺序筛选字符；
次数等于最小值的全部跳过；
join() 拼接剩余字符。
```
