# HJ148 迷宫寻路

## 一、答案

~~~python
import sys
from collections import deque


n, m = map(int, sys.stdin.readline().split())
maze = [sys.stdin.readline().strip() for _ in range(n)]

queue = deque([(0, 0)])
visited = [[False] * m for _ in range(n)]
visited[0][0] = True

directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
reachable = False

while queue:
    row, col = queue.popleft()

    if row == n - 1 and col == m - 1:
        reachable = True
        break

    for dr, dc in directions:
        next_row = row + dr
        next_col = col + dc

        if not (0 <= next_row < n and 0 <= next_col < m):
            continue
        if maze[next_row][next_col] == "#":
            continue
        if visited[next_row][next_col]:
            continue

        visited[next_row][next_col] = True
        queue.append((next_row, next_col))

print("Yes" if reachable else "No")
~~~

## 二、题目翻译成人话

迷宫中：

~~~text
. 表示空地，可以走
# 表示墙，不能走
~~~

从左上角坐标 (1, 1) 出发，目标是右下角坐标 (n, m)。每次只能向上、下、左、右移动一格。

题目只要求判断能不能到达终点，不需要输出具体路线。能到达输出 Yes，不能到达输出 No。

## 三、使用的方法：BFS

BFS 是 Breadth First Search 的缩写，中文叫广度优先搜索。

可以把它想象成水波从起点向四周一层一层扩散：

~~~text
先检查距离起点 1 步的格子
再检查距离起点 2 步的格子
再检查距离起点 3 步的格子
~~~

只要终点被扩散到，就说明存在一条路。

## 四、为什么使用队列

~~~python
queue = deque([(0, 0)])
~~~

队列遵守先进先出：先进入队列的格子先检查。这正好实现一层一层扩散。

取出队头：

~~~python
row, col = queue.popleft()
~~~

发现可以走的新格子后加入队尾：

~~~python
queue.append((next_row, next_col))
~~~

`deque` 是 Python 自带的双端队列，适合进行 popleft 和 append 操作。

## 五、visited 的作用

~~~python
visited = [[False] * m for _ in range(n)]
visited[0][0] = True
~~~

visited[row][col] 表示这个格子是否已经走过。进入新格子后立即标记，避免反复走同一个格子。

如果不标记，可能出现：

~~~text
A → B → A → B → ……
~~~

## 六、如何判断相邻格子能不能走

当前格子为 row、col，四个方向用行列变化表示：

| 方向 | 行变化 | 列变化 |
| --- | ---: | ---: |
| 上 | -1 | 0 |
| 下 | 1 | 0 |
| 左 | 0 | -1 |
| 右 | 0 | 1 |

新坐标是：

~~~python
next_row = row + dr
next_col = col + dc
~~~

新格子必须同时满足：

1. 没有越界；
2. 不是墙；
3. 之前没有走过。

代码中的 continue 表示当前方向不符合条件，跳过它，继续检查下一个方向。

## 七、代码执行过程

以示例一为例，起点是 (0, 0)。程序先把它放入队列，然后不断执行：

~~~text
取出一个格子
尝试它的上、下、左、右
合法且没有走过的格子标记后加入队列
~~~

最终终点 (2, 4) 被放入并取出，reachable 变成 True，输出 Yes。

## 八、reachable 是什么

~~~python
reachable = False
~~~

它表示当前还没有找到终点。取出格子时，如果发现它就是右下角：

~~~python
reachable = True
break
~~~

break 表示结束搜索循环。最后根据 reachable 输出结果：

~~~python
print("Yes" if reachable else "No")
~~~

## 九、HJ148 和 HJ43 的区别

这两题都属于迷宫搜索：

~~~text
HJ148：只判断是否能到达终点，所以 BFS 找到即可
HJ43：要求输出具体路径，所以通常使用 DFS 加回溯，或者 BFS 记录前驱
~~~

简单记忆：

~~~text
DFS：一条路走到底，走不通再退回
BFS：一层一层向外扩散
~~~

## 十、输入为什么这样读取

第一行是两个数字，可以使用 split：

~~~python
n, m = map(int, sys.stdin.readline().split())
~~~

迷宫每一行是连续的点和井号，没有空格，所以直接读取成字符串：

~~~python
maze = [sys.stdin.readline().strip() for _ in range(n)]
~~~

## 十一、复杂度

每个格子最多进入队列一次，每次最多检查四个方向：

- 时间复杂度：O(n × m)
- 空间复杂度：O(n × m)

## 十二、记忆方式

~~~text
起点入队并标记
取出队头，尝试上下左右
合法且未访问就标记并入队
取到终点输出 Yes
队列为空仍没到终点输出 No
~~~
