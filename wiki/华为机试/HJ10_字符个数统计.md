# HJ10 字符个数统计

## 一、答案

```python
import sys


s = sys.stdin.readline().strip()
different_characters = set(s)

print(len(different_characters))
```

## 二、解题思路

题目要求统计字符串中有多少种不同字符。

例如：

```text
abca
```

其中出现过：

```text
a、b、c
```

虽然 `a` 出现了两次，但它只算一种字符，所以答案是 `3`。

Python 的集合 `set` 有一个重要特点：

```text
相同元素只保存一份
```

因此可以直接把字符串转换成集合：

```python
set("abca")
```

得到的集合中只有：

```python
{"a", "b", "c"}
```

然后使用 `len()` 统计集合中有多少个元素：

```python
len({"a", "b", "c"})
```

结果是：

```text
3
```

## 三、为什么不需要手动判断 ASCII 码

题目要求统计 ASCII 码在 `0` 到 `127` 范围内的字符。

但题目又保证，实际输入只包含 ASCII 码在 `33` 到 `126` 范围内的可见字符。

也就是说：

```text
输入中的所有字符都已经符合统计范围
```

所以不需要使用 `ord()` 检查每个字符的 ASCII 码，直接统计不同字符即可。

如果题目没有这个保证，才需要写类似：

```python
if 0 <= ord(ch) <= 127:
```

本题不需要增加这个判断。

## 四、代码逐行解释

### 1. 读取字符串

```python
s = sys.stdin.readline().strip()
```

`sys.stdin.readline()` 读取输入的一整行。

`strip()` 删除行末的换行符。

题目保证输入只包含 ASCII 可见字符，并且其中不包含空格，所以这里可以直接使用 `strip()`。

例如输入：

```text
[@A8aA].0
```

读取后：

```python
s = "[@A8aA].0"
```

### 2. 使用集合去重

```python
different_characters = set(s)
```

字符串可以被逐个字符遍历，所以 `set(s)` 会把字符串中的每个字符放进集合。

相同字符只保留一份。

例如：

```python
set("A8aA")
```

得到的字符有：

```text
A、8、a
```

第二个 `A` 和第一个 `A` 相同，所以集合只保留一个。

### 3. 统计不同字符个数

```python
print(len(different_characters))
```

`len()` 可以统计集合中有多少个元素。

集合中一个元素代表一种不同字符，因此集合大小就是题目答案。

## 五、大小写是否算同一个字符

本题统计的是不同的 ASCII 字符，所以大小写字母是不同字符。

例如：

```text
A 的 ASCII 码是 65
a 的 ASCII 码是 97
```

因此：

```python
set("Aa")
```

包含两个不同字符，答案是：

```text
2
```

这道题不能调用 `lower()`，否则会错误地把 `A` 和 `a` 合并。

HJ2 要求忽略字母大小写，所以使用了 `lower()`；HJ10 要求统计不同 ASCII 字符，所以必须保留原来的大小写。

## 六、示例完整执行过程

输入：

```text
[@A8aA].0
```

依次出现的字符是：

```text
[、@、A、8、a、A、]、.、0
```

其中 `A` 出现了两次，只保留一种。

不同字符是：

```text
[、@、A、8、a、]、.、0
```

一共有 `8` 种，所以输出：

```text
8
```

## 七、使用循环的写法

如果想看清楚集合是如何去重的，也可以手动遍历：

```python
import sys


s = sys.stdin.readline().strip()
different_characters = set()

for ch in s:
    different_characters.add(ch)

print(len(different_characters))
```

每次循环把当前字符加入集合：

```python
different_characters.add(ch)
```

如果字符已经存在，集合不会重复保存。

主答案中的：

```python
different_characters = set(s)
```

就是把这个循环交给 Python 直接完成。

## 八、和前面集合题的区别

### HJ3 明明的随机数

```text
使用 set 删除重复数字；
还需要 sorted() 排序并输出数字。
```

### HJ9 提取不重复的整数

```text
使用 set 判断数字是否出现过；
还需要使用列表保存从右到左的顺序。
```

### HJ10 字符个数统计

```text
只关心有多少种字符；
不关心字符顺序，也不需要输出字符；
所以直接 len(set(s)) 即可。
```

## 九、更简洁的写法

完整答案也可以缩写成：

```python
import sys


s = sys.stdin.readline().strip()
print(len(set(s)))
```

两种写法完全相同。主答案把集合单独保存到变量中，更方便初学者理解。

## 十、复杂度

设字符串长度为 `n`：

- 时间复杂度：平均 `O(n)`，需要检查每个字符；
- 空间复杂度：`O(1)`，ASCII 字符最多只有 `128` 种。

虽然也可以写成 `O(n)` 空间，但由于字符种类上限固定为 `128`，从输入规模角度可以看作常数空间。

## 十一、记忆方式

```text
set(s) 删除重复字符；
len(set(s)) 统计不同字符的个数；
大小写是不同的 ASCII 字符，不要调用 lower()。
```
