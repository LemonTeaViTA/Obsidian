# HJ22 汽水瓶

## 一、答案

```python
import sys


for line in sys.stdin:
    bottles = int(line)

    if bottles == 0:
        break

    answer = 0

    while bottles >= 3:
        drinks = bottles // 3
        answer += drinks
        bottles = bottles % 3 + drinks

    if bottles == 2:
        answer += 1

    print(answer)
```

## 二、解题思路

题目的兑换规则是：

```text
3 个空瓶可以换 1 瓶汽水。
```

换来的汽水喝完以后，又会得到一个空瓶。

所以可以一轮一轮模拟兑换：

1. 计算当前空瓶能换多少瓶汽水；
2. 把换到的汽水数量加入答案；
3. 计算喝完以后还剩多少空瓶；
4. 只要空瓶数不少于 `3`，就继续兑换。

最后如果剩下 `2` 个空瓶，可以向老板借一个空瓶：

```text
自己的 2 个空瓶 + 借来的 1 个空瓶
= 3 个空瓶
```

换一瓶汽水，喝完得到一个空瓶，再把这个空瓶还给老板。因此还能多喝一瓶。

## 三、一轮兑换如何计算

假设现在有 `10` 个空瓶。

### 能换多少瓶汽水

```python
drinks = bottles // 3
```

`//` 是整数除法：

```python
10 // 3 = 3
```

所以这一轮可以换 `3` 瓶汽水。

### 兑换后还剩多少空瓶

原来的 `10` 个空瓶中：

```text
9 个用于兑换；
剩下 1 个没有使用。
```

剩余数量是：

```python
10 % 3 = 1
```

换来的 `3` 瓶汽水喝完以后，又会产生 `3` 个空瓶。

因此下一轮的空瓶数量是：

```text
原来没有使用的空瓶 + 喝完汽水产生的空瓶
= 1 + 3
= 4
```

对应代码：

```python
bottles = bottles % 3 + drinks
```

## 四、代码逐行解释

### 1. 一直读取到文件结尾

```python
for line in sys.stdin:
```

题目没有告诉我们确切有多少组数据，所以需要一直读取。

每读取一行，就是一组空瓶数量。

### 2. 把输入转换成整数

```python
bottles = int(line)
```

例如这一行是：

```text
10
```

转换后：

```python
bottles = 10
```

### 3. 遇到 `0` 立即结束

```python
if bottles == 0:
    break
```

题目规定 `0` 是结束标志，不是一组需要计算的数据。

`break` 表示直接结束整个读取循环。

因此输入 `0` 时不能输出答案。

### 4. 初始化答案

```python
answer = 0
```

`answer` 记录目前一共喝了多少瓶汽水。

每组测试数据都要重新从 `0` 开始计算，所以它必须放在外层循环里面。

### 5. 能正常兑换时反复兑换

```python
while bottles >= 3:
```

只要空瓶数量不少于 `3`，就可以继续正常兑换。

```python
drinks = bottles // 3
```

计算这一轮能换多少瓶汽水。

```python
answer += drinks
```

把这一轮喝到的汽水加入总数。

```python
bottles = bottles % 3 + drinks
```

下一轮空瓶数量等于：

```text
这轮兑换后剩余的空瓶
+
换来的汽水喝完产生的空瓶
```

### 6. 剩两个空瓶时借一个

```python
if bottles == 2:
    answer += 1
```

正常兑换结束以后，空瓶只可能小于 `3`。

如果剩下两个，可以借一个空瓶，再换一瓶汽水，所以答案加 `1`。

如果只剩一个空瓶，即使借一个也只有两个，仍然不能兑换，所以不能再喝。

### 7. 输出当前这组的答案

```python
print(answer)
```

每组测试数据输出一行。

## 五、示例中 `10` 个空瓶的完整过程

开始时：

```text
空瓶：10
已喝：0
```

### 第一轮

```text
10 // 3 = 3，可以换 3 瓶汽水
10 % 3 = 1，原来剩 1 个空瓶
3 瓶汽水喝完又得到 3 个空瓶
```

所以：

```text
空瓶：1 + 3 = 4
已喝：3
```

### 第二轮

```text
4 // 3 = 1，可以换 1 瓶汽水
4 % 3 = 1，原来剩 1 个空瓶
1 瓶汽水喝完又得到 1 个空瓶
```

所以：

```text
空瓶：1 + 1 = 2
已喝：3 + 1 = 4
```

### 最后借一个空瓶

剩下 `2` 个空瓶，向老板借 `1` 个：

```text
2 + 1 = 3
```

换一瓶汽水并喝掉：

```text
已喝：4 + 1 = 5
```

喝完得到的空瓶归还老板。

所以 `10` 个空瓶最多喝：

```text
5 瓶汽水
```

## 六、完整示例

输入：

```text
3
10
81
0
```

输出：

```text
1
5
40
```

最后的 `0` 只表示输入结束，不输出任何内容。

## 七、为什么剩一个空瓶不能借

假设自己只有 `1` 个空瓶。

如果向老板借一个：

```text
1 + 1 = 2
```

仍然不足 `3`，不能换汽水。

如果向老板借两个，虽然能凑成三个空瓶换一瓶汽水，但是喝完后只得到一个空瓶，无法归还借来的两个空瓶，所以不允许。

因此：

```text
剩 1 个：不能再喝；
剩 2 个：可以借 1 个，再喝 1 瓶。
```

## 八、更简洁的规律

这道题最终还有一个规律：

```python
answer = bottles // 2
```

所以可以简写为：

```python
import sys


for line in sys.stdin:
    bottles = int(line)

    if bottles == 0:
        break

    print(bottles // 2)
```

例如：

```text
3 // 2 = 1
10 // 2 = 5
81 // 2 = 40
```

这个规律能直接通过本题，但第一次学习时，建议先理解前面的逐轮模拟，因为它清楚展示了空瓶如何变化。

## 九、复杂度

在模拟过程中，每一轮空瓶数量都会明显减少：

- 单组时间复杂度：`O(log n)`；
- 额外空间复杂度：`O(1)`。

使用 `n // 2` 的规律版本时，单组时间复杂度为 `O(1)`。

## 十、记忆方式

```text
每轮能喝 bottles // 3 瓶；
新空瓶 = bottles % 3 + drinks；
剩 2 个时借 1 个再喝一瓶；
读到 0 使用 break 结束，不输出；
最终规律是答案等于 n // 2。
```
