# HJ79 支付宝消费打折

## 一、答案

```python
import sys

data = sys.stdin.read().split()

n = int(data[0])
balance = int(data[1])
prices = list(map(int, data[2:2 + n]))
discount = data[2 + n]

costs = []

for price, flag in zip(prices, discount):
    if flag == '1':
        # 九五折：price * 19 / 20，乘以20后就是 price * 19
        cost = price * 19
    else:
        # 原价乘以20，和优惠价格统一比较
        cost = price * 20

    costs.append(cost)

costs.sort()

money = balance * 20
answer = 0

for cost in costs:
    if money >= cost:
        money -= cost
        answer += 1
    else:
        break

print(answer)
```

## 二、题目翻译成人话

有 `n` 件商品，每件最多买一次。你有 `k` 元支付宝余额。

每件商品有一个价格，还有一个标记：

```text
1：支持支付宝九五折
0：不支持优惠，按原价支付
```

问最多可以买多少件商品。

例如某件商品原价是 4 元：

```text
支持优惠：支付 4 × 0.95 = 3.8 元
不支持优惠：支付 4 元
```

## 三、这是什么类型的题目

这题属于：

```text
贪心算法 + 排序
```

因为目标是“买最多件”，所以应该优先选择当前实际价格最低的商品。把所有商品按实际支付价格从小到大排序，然后从便宜到贵依次购买。

## 四、为什么要从便宜的开始买

假设余额有 9 元，商品实际价格为：

```text
2、3、4、6
```

按从便宜到贵购买：

```text
买 2 元，剩 7 元
买 3 元，剩 4 元
买 4 元，剩 0 元
```

一共可以买 3 件。

如果先买 6 元商品，剩下 3 元，最多只能再买 2 元或 3 元中的一件，只能买 2 件。

因此，要想买到最多件数，就要优先购买便宜的商品。

## 五、为什么把金额乘以 20

九五折可以写成：

```text
价格 × 0.95 = 价格 × 19 ÷ 20
```

为了避免小数计算的精度问题，把所有金额统一乘以 20：

```text
原价：price × 20
优惠价：price × 19
```

例如原价 4 元：

```text
原价金额：4 × 20 = 80
优惠金额：4 × 19 = 76
```

比较 80 和 76，与比较 4 和 3.8 完全一致。

余额也乘以 20：

```python
money = balance * 20
```

这样全程只使用整数，不会出现浮点数误差。

## 六、`zip(prices, discount)` 是什么

```python
for price, flag in zip(prices, discount):
```

`prices` 是价格列表，`discount` 是优惠标记字符串。

例如：

```text
prices   = [3, 4, 2]
discount = "101"
```

`zip` 会把对应位置配在一起：

```text
(3, '1')
(4, '0')
(2, '1')
```

每次循环同时得到当前商品的价格和优惠标记。

## 七、为什么 `flag == '1'` 要加引号

第三行输入的是字符串，例如：

```text
11101
```

遍历这个字符串时，每个 `flag` 是字符 `'1'` 或 `'0'`。

所以要写：

```python
if flag == '1':
```

不能写成 `flag == 1`，因为 `'1'` 是字符串，`1` 是整数。

## 八、样例解析

输入：

```text
5 9
3 4 2 3 1
11101
```

每件商品乘以 20 后的实际金额：

```text
第1件：3 × 19 = 57
第2件：4 × 19 = 76
第3件：2 × 19 = 38
第4件：3 × 20 = 60
第5件：1 × 19 = 19
```

余额 9 元乘以 20 后是 `180`。

排序后：

```text
19、38、57、60、76
```

依次购买：

```text
180 - 19 = 161
161 - 38 = 123
123 - 57 = 66
66 - 60 = 6
6 不够购买 76
```

所以可以买 4 件。

## 九、为什么买不起当前商品后可以停止

商品已经按实际价格从小到大排序。

如果当前商品都买不起，后面的商品只会更贵，也不可能买得起，所以可以直接停止：

```python
else:
    break
```

## 十、代码逐行解释

```python
data = sys.stdin.read().split()
```

读取所有输入并按空白拆分，得到的内容都是字符串。

```python
n = int(data[0])
balance = int(data[1])
```

读取商品数量和余额。

```python
prices = list(map(int, data[2:2 + n]))
```

取出接下来的 `n` 个价格，并转换成整数列表。

```python
discount = data[2 + n]
```

读取最后的优惠标记字符串。

## 十一、复杂度

设商品数量为 `n`：

- 计算价格：`O(n)`；
- 排序：`O(n log n)`；
- 购买遍历：`O(n)`；
- 总时间复杂度：`O(n log n)`；
- 额外空间复杂度：`O(n)`。
