# HJ94 记票统计

## 一、答案

```python
import sys

data = sys.stdin.read().split()
index = 0

n = int(data[index])
index += 1

# 保存候选人顺序，输出时要按照这个顺序
candidates = data[index:index + n]
index += n

m = int(data[index])
index += 1
votes = data[index:index + m]

# 字典记录每位候选人的票数
counts = {}
for name in candidates:
    counts[name] = 0

invalid = 0

for vote in votes:
    if vote in counts:
        counts[vote] += 1
    else:
        invalid += 1

for name in candidates:
    print(name, ':', counts[name])

print('Invalid', ':', invalid)
```

## 二、题目翻译成人话

有一份候选人名单和很多张选票。

如果选票上的名字在候选人名单里，就给对应候选人加 1 票；如果名字不在名单里，这张票就是无效票。

最后输出：

```text
每位候选人的票数
无效票的总数
```

## 三、样例解析

候选人：

```text
A、B、C、D
```

选票：

```text
A D E CF A GG A B
```

逐张检查：

```text
A  -> A 得1票
D  -> D 得1票
E  -> 不在名单中，无效票+1
CF -> 不在名单中，无效票+1
A  -> A 得2票
GG -> 不在名单中，无效票+1
A  -> A 得3票
B  -> B 得1票
```

最终：

```text
A：3票
B：1票
C：0票
D：1票
Invalid：3票
```

## 四、为什么使用字典

可以把候选人的名字作为字典的键，把票数作为值：

```python
counts = {
    'A': 0,
    'B': 0,
    'C': 0,
    'D': 0
}
```

这样检查选票时，只需要判断：

```python
if vote in counts:
```

如果存在，就说明这是有效票，可以更新对应票数：

```python
counts[vote] += 1
```

如果不存在，就增加无效票数量：

```python
invalid += 1
```

## 五、为什么要先给每位候选人初始化 0 票

```python
for name in candidates:
    counts[name] = 0
```

即使某位候选人一票也没有，也必须输出：

```text
C : 0
```

所以要提前把所有候选人的票数设置为 0。

## 六、为什么保存 `candidates` 列表

虽然字典在 Python 3.7 及之后会保留插入顺序，但这里单独保存候选人列表更清楚：

```python
candidates = data[index:index + n]
```

输出时遍历 `candidates`：

```python
for name in candidates:
    print(name, ':', counts[name])
```

这样能保证输出顺序和题目给出的候选人顺序一致。

## 七、输出格式解释

```python
print(name, ':', counts[name])
```

Python 的 `print` 默认会在多个参数之间加空格。

例如：

```python
print('A', ':', 3)
```

输出：

```text
A : 3
```

正好符合题目要求。

最后一行：

```python
print('Invalid', ':', invalid)
```

输出格式为：

```text
Invalid : 3
```

## 八、输入代码解释

```python
data = sys.stdin.read().split()
```

一次读取所有输入，并按照空白拆分。

样例输入会变成：

```python
['4', 'A', 'B', 'C', 'D', '8', 'A', 'D', 'E', 'CF', 'A', 'GG', 'A', 'B']
```

用 `index` 指针依次读取：

```python
n = int(data[index])
index += 1
```

然后读取 `n` 个候选人、`m` 和 `m` 张选票。

## 九、为什么不需要排序

题目要求候选人按照输入顺序输出，不是按照名字或票数排序。

因此只需要：

```python
for name in candidates:
```

按照原来的列表顺序输出即可。

## 十、复杂度

设候选人数为 `n`，选票数为 `m`：

- 初始化票数：`O(n)`；
- 统计选票：平均 `O(m)`；
- 输出结果：`O(n)`；
- 总时间复杂度：`O(n + m)`；
- 额外空间复杂度：`O(n)`。

## 十一、记忆方式

```text
候选人名单保存顺序
字典初始化每人0票
选票在字典中：对应票数+1
选票不在字典中：Invalid+1
按候选人原顺序输出
最后输出 Invalid
```
