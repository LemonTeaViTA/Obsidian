# HJ80 整型数组合并

## 一、答案

```python
import sys


data = list(map(int, sys.stdin.read().split()))

index = 0

n = data[index]
index += 1
array_a = data[index:index + n]
index += n

m = data[index]
index += 1
array_b = data[index:index + m]

# 合并两个数组，set 会自动去重，sorted 再进行升序排序
numbers = sorted(set(array_a + array_b))

# 题目要求数字之间不加空格，所以直接拼接
answer = ''.join(str(number) for number in numbers)

print(answer)
```

## 二、题目翻译成人话

题目给出两个整数数组：

```text
数组 a
数组 b
```

需要完成三件事：

1. 把两个数组合并；
2. 删除重复数字；
3. 从小到大排序并输出。

特别注意：输出数字时，数字之间不能有空格。

例如：

```text
a = [1, 2, 5]
b = [-1, 0, 3, 2]
```

合并：

```text
[1, 2, 5, -1, 0, 3, 2]
```

去重并排序：

```text
[-1, 0, 1, 2, 3, 5]
```

因为不能加空格，所以输出为：

```text
-101235
```

## 三、这是什么类型的题目

这是一道基础的：

```text
列表合并 + 集合去重 + 排序 + 字符串拼接
```

## 四、`array_a + array_b` 是什么

```python
array_a + array_b
```

表示把两个列表连接起来。

例如：

```python
[1, 2] + [3, 4]
```

结果是：

```python
[1, 2, 3, 4]
```

所以：

```python
array_a + array_b
```

就是把两个数组合并。

## 五、`set` 为什么可以去重

```python
set(array_a + array_b)
```

`set` 表示集合，它会自动去掉重复元素。

例如：

```python
set([1, 2, 2, 3, 1])
```

结果相当于：

```text
{1, 2, 3}
```

本题不要求保留原来的重复次数，因此使用 `set` 很合适。

## 六、`sorted` 是什么

```python
sorted(set(array_a + array_b))
```

`sorted` 会把数据从小到大排序，并返回一个新的列表。

例如：

```python
sorted({5, 1, 3})
```

结果是：

```python
[1, 3, 5]
```

完整过程可以拆开写成：

```python
merged = array_a + array_b       # 合并
unique = set(merged)             # 去重
numbers = sorted(unique)         # 升序排序
```

答案中的一行：

```python
numbers = sorted(set(array_a + array_b))
```

只是把这三步写到了一起。

## 七、为什么不能用 `print(*numbers)`

如果：

```python
numbers = [-1, 0, 1, 2, 3, 5]
```

使用：

```python
print(*numbers)
```

输出是：

```text
-1 0 1 2 3 5
```

数字之间有空格，不符合题目要求。

题目要求的是：

```text
-101235
```

因此要先把数字转成字符串，再直接拼接。

## 八、`''.join(...)` 是什么

```python
answer = ''.join(str(number) for number in numbers)
```

`join` 表示使用指定的字符串连接多个字符串。

这里前面的 `''` 是空字符串，表示连接时不放任何分隔符。

例如：

```python
''.join(['1', '2', '3'])
```

结果是：

```text
123
```

如果写成：

```python
' '.join(['1', '2', '3'])
```

结果则是：

```text
1 2 3
```

本题不能有空格，所以使用空字符串 `''` 作为连接符。

## 九、为什么要使用 `str(number)`

`join` 只能连接字符串，不能直接连接整数。

例如下面这样会报错：

```python
''.join([1, 2, 3])
```

因为 `1、2、3` 是整数，不是字符串。

所以要使用：

```python
str(number)
```

把整数转换成字符串：

```python
str(-1)  # '-1'
str(2)   # '2'
```

## 十、把拼接代码写成普通循环

如果你暂时看不懂：

```python
answer = ''.join(str(number) for number in numbers)
```

可以改成更直观的写法：

```python
answer = ''

for number in numbers:
    answer += str(number)

print(answer)
```

执行过程例如：

```text
开始：answer = ''
加入 -1：answer = '-1'
加入 0： answer = '-10'
加入 1： answer = '-101'
加入 2： answer = '-1012'
```

最后得到 `-101235`。

## 十一、输入代码怎么理解

```python
data = list(map(int, sys.stdin.read().split()))
```

本题输入中没有需要保留的空格，所有内容都是整数，所以可以一次读入全部数字。

例如样例输入：

```text
3
1 2 5
4
-1 0 3 2
```

读取后得到：

```python
data = [3, 1, 2, 5, 4, -1, 0, 3, 2]
```

然后使用 `index` 依次取出数据：

```python
n = data[index]
index += 1
```

读取数组长度后，取出 `n` 个元素：

```python
array_a = data[index:index + n]
index += n
```

再读取 `m` 和数组 `b`。

## 十二、样例解析

输入：

```text
3
1 2 5
4
-1 0 3 2
```

### 1. 合并

```text
[1, 2, 5] + [-1, 0, 3, 2]
= [1, 2, 5, -1, 0, 3, 2]
```

### 2. 去重

重复的 `2` 只保留一个：

```text
[-1, 0, 1, 2, 3, 5]
```

### 3. 拼接输出

```text
-1 + 0 + 1 + 2 + 3 + 5
= -101235
```

## 十三、复杂度

设两个数组总共有 `n + m` 个元素：

- 合并和去重：平均 `O(n + m)`；
- 排序：`O((n + m) log(n + m))`；
- 额外空间复杂度：`O(n + m)`。

## 十四、记忆方式

```text
array_a + array_b：合并
set(...)：去重
sorted(...)：升序排序
''.join(str(number) ...)：不加空格拼接
```

## 十五、常见的输出错误

如果前面的合并、去重、排序都已经完成，最后必须输出排序后的列表。例如：

```python
sorted_ans = [-1, 0, 1, 2, 3, 5]
```

下面这句：

```python
sys.stdout.write('\n')
```

只会输出一个换行符，不会输出数组内容。

正确写法是：

```python
print(''.join(str(number) for number in sorted_ans))
```

也可以写成：

```python
print(''.join(map(str, sorted_ans)))
```

`join` 只能连接字符串，不能直接连接整数，所以不能写：

```python
''.join(sorted_ans)  # 错误：sorted_ans 中是整数
```

还要注意变量名必须完全一致。如果前面定义的是：

```python
sorted_ans
```

后面就不能写成：

```python
sortedans
```

这会被 Python 当成另一个不存在的变量。

本题不能使用：

```python
print(*sorted_ans)
```

因为它会在数字之间自动加入空格，输出成 `-1 0 1 2 3 5`，而题目要求的是不带空格的 `-101235`。
