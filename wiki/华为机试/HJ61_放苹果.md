# HJ61 放苹果

## 一、答案：二维动态规划入门版

```python
import sys

m, n = map(int, sys.stdin.readline().split())
n = min(n, m)

# dp[i][j]：i 个苹果放入 j 个相同盘子的分法数量
dp = [[0] * (n + 1) for _ in range(m + 1)]

# 0 个苹果时，所有盘子都空着，只有 1 种分法
for j in range(n + 1):
    dp[0][j] = 1

for apples in range(1, m + 1):
    for plates in range(1, n + 1):
        if plates > apples:
            dp[apples][plates] = dp[apples][apples]
        else:
            dp[apples][plates] = (
                dp[apples][plates - 1]
                + dp[apples - plates][plates]
            )

print(dp[m][n])
```

## 二、题目翻译成人话

把 `m` 个相同的苹果放到 `n` 个相同的盘子里，允许空盘子，求不同的放法数量。

盘子没有编号，所以 `5+1+1`、`1+5+1` 和 `1+1+5` 是同一种分法。

例如 3 个苹果、2 个盘子只有：

```text
3 + 0
2 + 1
```

答案是 2。

## 三、`dp[i][j]` 表示什么

```text
dp[i][j] = i 个苹果放入 j 个相同盘子的分法数量
```

例如 `dp[3][2]` 表示 3 个苹果放入 2 个相同盘子的分法数量。

最终要输出：

```python
dp[m][n]
```

## 四、为什么分成两种情况

### 情况1：至少有一个空盘子

空着一个盘子，相当于把问题变成：`i` 个苹果放入 `j-1` 个盘子，方案数为：

```text
dp[i][j - 1]
```

### 情况2：没有空盘子

每个盘子先放 1 个苹果，使用 `j` 个苹果，剩下 `i-j` 个苹果继续放入 `j` 个盘子，方案数为：

```text
dp[i - j][j]
```

两种情况不重复：第一种有空盘子，第二种没有空盘子。因此：

```text
dp[i][j] = dp[i][j-1] + dp[i-j][j]
```

## 五、`m=3，n=2` 的填表过程

```text
        盘子数
        0   1   2
苹果0   1   1   1
苹果1   0   1   1
苹果2   0   1   2
苹果3   0   1   2
```

`dp[3][2]`：

```text
dp[3][2] = dp[3][1] + dp[1][2]
         = 1 + 1
         = 2
```

对应两种分法：`3+0` 和 `2+1`。

## 六、终止条件和边界

0 个苹果时：

```python
dp[0][j] = 1
```

所有盘子都空着，只有一种分法。

0 个盘子但还有苹果时，表格默认是 0，表示无法放置。

如果盘子比苹果多：

```python
n = min(n, m)
```

因为多出来的盘子一定是空的。例如 3 个苹果放 5 个盘子，和放 3 个盘子有相同数量的分法。

## 七、代码逐行解释

```python
dp = [[0] * (n + 1) for _ in range(m + 1)]
```

创建二维表：行下标表示苹果数量，列下标表示盘子数量。多出的 1 是为了包含下标 0。

```python
for apples in range(1, m + 1):
    for plates in range(1, n + 1):
```

从小的苹果数量开始，逐格填写表格。

```python
if plates > apples:
    dp[apples][plates] = dp[apples][apples]
```

盘子多于苹果时，多出来的盘子只能空着。

```python
dp[apples][plates] = (
    dp[apples][plates - 1]
    + dp[apples - plates][plates]
)
```

把“有空盘子”和“没有空盘子”两类方案相加。

## 八、和递归版本的关系

递归版本和二维表版本使用同一个公式：

```text
f(i,j) = f(i,j-1) + f(i-j,j)
```

区别是：

```text
递归：从大问题调用小问题
二维表：从小问题开始填到大问题
```

当前答案使用二维表，是为了更直观地学习动态规划。

## 九、复杂度

- 时间复杂度：`O(mn)`；
- 额外空间复杂度：`O(mn)`。

题目中 `m、n <= 10`，可以轻松通过。

## 十、记忆方式

```text
dp[i][j]：i个苹果放入j个相同盘子
有空盘子：dp[i][j-1]
无空盘子：每个盘子先放1个，剩下 dp[i-j][j]
两种情况相加
```
