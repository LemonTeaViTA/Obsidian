# Java 基础篇 MOC (Map of Content)

这里是 Java 基础语法的知识索引地图。Java 是一切生态的地基，这部分涉及从宏观概念、基础语法，到面向对象设计、类型系统等核心基石。

由于基础知识繁杂，我们采用了**主题聚类（Concept-Cluster）**的方式进行了合理的分拆，构建起一张清晰的从点到面的知识网。

---

## 🗺️ 知识体系导航

建议按照以下顺序进行系统学习和复习：

 Java 概述与宏观运行
了解 Java 跨平台的本质、“一次编译处处运行”、JDK/JRE/JVM的区别，以及常用的 Java 应用领域。
👉 **[[Java 概述]]**

 基础语法篇
深究 Java 处理数据的基础方式：基本数据类型、字面量与操作符、自动类型工厂。掌握各种语法糖、关键字（& 与 && 的区别等）的特性与使用。
👉 **[[基础语法]]**

 面向对象核心构建
**Java 世界观的根本。**
死磕三大特性（封装、继承、多态），理解重载与重写、抽象类与接口。深入搞懂构造方法的执行顺序与 this/super 引用。
👉 **[[面向对象核心]]**

 类成员与关键字
**OOP 落地的语法细节集合。**
访问控制（public/protected/default/private）、static / final 的语义、内部类四种形态（成员/静态/局部/匿名）、this 与 super 的引用机制，以及它们如何影响初始化顺序。
👉 **[[类成员与关键字]]**

 对象语义
**对象的"等价"与"流动"。**
死磕 `==` vs `equals()` vs `hashCode()` 的协同契约（与 [[包装类与 Object]] 的 Object 方法呼应）、Java 值传递的真相、对象创建的五种方式、深拷贝与浅拷贝的工程取舍。
👉 **[[对象语义]]**

 String 字符串设计哲学
字符串是 Java 中使用最频繁的对象结构。理解不可变的哲学设计、字符串驻留池、不可变带来的开销，以及 StringBuilder 与 StringBuffer 之间的使用博弈。
👉 **[[String]]**

 包装类与 Object 体系
理解为什么要有包装类的机制和极其经典的缓存池机制。死磕 Object 自带的常用方法以及 `==` 和 `equals()`, `hashCode()` 的协同机制。
👉 **[[包装类与 Object]]**

 异常处理与 I/O 体系
理解 Exception 和 Error 的派生关系；掌握各种 I/O 流的分类与阻塞 IO 机制。
👉 **[[异常与 IO]]**

 注解、反射与 Java 8
框架和高度解耦的实现基石。掌握注解系统、反射的执行性能表现，以及 Java 8 带来的强大特性（Lambda 和 Stream API）。
👉 **[[注解、反射与 Java 8]]**

## 面试考点

### Java 概述

- JDK、JRE、JVM 三者是什么关系？
- 为什么说 Java 是"一次编译，到处运行"？

### 基础语法

- Java 有哪些基本数据类型？各占用多少字节？
- == 和 equals 的区别？
- final、finally、finalize 的区别？
- & 和 && 的区别？
- 如何保证浮点数计算的精度？

### 面向对象

- 面向对象编程有哪些特性？（封装、继承、多态）
- 重载和重写的区别？
- 抽象类和接口有什么区别？
- static 关键字了解吗？静态方法为什么不能被重写？
- final 关键字有什么作用？
- Java 有哪几种内部类？各有什么特点？
- Java 是值传递还是引用传递？
- 深拷贝和浅拷贝的区别？
- Java 创建对象有哪几种方式？

### String

- String、StringBuilder、StringBuffer 的区别？
- `new String("abc")` 创建了几个对象？
- String 是不可变类吗？字符串拼接如何实现？
- intern 方法有什么作用？

### 包装类与 Object

- Integer 127 与 128 的 == 比较结果？缓存机制？
- 如何正确重写 equals？
- 为什么重写 equals 必须同时重写 hashCode？

### 异常与 IO

- Java 异常处理体系？Checked 和 Unchecked 异常区别？
- try-with-resources 是什么？为什么推荐用？
- BIO、NIO、AIO 的区别？
- Java 泛型了解吗？类型擦除有什么影响？

### 注解、反射与 Java 8

- 什么是反射？应用？原理？
- Lambda 表达式了解多少？四大函数式接口？
- Stream 流用过吗？惰性求值怎么理解？
