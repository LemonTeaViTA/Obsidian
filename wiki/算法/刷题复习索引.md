## 代码格式切换

| 项目 | 华为机试（ACM） | LeetCode |
|------|----------------|----------|
| 代码形态 | 可直接运行的完整程序 | `class Solution` 中的平台方法 |
| 输入 | `sys.stdin.readline()`、`sys.stdin.buffer.read()` 等标准输入 | 方法参数由平台传入 |
| 输出 | 按题目要求 `print()`，通常需要处理多组输入 | `return` 返回结果，不主动打印 |
| 主函数 | 不需要额外类包装；程序从顶层开始执行 | 不写 `main`、不读取标准输入 |
| 复习重点 | 输入格式、输出格式、空行和多组数据 | 方法签名、返回值类型、平台给定数据结构 |

### 从 LeetCode 改成 ACM

1. 把 `class Solution` 方法参数改为题目规定的标准输入解析。
2. 把 `return` 改为题目规定的输出，并确认输出顺序和格式。
3. 补齐多组测试、空输入、行数和分隔符处理。
4. 用题目样例作为完整 stdin 跑一次，确认没有依赖平台注入的 `List`、树节点或链表节点。

### 从 ACM 改成 LeetCode

1. 删除 `sys.stdin`、`input()`、`print()` 和顶层执行代码。
2. 保留核心算法，改成平台要求的方法名、参数和返回值。
3. 如果题目给定 `ListNode`、`TreeNode` 等类型，直接使用平台定义，不重复声明输入解析。
4. 检查返回值是否覆盖无解、空数组、单节点等边界，不依赖控制台输出验证。

## 复习状态

新增题目时只需补充来源、模式和状态，不要把完整题解复制到本页。

| 状态 | 含义 |
|------|------|
| 待复习 | 尚未形成稳定解题路径 |
| 练习中 | 能看懂思路，但需要重新编码 |
| 已掌握 | 能独立说明模式、边界和复杂度 |
| 易错重刷 | 曾在边界、输入格式或遍历顺序上出错 |
