# Baize 项目知识库索引（MOC）

> [!warning] 学习资料边界
> 本目录主要同步和分析 PaiSmart 上游实现。架构与原理可以用于学习，旧指标和效果数据不能自动视为个人实验结果；当前安全复习入口见 [[Baize-03-证据与事实边界]]。

> Baize 是一个**企业级 RAG 知识库系统的工程实践 + 算法研究项目**（Spring Boot 3.4.2 / Java 17 后端 + 本地 vLLM）。
> 本笔记是整个 `Baize项目` 文件夹的导航入口（Map of Content），内容同步自项目源文档 `Baize/docs`，最后对齐基线 **2026-05-29**。

> [!tip] 第一次看从哪进
> 先读 [[系统架构总览]] 建立全貌（7 大业务域 + 技术栈），再按兴趣进 RAG 算法线或工程模块线。面试复盘走「核心亮点」那几篇。
