### 第3层：面试准备（5篇精炼文档）

**目标**：2天内准备好面试

```
00-项目概述/
  └─ 📝 一句话介绍项目.md (10分钟)
      "AI Agent 平台是一个基于 Claude 的代码开发自动化平台，
       支持从 PRD 到上线的全流程自动化，
       核心创新点是可配置的工作流引擎和编排系统。"

01-简历亮点/
  └─ 💎 5个可写的项目亮点.md (30分钟)
      
      亮点1：工作流引擎设计
        技术：Spring Boot + MyBatis + 策略模式
        复杂度：3层表结构（workflow-stage-convention）
        亮点：可配置、可扩展、支持版本化
        
      亮点2：编排任务 FAN_OUT 机制
        技术：MQ 解耦 + 多线程并发
        复杂度：动态子任务创建 + 状态聚合
        亮点：支持并行开发，提升效率
        
      亮点3：TDD Hook 强制执行
        技术：Hook 机制 + manifest.json
        复杂度：测试文件锁 + 停止门禁
        亮点：保证代码质量
        
      亮点4：MCP 工具集成
        技术：JSON-RPC + SSE
        复杂度：多服务集成 + 动态配置
        亮点：可扩展工具生态
        
      亮点5：实时状态推送
        技术：WebSocket + Redis Pub/Sub
        复杂度：多实例广播 + 状态同步
        亮点：提升用户体验

02-技术难点/
  └─ 🔥 3个技术难点与解决方案.md (1小时)
      
      难点1：多 Agent 并发冲突
        问题：多个子任务同时修改同一文件
        方案：工作目录隔离 + Git 独立 clone
        效果：避免冲突，CR 阶段人工合并
        
      难点2：审批拒绝后的重试
        问题：Agent 生成的方案不满意
        方案：调用 /task/query 传递反馈
        效果：最多重试3次，超过人工介入
        
      难点3：测试文件被锁定后发现问题
        问题：TDD 锁定后无法修改测试
        方案：依赖 CR 阶段人工审查
        改进空间：可以添加人工解锁接口

03-架构设计/
  └─ 🏗️ 架构设计思路（面试必问）.md (40分钟)
      
      Q1：为什么工作流要可配置？
      A：不同需求类型的流程不同，硬编码无法扩展。
         通过数据库配置，可以灵活组合阶段。
      
      Q2：为什么用 MQ 而不是直接创建子任务？
      A：MQ 解耦，失败可重试，支持削峰。
         直接创建会阻塞主流程。
      
      Q3：为什么要工作目录隔离？
      A：多个 Agent 并行执行，避免文件冲突。
         每个任务独立的 workspace。
      
      Q4：为什么前端用 WebSocket 而不是轮询？
      A：实时性要求高，轮询浪费资源。
         WebSocket 推送，用户体验好。

04-项目亮点总结/
  └─ ⭐ 2分钟项目介绍模板.md (30分钟)
      
      开场（30秒）：
      "我负责开发的是一个 AI Agent 平台，
       核心功能是基于 Claude 实现代码自动化开发。
       用户提交 PRD，系统自动完成领域划分、应用拆分、
       代码开发、测试、审查全流程。"
      
      技术栈（30秒）：
      "后端是 Spring Boot + MyBatis + Redis + MQ，
       前端是 React + TypeScript + WebSocket，
       Agent 侧是 Python + Claude SDK。
       核心创新是可配置的工作流引擎和编排系统。"
      
      个人贡献（60秒）：
      "我主要负责以下几个模块：
       1. 编排任务的 FAN_OUT 机制（支持并行开发）
       2. 工作流审批策略（支持自动重试）
       3. code-agent 的并发执行（工作目录隔离）
       
       遇到的最大挑战是多 Agent 并发冲突，
       通过工作目录隔离和 Git 独立 clone 解决。"

05-常见面试题/
  └─ 💬 20个高频面试问题.md (2小时)
      
      基础问题（5个）
      1. 项目整体架构是什么？
      2. 技术栈选型理由？
      3. 数据库表设计？

      18. 如果重新设计会怎么做？
```
