# 任务创建流程

## 概述

任务创建是 AI Agent Platform 的核心功能之一，通过 `SimpleTaskForm` 组件实现。用户可以通过表单选择任务类型、工作流模板、模型等参数，提交后创建新的任务并跳转到对话页面。

## 核心文件

- **组件文件**: `/src/components/features/home/simple-task-form.tsx`
- **常量定义**: `/src/constants/task-constants.ts`
- **API工具**: `/src/utils/api-base-url.ts`

## 功能特性

### 1. 任务类型支持

系统支持多种任务类型，通过 `FLOW_TYPE_MAP` 常量定义：

- **后端任务** (backend): 后端代码开发
- **前端任务** (frontend_common): 前端页面开发
- **测试任务** (test_workflow): 测试用例生成
- **编排任务** (orchestration): 多节点任务编排

### 2. 动态表单字段

表单字段根据选择的任务类型动态显示：

```typescript
interface SimpleTaskFormData {
  flowType: string;                    // 任务类型
  depUrl: string;                      // DEP任务地址
  templateId: string;                  // 工作流模板ID
  orchestrationNo: string;             // 编排模板编号（编排任务）
  testerName: string;                  // 测试人员姓名（后端任务）
  models: string[];                    // 模型列表（多选，普通任务）
  orchestrationModel: string;          // 编排任务模型��单选）
  pageUrls: string[];                  // 页面地址列表（UI测试）
  // UI测试工作流字段
  appName: string;                     // 应用名称
  appKey: string;                      // 应用Key
  platform: string;                    // 平台（android/ios）
  platformName: string;                // 平台名称
  jobId: number;                       // Job ID
  jobName: string;                     // Job名称
  buildId: string;                     // 构建ID
}
```

## 实现原理

### 1. 工作流加载

根据任务类型动态加载对应的工作流列表：

```typescript
// 获取工作流列表（根据选择的任务类型过滤）
React.useEffect(() => {
  const fetchWorkflows = async () => {
    if (!formData.flowType) {
      setWorkflows([]);
      return;
    }

    setIsLoadingWorkflows(true);
    try {
      const apiBaseUrl = getApiBaseUrl();
      
      // 获取当前任务类型对应的工作流类型
      const workflowTypes = getWorkflowTypesByFlowType(formData.flowType);
      const workflowTypesParam = workflowTypes.length > 0
        ? `&workflowTypes=${workflowTypes.join(",")}`
        : "";

      const response = await axios.get(
        `${apiBaseUrl}/api/promptTemplate/promptParent/listByUser?${workflowTypesParam}`
      );

      if (response.data?.success && Array.isArray(response.data.data)) {
        setWorkflows(response.data.data);
      }
    } catch (error) {
      displayErrorToast("获取工作流列表失败");
    } finally {
      setIsLoadingWorkflows(false);
    }
  };

  fetchWorkflows();
}, [formData.flowType]);
```

### 4. 表单验证

提交前进行完整的表单验证：

```typescript
const validateForm = (): boolean => {
  const newErrors: Partial<Record<keyof SimpleTaskFormData, string>> = {};

  if (!formData.flowType) {
    newErrors.flowType = "请选择任务类型";
  }

  // 编排任务需要选择编排模板
  if (formData.flowType === "orchestration") {
    if (!formData.orchestrationNo) {
      newErrors.orchestrationNo = "请选择编排模板";
    }
    if (!formData.orchestrationModel) {
      newErrors.orchestrationModel = "请选择模型";
    }
  } else {
    // 普通任务需要选择工作流
    if (!formData.templateId) {
      newErrors.templateId = "请选择工作流";
    }
  }

  if (!formData.depUrl.trim()) {
    newErrors.depUrl = formData.flowType === "orchestration"
      ? "请输入产品任务DEP链接"
      : "请输入DEP地址";
  }

  // 后端任务类型的测试人员字段为必填
  if (formData.flowType === "backend" && !formData.testerName.trim()) {
    newErrors.testerName = "请输入测试人员姓名";
  }

  // UI用例工作流的页面地址字段为必填
  if (isUITestWorkflow && formData.pageUrls.length === 0) {
    newErrors.pageUrls = "请选择页面地址";
  }

  setErrors(newErrors);
  return Object.keys(newErrors).length === 0;
};
```

### 5. 任务提交

根据任务类型构建不同的请求数据：

```typescript
const handleSubmit = async (e: React.FormEvent) => {
  e.preventDefault();

  if (!validateForm()) {
    return;
  }

  setIsSubmitting(true);

  try {
    const apiBaseUrl = getApiBaseUrl();

    // 编排任务使用不同的提交逻辑
    if (formData.flowType === "orchestration") {
      const inputData = {
        depUrl: formData.depUrl,
        flowType: "orchestration",
        model: formData.orchestrationModel,
      };

      const requestData = {
        input: JSON.stringify(inputData),
        orchestrationNo: formData.orchestrationNo,
      };

      const response = await axios.post(
        `${apiBaseUrl}/api/taskInfo/create`,
        requestData,
      );

      if (response.data && response.data.success) {
        displaySuccessToast("编排任务创建成功");
        const taskId = response.data.data?.taskId || response.data.data;
        if (taskId) {
          navigate(`/orchestration/${taskId}`);
        }
      }
      return;
    }

    // 普通任务提交逻辑
    const isMultiModel = formData.models.length > 1;
    const inputData = {
      flowType: formData.flowType,
      depUrl: formData.depUrl,
      templateId: formData.templateId,
      // 单模型时在 input 中传 model 字段
      ...(!isMultiModel &&
        formData.models.length === 1 && {
          model: formData.models[0],
        }),
      // 后端任务类型需要包含测试人员姓名
      ...(formData.flowType === "backend" && {
        testerName: formData.testerName,
      }),
      // UI用例工作流需要包含页面地址和三级联动字段
      ...(isUITestWorkflow && {
        pageUrls: formData.pageUrls,
        appName: formData.appName,
        appKey: formData.appKey,
        platform: formData.platform,
        platformName: formData.platformName,
        jobId: formData.jobId,
        jobName: formData.jobName,
        buildId: formData.buildId,
      }),
    };

    // 构建请求数据
    const requestData: {
      input: string;
      status: number;
      username: string;
      models?: string[];
      multiModel?: boolean;
    } = {
      input: JSON.stringify(inputData),
      status: 100, // 默认状态：初始化
      username: window.ssoData.name,
    };

    // 多模型时在 requestData 中与 input 平级传 models 和 multiModel
    if (isMultiModel) {
      requestData.models = formData.models;
      requestData.multiModel = true;
    }

    const response = await axios.post(
      `${apiBaseUrl}/api/taskInfo/create`,
      requestData,
    );

    if (response.data.success) {
      const taskId = response.data.data;
      if (taskId) {
        displaySuccessToast("任务创建成功，正在跳转...");
        navigate(`/conversations/${taskId}`);
      }
    }
  } catch (error) {
    console.error("Submit error:", error);
    if (axios.isAxiosError(error)) {
      if (error.response) {
        const errorMsg = error.response.data?.message ||
          `服务器错误 (${error.response.status})`;
        displayErrorToast(errorMsg);
      } else if (error.request) {
        displayErrorToast("网络连接失败，请检查网络连接");
      } else {
        displayErrorToast("请求配置错误，请重试");
      }
    } else {
      displayErrorToast("创建任务失败，请稍后重试");
    }
  } finally {
    setIsSubmitting(false);
  }
};
```

## 数据流

```
用户操作
  ↓
选择任务类型 (flowType)
  ↓
加载对应工作流列表 (GET /api/promptTemplate/promptParent/listByUser)
  ↓
选择工作流模板 (templateId)
  ↓
填写其他必填字段
  - DEP地址
  - 模型选择
  - 任务类型特定字段（测试人员、页面地址等）
  ↓
表单验证 (validateForm)
  ↓
构建请求数据 (inputData + requestData)
  ↓
提交到后端 (POST /api/taskInfo/create)
  ↓
获取任务ID
  ↓
跳转到任务对话页面 (/conversations/{taskId})
```

### URL参数预填充

支持通过URL参数自动填充DEP地址：

```
# URL格式
https://example.com/#/?dep=https://dep.example.com/task/123

# 组件内部自动解析
useEffect(() => {
  const { hash } = window.location;
  if (hash) {
    const params = new URLSearchParams(hashContent);
    const depParam = params.get("dep");
    if (depParam) {
      const decodedDep = decodeURIComponent(depParam);
      setFormData((prev) => ({ ...prev, depUrl: decodedDep }));
    }
  }
}, []);
```

## 常见问题

### 1. 工作流列表为空？

**原因**: 可能未选择任务类型，或该任务类型下没有可用工作流。

**解决方案**: 
- 确保先选择任务类型
- 检查 `FLOW_TYPE_MAP` 中该任务类型对应的 `workflowTypes` 是否正确
- 确认后端有对应类型的工作流模板

### 2. 模型选择后显示不正确？

**原因**: 模型配置数据未加载完成或默认模型设置失败。

**解决方案**:
```typescript
// 使用 useModelConfig hook 确保数据加载
const { data: modelConfigs = [], isLoading: isLoadingModels } = useModelConfig();
const defaultModel = useDefaultModel();

// 等待加载完成后设置默认值
useEffect(() => {
  if (defaultModel && formData.models.length === 0) {
    setFormData((prev) => ({ ...prev, models: [defaultModel] }));
  }
}, [defaultModel, formData.models.length]);
```

### 3. UI测试工作流的三级联动不工作？

**原因**: 数据依赖未正确传递或状态更新时机不对。

**解决方案**:
```typescript
// 选择应用时清空下级数据
const handleAppChange = (appKey: string) => {
  const app = appList.find((a) => a.appKey === appKey);
  if (!app) return;
  setFormData((prev) => ({
    ...prev,
    appKey: app.appKey,
    appName: app.appName,
    platform: "",      // 清空平台
    platformName: "",
    jobId: 0,          // 清空Job
    jobName: "",
    pageUrls: [],      // 清空页面
  }));
  setPlatformList(app.platforms || []);
  setJobList([]);
  setPageOptions([]);
};
```

### 4. 提交后没有跳转？

**原因**: 后端返回的任务ID格式不正确或导航失败。

**解决方案**:
```typescript
if (response.data.success) {
  const taskId = response.data.data?.taskId || response.data.data;
  if (taskId) {
    displaySuccessToast("任务创建成功，正在跳转...");
    navigate(`/conversations/${taskId}`);
  } else {
    displayErrorToast("创建成功但未返回任务ID，请稍后在任务列表中查看");
  }
}
```

### 5. 多模型任务和单模型任务的区别？

**区别**:
- **单模型**: `model` 字段在 `input` 对象内部，创建一个任务
- **多模型**: `models` 数组和 `multiModel` 标志在 `requestData` 顶层，后端会为每个模型创建独立的子任务

```typescript
// 单模型
{
  input: JSON.stringify({
    flowType: "backend",
    depUrl: "...",
    model: "claude-opus-4"  // 在input内部
  }),
  status: 100,
  username: "user"
}

// 多模型
{
  input: JSON.stringify({
    flowType: "backend",
    depUrl: "..."
    // 没有model字段
  }),
  models: ["claude-opus-4", "gpt-4"],  // 在外层
  multiModel: true,                     // 标识为多模型
  status: 100,
  username: "user"
}
```
