# 状态管理

## 概述

AI Agent Platform 采用多层次的状态管理方案，结合 Zustand、TanStack Query 和 React Context，针对不同类型的状态选择最适合的管理方式。Zustand 用于全局UI状态，TanStack Query 管理服务端数据状态，React Context 处理跨组件共享的特殊状态。

## 核心技术栈

- **Zustand**: 轻量级全局状态管理
- **TanStack Query (React Query)**: 服务端数据状态管理
- **React Context**: 跨组件状态共享

## Zustand Stores

### 1. 事件流状态 (use-event-store.ts)

管理对话消息和事件流。

```typescript
// src/stores/use-event-store.ts
import { create } from 'zustand';

interface Event {
  id: string;
  timestamp: string;
  source: 'user' | 'agent' | 'environment';
  // ... 其他字段
}

interface EventStoreState {
  events: Event[];
  addEvent: (event: Event, taskId?: string) => void;
  clearEvents: () => void;
  getEventsByTaskId: (taskId: string) => Event[];
}

export const useEventStore = create<EventStoreState>((set, get) => ({
  events: [],
  
  addEvent: (event, taskId) => set((state) => ({
    events: [...state.events, { ...event, taskId }]
  })),
  
  clearEvents: () => set({ events: [] }),
  
  getEventsByTaskId: (taskId) => {
    return get().events.filter((e) => e.taskId === taskId);
  },
}));
```

**使用场景**:
- 对话消息展示
- 事件流实时更新
- WebSocket消息存储

**使用示例**:
```typescript
function ChatInterface() {
  const { events, addEvent } = useEventStore();
  
  return (
    <div>
      {events.map((event) => (
        <MessageItem key={event.id} event={event} />
      ))}
    </div>
  );
}
```

### 2. 任务状态 (task-status-store.ts)

管理当前任务的执行状态。

```typescript
// src/stores/task-status-store.ts
import { create } from 'zustand';

interface TaskStatusState {
  taskStatus: number | null;
  setTaskStatus: (status: number) => void;
  clearTaskStatus: () => void;
}

export const useTaskStatusStore = create<TaskStatusState>((set) => ({
  taskStatus: null,
  
  setTaskStatus: (status) => set({ taskStatus: status }),
  
  clearTaskStatus: () => set({ taskStatus: null }),
}));
```

**状态映射**:
- `100`: 初始化
- `200`: 执行中
- `500`: 已完成
- `999`: 已终止

**使用示例**:
```typescript
function TaskStatusBadge() {
  const taskStatus = useTaskStatusStore((state) => state.taskStatus);
  
  const statusText = {
    100: '初始化',
    200: '执行中',
    500: '已完成',
    999: '已终止',
  }[taskStatus || 0] || '未知';
  
  return <Badge>{statusText}</Badge>;
}
```

### 3. 会话状态 (session-status-store.ts)

管理多子任务模式下每个会话的状态。

```typescript
// src/stores/session-status-store.ts
import { create } from 'zustand';

interface SessionStatusState {
  sessionStatuses: Record<string, number>; // taskId -> status
  setSessionStatus: (taskId: string, status: number) => void;
  getSessionStatus: (taskId: string) => number | undefined;
  clearSessionStatus: (taskId: string) => void;
  clearAllSessionStatus: () => void;
}

export const useSessionStatusStore = create<SessionStatusState>((set, get) => ({
  sessionStatuses: {},
  
  setSessionStatus: (taskId, status) => set((state) => ({
    sessionStatuses: {
      ...state.sessionStatuses,
      [taskId]: status,
    }
  })),
  
  getSessionStatus: (taskId) => {
    return get().sessionStatuses[taskId];
  },
  
  clearSessionStatus: (taskId) => set((state) => {
    const newStatuses = { ...state.sessionStatuses };
    delete newStatuses[taskId];
    return { sessionStatuses: newStatuses };
  }),
  
  clearAllSessionStatus: () => set({ sessionStatuses: {} }),
}));
```

**使用场景**:
- 多子任务模式下，每个子任务独立的会话状态
- 区分任务总体状态和会话执行状态

## TanStack Query (React Query)

### 1. 查询Hooks (Query)

用于获取和缓存服务端数据。

```typescript
// src/hooks/query/use-task-detail.ts
import { useQuery } from '@tanstack/react-query';
import axios from 'axios';
import { getApiBaseUrl } from '#/utils/api-base-url';

export function useTaskDetail(taskId: string | undefined) {
  return useQuery({
    queryKey: ['task-detail', taskId],
    queryFn: async () => {
      if (!taskId) throw new Error('Task ID is required');
      
      const apiBaseUrl = getApiBaseUrl();
      const response = await axios.get(
        `${apiBaseUrl}/api/taskInfo/detail`,
        { params: { id: taskId } }
      );
      
      if (!response.data.success) {
        throw new Error(response.data.message || '获取任务详情失败');
      }
      
      return response.data.data;
    },
    enabled: !!taskId, // 只有taskId存在时才执行查询
    staleTime: 30000, // 30秒内数据视为新鲜
    gcTime: 5 * 60 * 1000, // 5分钟后清理缓存
  });
}
```

**关键配置**:
- `queryKey`: 查询唯一标识，用于缓存管理
- `queryFn`: 数据获取函数
- `enabled`: 条件查询开关
- `staleTime`: 数据新鲜度时间
- `gcTime`: 垃圾回收时间

**使用示例**:
```typescript
function TaskDetailPage({ taskId }: { taskId: string }) {
  const { data, isLoading, error, refetch } = useTaskDetail(taskId);
  
  if (isLoading) return <Loading />;
  if (error) return <Error message={error.message} />;
  
  return (
    <div>
      <h1>{data.taskName}</h1>
      <button onClick={() => refetch()}>刷新</button>
    </div>
  );
}
```

### 2. 变更Hooks (Mutation)

用于修改服务端数据。

```typescript
// src/hooks/mutation/use-delete-task.ts
import { useMutation, useQueryClient } from '@tanstack/react-query';
import { deleteTask } from '#/api/task-service/task-service.api';
import { displaySuccessToast, displayErrorToast } from '#/utils/custom-toast-handlers';

export function useDeleteTask() {
  const queryClient = useQueryClient();
  
  return useMutation({
    mutationFn: deleteTask,
    
    onSuccess: () => {
      // 删除成功后刷新任务列表
      queryClient.invalidateQueries({ queryKey: ['tasks-with-summary'] });
      displaySuccessToast('任务删除成功');
    },
    
    onError: (error: Error) => {
      displayErrorToast(error.message || '任务删除失败');
    },
  });
}
```

**关键配置**:
- `mutationFn`: 变更操作函数
- `onSuccess`: 成功回调，通常用于刷新缓存
- `onError`: 失败回调，显示错误信息
- `onMutate`: 乐观更新（可选）

**使用示例**:
```typescript
function DeleteTaskButton({ taskId }: { taskId: number }) {
  const deleteTaskMutation = useDeleteTask();
  
  const handleDelete = async () => {
    await deleteTaskMutation.mutateAsync(taskId);
  };
  
  return (
    <button
      onClick={handleDelete}
      disabled={deleteTaskMutation.isPending}
    >
      {deleteTaskMutation.isPending ? '删除中...' : '删除'}
    </button>
  );
}
```

### 3. 缓存失效策略

```typescript
import { useQueryClient } from '@tanstack/react-query';

function Component() {
  const queryClient = useQueryClient();
  
  // 1. 失效特定查询
  queryClient.invalidateQueries({ queryKey: ['task-detail', taskId] });
  
  // 2. 失效所有匹配的查询
  queryClient.invalidateQueries({ queryKey: ['tasks'] });
  
  // 3. 使用predicate函数
  queryClient.invalidateQueries({
    predicate: (query) => query.queryKey[0] === 'task-detail'
  });
  
  // 4. 直接设置数据
  queryClient.setQueryData(['task-detail', taskId], newData);
  
  // 5. 移除查询
  queryClient.removeQueries({ queryKey: ['task-detail', taskId] });
}
```

## 状态选择指南

| 状态类型 | 推荐方案 | 原因 |
|---------|---------|------|
| UI状态（本地） | useState | 简单、局部状态 |
| UI状态（全局） | Zustand | 性能好、API简单 |
| 服务端数据 | TanStack Query | 自动缓存、重试、背景更新 |
| 表单状态 | React Hook Form | 专业表单解决方案 |
| WebSocket状态 | React Context | 需要Provider模式 |
| 路由状态 | React Router | 原生支持 |

## 最佳实践

### 1. Zustand Store设计

```typescript

  taskStatus: null,

// ❌ 不推荐：过大的Store
export const useAppStore = create((set) => ({
  taskStatus: null,
  userInfo: null,
  settings: {},
  // ... 太多不相关的状态
}));
```

### 2. TanStack Query键管理

```typescript
// ✅ 推荐：使用queryKey工厂函数
export const queryKeys = {
  tasks: {
    all: ['tasks'] as const,
    lists: () => [...queryKeys.tasks.all, 'list'] as const,
    list: (filters: string) => [...queryKeys.tasks.lists(), filters] as const,
    details: () => [...queryKeys.tasks.all, 'detail'] as const,
    detail: (id: string) => [...queryKeys.tasks.details(), id] as const,
  },
};

// 使用
useQuery({
  queryKey: queryKeys.tasks.detail(taskId),
  // ...
});
```

### 3. 避免状态重复

```typescript
// ❌ 不推荐：状态重复
const { data: taskDetail } = useTaskDetail(taskId);
```
