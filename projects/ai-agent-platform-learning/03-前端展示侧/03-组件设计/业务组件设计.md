# 业务组件设计

## 概述

业务组件是与特定业务逻辑紧密相关的UI组件，封装了复杂的交互逻辑和数据处理。AI Agent Platform 的核心业务组件包括对话面板、任务卡片、事件渲染组件、审批组件等。

## 核心业务组件

### 1. 对话面板组件

#### ChatInterface - 聊天界面

完整的对话交互界面，包含消息列表、输入框、工具栏等。

```typescript
// src/components/features/chat/chat-interface.tsx
import React, { useRef, useEffect } from 'react';
import { useEventStore } from '#/stores/use-event-store';
import { useCustomAgentWebSocket } from '#/contexts/custom-agent-websocket-context';
import { MessageItem } from './message-item';
import { ChatInput } from './chat-input';

interface ChatInterfaceProps {
  taskId: string;
}

export function ChatInterface({ taskId }: ChatInterfaceProps) {
  const messagesEndRef = useRef<HTMLDivElement>(null);
  const { events } = useEventStore();
  const ws = useCustomAgentWebSocket();

  // 自动滚动到底部
  useEffect(() => {
    messagesEndRef.current?.scrollIntoView({ behavior: 'smooth' });
  }, [events]);

  // 过滤当前任务的事件
  const taskEvents = events.filter((e) => e.taskId === taskId);

  return (
    <div className="flex flex-col h-full">
      {/* 消息列表 */}
      <div className="flex-1 overflow-y-auto p-4 space-y-4">
        {taskEvents.map((event) => (
          <MessageItem key={event.id} event={event} />
        ))}
        <div ref={messagesEndRef} />
      </div>

      {/* 输入区域 */}
      <div className="border-t border-[#27272A] p-4">
        <ChatInput
          onSend={(message) => ws?.sendMessage(message)}
          disabled={ws?.connectionState !== 'OPEN'}
        />
      </div>
    </div>
  );
}
```

#### MessageItem - 消息项

单条消息的渲染组件，支持用户消息、Agent消息和系统消息。

```typescript
// src/components/features/chat/message-item.tsx
import React from 'react';
import { Avatar } from '@heroui/react';
import { User, Bot } from 'lucide-react';
import { ActionEvent } from '#/components/v1/action-event';
import { ObservationEvent } from '#/components/v1/observation-event';

interface MessageItemProps {
  event: any;
}

export function MessageItem({ event }: MessageItemProps) {
  // 用户消息
  if (event.source === 'user') {
    return (
      <div className="flex gap-3 justify-end">
        <div className="max-w-[70%] bg-[#22D3EE] text-white rounded-lg p-3">
          {event.llm_message?.content?.map((item: any, index: number) => {
            if (item.type === 'text') {
              return <p key={index}>{item.text}</p>;
            }
            if (item.type === 'image') {
              return (
                <div key={index} className="mt-2">
                  {item.image_urls?.map((url: string, i: number) => (
                    <img key={i} src={url} alt="" className="rounded" />
                  ))}
                </div>
              );
            }
            return null;
          })}
        </div>
        <Avatar icon={<User />} className="bg-[#22D3EE]" />
      </div>
    );
  }

  // Agent消息（带Action）
  if (event.action) {
    return (
      <div className="flex gap-3">
        <Avatar icon={<Bot />} className="bg-[#8B5CF6]" />
        <div className="flex-1 max-w-[70%]">
          <ActionEvent event={event} />
        </div>
      </div>
    );
  }

  // Observation消息
  if (event.observation) {
    return (
      <div className="flex gap-3">
        <div className="w-10" /> {/* 占位，保持对齐 */}
        <div className="flex-1 max-w-[70%]">
          <ObservationEvent event={event} />
        </div>
      </div>
    );
  }

  // 普通Agent消息
  return (
    <div className="flex gap-3">
      <Avatar icon={<Bot />} className="bg-[#8B5CF6]" />
      <div className="flex-1 max-w-[70%] bg-[#27272A] rounded-lg p-3">
        <p className="text-white">{event.llm_message?.content?.[0]?.text}</p>
      </div>
    </div>
  );
}
```

#### ChatInput - 聊天输入框

支持文本输入、图片上传、快捷命令等功能。

```typescript
// src/components/features/chat/chat-input.tsx
import React, { useState, useRef } from 'react';
import { Textarea, Button } from '@heroui/react';
import { Send, Image, Paperclip } from 'lucide-react';

interface ChatInputProps {
  onSend: (message: string) => void;
  disabled?: boolean;
}

export function ChatInput({ onSend, disabled }: ChatInputProps) {
  const [message, setMessage] = useState('');
  const [images, setImages] = useState<string[]>([]);
  const fileInputRef = useRef<HTMLInputElement>(null);

  const handleSend = () => {
    if (!message.trim() && images.length === 0) return;

    // 构建消息内容
    const content = [];
    if (message.trim()) {
      content.push({ type: 'text', text: message });
    }
    if (images.length > 0) {
      content.push({ type: 'image', image_urls: images });
    }

    onSend(JSON.stringify(content));
    setMessage('');
    setImages([]);
  };

  const handleKeyDown = (e: React.KeyboardEvent) => {
    if (e.key === 'Enter' && !e.shiftKey) {
      e.preventDefault();
      handleSend();
    }
  };

  const handleImageUpload = (e: React.ChangeEvent<HTMLInputElement>) => {
    const files = e.target.files;
    if (!files) return;

    // 处理图片上传逻辑
    // ...
  };

  return (
    <div className="space-y-2">
      {/* 图片预览 */}
      {images.length > 0 && (
        <div className="flex gap-2 flex-wrap">
          {images.map((url, index) => (
            <div key={index} className="relative">
              <img src={url} alt="" className="w-20 h-20 object-cover rounded" />
              <button
                onClick={() => setImages(images.filter((_, i) => i !== index))}
                className="absolute -top-2 -right-2 bg-red-500 text-white rounded-full w-5 h-5 flex items-center justify-center text-xs"
              >
                ×
              </button>
            </div>
          ))}
        </div>
      )}

      {/* 输入框 */}
      <div className="flex gap-2">
        <Textarea
          value={message}
          onChange={(e) => setMessage(e.target.value)}
          onKeyDown={handleKeyDown}
          placeholder="输入消息... (Shift+Enter换行)"
          minRows={1}
          maxRows={5}
          disabled={disabled}
          className="flex-1"
        />
        
        {/* 工具栏 */}
        <div className="flex flex-col gap-2">
          <Button
            isIconOnly
            variant="light"
            onClick={() => fileInputRef.current?.click()}
            disabled={disabled}
          >
            <Image size={20} />
          </Button>
          <Button
            isIconOnly
            color="primary"
            onClick={handleSend}
            disabled={disabled || (!message.trim() && images.length === 0)}
          >
            <Send size={20} />
          </Button>
        </div>

        <input
          ref={fileInputRef}
          type="file"
          accept="image/*"
          multiple
          onChange={handleImageUpload}
          className="hidden"
        />
      </div>
    </div>
  );
}
```

### 3. V1协议事件组件

#### ActionEvent - Action事件渲染

渲染Agent执行的Action（工具调用）。

```typescript
// src/components/v1/action-event.tsx
import React, { useState } from 'react';
import { Card, CardHeader, CardBody, Button } from '@heroui/react';
import { ChevronDown, ChevronRight, Terminal, FileEdit, Brain } from 'lucide-react';
import { Prism as SyntaxHighlighter } from 'react-syntax-highlighter';
import { vscDarkPlus } from 'react-syntax-highlighter/dist/esm/styles/prism';

interface ActionEventProps {
  event: any;
}

export function ActionEvent({ event }: ActionEventProps) {
  const [isExpanded, setIsExpanded] = useState(false);
  const action = event.action;

  // 根据action类型选择图标
  const getIcon = () => {
    switch (action.kind) {
      case 'ExecuteBashAction':
        return <Terminal size={20} className="text-blue-400" />;
      case 'FileEditorAction':
        return <FileEdit size={20} className="text-green-400" />;
      case 'ThinkAction':
        return <Brain size={20} className="text-purple-400" />;
      default:
        return null;
    }
  };

  // 渲染Action内容
  const renderActionContent = () => {
    switch (action.kind) {
      case 'ExecuteBashAction':
        return (
          <div>
            <p className="text-sm text-default-500 mb-2">执行命令:</p>
            <SyntaxHighlighter
              language="bash"
              style={vscDarkPlus}
              customStyle={{
                margin: 0,
                borderRadius: '8px',
                fontSize: '14px',
              }}
            >
              {action.command || ''}
            </SyntaxHighlighter>
          </div>
        );

      case 'FileEditorAction':
        return (
          <div>
            <p className="text-sm text-default-500 mb-2">
              {action.command === 'view' ? '查看文件' : '编辑文件'}: {action.path}
            </p>
            {action.command === 'edit' && action.new_str && (
              <SyntaxHighlighter
                language="diff"
                style={vscDarkPlus}
                customStyle={{
                  margin: 0,
                  borderRadius: '8px',
                  fontSize: '14px',
                }}
              >
                {`- ${action.old_str || ''}\n+ ${action.new_str}`}
              </SyntaxHighlighter>
            )}
          </div>
        );

      case 'ThinkAction':
        return (
          <div className="text-sm text-default-700">
            <p className="italic">{action.thought || '思考中...'}</p>
          </div>
        );

      default:
        return (
          <pre className="text-xs overflow-auto bg-[#1E1E1E] p-3 rounded">
            {JSON.stringify(action, null, 2)}
          </pre>
        );
    }
  };

  return (
    <Card className="bg-[#27272A] border border-[#3F3F46]">
      <CardHeader className="flex justify-between items-center">
        <div className="flex items-center gap-2">
          {getIcon()}
          <span className="font-semibold">{action.kind}</span>
        </div>
        <Button
          isIconOnly
          size="sm"
          variant="light"
          onClick={() => setIsExpanded(!isExpanded)}
        >
          {isExpanded ? <ChevronDown size={16} /> : <ChevronRight size={16} />}
        </Button>
      </CardHeader>

      {isExpanded && (
        <CardBody>
          {renderActionContent()}
        </CardBody>
      )}
    </Card>
  );
}
```

#### ObservationEvent - Observation事件渲染

渲染Action执行结果。

```typescript
// src/components/v1/observation-event.tsx
import React, { useState } from 'react';
import { Card, CardHeader, CardBody, Button, Chip } from '@heroui/react';
import { ChevronDown, ChevronRight, CheckCircle, XCircle } from 'lucide-react';
import { Prism as SyntaxHighlighter } from 'react-syntax-highlighter';
import { vscDarkPlus } from 'react-syntax-highlighter/dist/esm/styles/prism';

interface ObservationEventProps {
  event: any;
}

export function ObservationEvent({ event }: ObservationEventProps) {
  const [isExpanded, setIsExpanded] = useState(true);
  const observation = event.observation;

  // 判断是否成功
  const isSuccess = !observation.is_error && 
                    observation.exit_code !== undefined ? 
                    observation.exit_code === 0 : true;

  // 渲染Observation内容
  const renderObservationContent = () => {
    switch (observation.kind) {
      case 'ExecuteBashObservation':
        return (
          <div>
            {observation.output && (
              <SyntaxHighlighter
                language="bash"
                style={vscDarkPlus}
                customStyle={{
                  margin: 0,
                  borderRadius: '8px',
                  fontSize: '14px',
                  maxHeight: '400px',
                }}
              >
                {observation.output}
              </SyntaxHighlighter>
            )}
            {observation.exit_code !== undefined && (
              <p className="text-sm text-default-500 mt-2">
                退出码: {observation.exit_code}
              </p>
            )}
          </div>
        );

      case 'FileEditorObservation':
        return (
          <div>
            <p className="text-sm text-default-500 mb-2">
              {observation.command === 'view' ? '文件内容' : '修改结果'}
            </p>
            <SyntaxHighlighter
              language="text"
              style={vscDarkPlus}
              customStyle={{
                margin: 0,
                borderRadius: '8px',
                fontSize: '14px',
                maxHeight: '400px',
              }}
            >
              {observation.output || '操作成功'}
            </SyntaxHighlighter>
          </div>
        );

      case 'TaskTrackerObservation':
        return (
          <div>
            {observation.task_list && observation.task_list.length > 0 ? (
              <div className="space-y-2">
                <p className="text-sm font-semibold mb-3">任务列表:</p>
                {observation.task_list.map((task: any, index: number) => (
                  <div
                    key={index}
                    className="flex items-start gap-2 p-2 bg-[#1E1E1E] rounded"
                  >
                    <Chip
                      color={task.status === 'completed' ? 'success' : 'default'}
                      size="sm"
                      variant="flat"
                    >
                      {task.status === 'completed' ? '✓' : '○'}
                    </Chip>
                    <div className="flex-1">
                      <p className="text-sm">{task.title || task.content}</p>
                      {task.notes && (
                        <p className="text-xs text-default-500 mt-1">{task.notes}</p>
                      )}
                    </div>
                  </div>
                ))}
              </div>
            ) : (
              <p className="text-sm text-default-500">{observation.content}</p>
            )}
          </div>
        );

      default:
        return (
          <pre className="text-xs overflow-auto bg-[#1E1E1E] p-3 rounded">
            {JSON.stringify(observation, null, 2)}
          </pre>
        );
    }
  };

  return (
    <Card className="bg-[#1E1E1E] border border-[#27272A]">
      <CardHeader className="flex justify-between items-center">
        <div className="flex items-center gap-2">
          {isSuccess ? (
            <CheckCircle size={20} className="text-green-400" />
          ) : (
            <XCircle size={20} className="text-red-400" />
          )}
          <span className="font-semibold">
            {isSuccess ? '执行成功' : '执行失败'}
          </span>
        </div>
        <Button
          isIconOnly
          size="sm"
          variant="light"
          onClick={() => setIsExpanded(!isExpanded)}
        >
          {isExpanded ? <ChevronDown size={16} /> : <ChevronRight size={16} />}
        </Button>
      </CardHeader>

      {isExpanded && (
        <CardBody>
          {renderObservationContent()}
        </CardBody>
      )}
    </Card>
  );
}
```

### 4. 任务进度组件

#### TaskProgressPanel - 任务进度面板

显示任务分解的待办事项列表。

```typescript
// src/components/features/task/task-progress-panel.tsx
import React from 'react';
import { Card, CardHeader, CardBody, Chip, Progress } from '@heroui/react';
import { CheckCircle, Circle, XCircle } from 'lucide-react';
import { useTaskProgressStore } from '#/stores/task-progress-store';

interface TaskProgressPanelProps {
  taskId: string;
}

export function TaskProgressPanel({ taskId }: TaskProgressPanelProps) {
  const getTaskList = useTaskProgressStore((state) => state.getTaskList);
  const taskList = getTaskList(taskId);

  if (!taskList || taskList.length === 0) {
    return null;
  }

  // 计算进度
  const completedCount = taskList.filter((t) => t.status === 'completed').length;
  const progress = (completedCount / taskList.length) * 100;

  return (
    <Card className="w-full">
      <CardHeader className="flex flex-col items-start gap-2">
        <div className="flex justify-between w-full">
          <h3 className="text-lg font-semibold">任务进度</h3>
          <span className="text-sm text-default-500">
            {completedCount} / {taskList.length}
          </span>
        </div>
        <Progress value={progress} color="primary" className="w-full" />
      </CardHeader>

      <CardBody>
        <div className="space-y-3">
          {taskList.map((task) => (
            <div
              key={task.id}
              className="flex items-start gap-3 p-3 bg-[#27272A] rounded-lg"
            >
              {/* 状态图标 */}
              {task.status === 'completed' ? (
                <CheckCircle size={20} className="text-green-400 flex-shrink-0 mt-0.5" />
              ) : task.status === 'failed' ? (
                <XCircle size={20} className="text-red-400 flex-shrink-0 mt-0.5" />
              ) : (
                <Circle size={20} className="text-default-400 flex-shrink-0 mt-0.5" />
              )}

              {/* 任务内容 */}
              <div className="flex-1 min-w-0">
                <p
                  className={`text-sm ${
                    task.status === 'completed'
                      ? 'line-through text-default-500'
                      : 'text-white'
                  }`}
                >
                  {task.content}
                </p>
                {task.activeForm && (
                  <p className="text-xs text-default-500 mt-1">{task.activeForm}</p>
                )}
              </div>

              {/* 状态标签 */}
              <Chip
                size="sm"
                variant="flat"
                color={
                  task.status === 'completed'
                    ? 'success'
                    : task.status === 'failed'
                    ? 'danger'
                    : 'default'
                }
              >
                {task.status === 'completed'
                  ? '已完成'
                  : task.status === 'failed'
                  ? '失败'
                  : '待处理'}
              </Chip>
            </div>
          ))}
        </div>
      </CardBody>
    </Card>
  );
}
```

## 组件设计原则

### 1. 单一职责

每个组件只负责一个明确的功能。

```typescript
// ✅ 推荐：职责单一
<ChatInterface />      // 聊天界面
<MessageItem />        // 单条消息
<ChatInput />          // 输入框

// ❌ 不推荐：职责过多
<ChatPanel />         // 包含了界面、消息、输入所有逻辑
```

### 2. 可组合性

组件应该易于组合使用。

```typescript
// ✅ 推荐：可组合
<Card>
  <CardHeader>标题</CardHeader>
  <CardBody>内容</CardBody>
  <CardFooter>操作</CardFooter>
</Card>

// ❌ 不推荐：不可组合
<Card title="标题" content="内容" footer={<Button />} />
```

### 3. Props接口清晰

使用TypeScript定义清晰的Props接口。

```typescript
// ✅ 推荐：类型明确
interface TaskCardProps {
  task: Task;
  onView: (taskId: string) => void;
  onDelete?: (taskId: string) => void;
}

// ❌ 不推荐：类型不明确
interface TaskCardProps {
  data: any;
  onClick: Function;
}
```

### 4. 状态提升

将共享状态提升到父组件或全局状态管理。

```typescript
// ✅ 推荐：状态提升
function ParentComponent() {
  const [selectedTask, setSelectedTask] = useState<string | null>(null);
  
  return (
    <>
      <TaskList onSelect={setSelectedTask} />
      <TaskDetail taskId={selectedTask} />

// ❌ 不推荐：状态分散
function TaskList() {
  const [selectedTask, setSelectedTask] = useState<string | null>(null);
  // TaskDetail无法获取selectedTask
}
```

## 常见问题

### 1. 如何优化大列表渲染性能？

使用虚拟滚动或分页：

```typescript
import { useInfiniteScroll } from '@heroui/use-infinite-scroll';

function MessageList() {
  const { data, fetchNextPage, hasNextPage } = useInfiniteMessages();
  const [loaderRef, scrollerRef] = useInfiniteScroll({
    hasMore: hasNextPage,
    onLoadMore: fetchNextPage,
  });

  return (
    <div ref={scrollerRef} className="overflow-auto h-full">
      {data.pages.map((page) =>
        page.messages.map((msg) => <MessageItem key={msg.id} message={msg} />)
      )}
      {hasNextPage && <div ref={loaderRef}>加载中...</div>}
    </div>
  );
}
```

### 2. 如何处理复杂的组件状态？

使用useReducer或状态机：

```typescript
import { useReducer } from 'react';

type State = { status: 'idle' | 'loading' | 'success' | 'error'; data: any };
type Action = 
  | { type: 'FETCH_START' }
  | { type: 'FETCH_SUCCESS'; payload: any }
  | { type: 'FETCH_ERROR'; error: string };

function reducer(state: State, action: Action): State {
  switch (action.type) {
    case 'FETCH_START':
      return { ...state, status: 'loading' };
    case 'FETCH_SUCCESS':
      return { status: 'success', data: action.payload };
    case 'FETCH_ERROR':
      return { ...state, status: 'error' };
    default:
      return state;
  }
}

  const [state, dispatch] = useReducer(reducer, { status: 'idle', data: null });

}
```
