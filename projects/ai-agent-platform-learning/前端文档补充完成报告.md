## 📂 基于 ai-program-factory 项目的分析

### 项目特点

1. **现代化技术栈**
   - React 19 (最新版本)
   - React Router 7 (文件路由)
   - TypeScript 5.9 (类型安全)
   - Vite 7 (极速构建)

2. **丰富的功能**
   - 任务创建与管理
   - 实时对话与WebSocket通信
   - 工作流配置
   - 审批流程
   - 敏捷看板
   - 开发者统计

3. **完善的目录结构**
   ```
   src/
   ├── api/           (27个服务模块)
   ├── components/    (业务组件 + UI组件)
   ├── routes/        (45个路由页面)
   ├── hooks/         (37个自定义Hooks)
   ├── stores/        (Zustand状态管理)
   ├── contexts/      (React Context)
   ├── constants/     (常量定义)
   └── utils/         (58个工具函数)
   ```

4. **核心文件识别**
   - ⭐ `simple-task-form.tsx` - 任务创建表单
   - ⭐ `conversation.tsx` - 实时对话页
   - ⭐ `tasks.tsx` - 任务列表
   - ⭐ `workflow-manage.tsx` - 工作流管理
   - ⭐ `task-constants.ts` - 任务类型/状态定义

## 📝 文档编写建议

### 建议采用的结构

每篇文档应包含：
1. **概述**：这个功能是什么，为什么需要
2. **核心文件**：相关的代码文件位置
3. **实现原理**：如何实现的
4. **代码示例**：关键代码片段
5. **数据流**：数据如何流转
6. **使用方式**：如何使用这个功能
7. **常见问题**：FAQ

### 代码分析重点

从 ai-program-factory 项目中提取：
- ✅ 真实的代码示例
- ✅ 实际的 API 接口
- ✅ 具体的数据结构
- ✅ 真实的配置文件

避免：
- ❌ 泛泛而谈
- ❌ 理论说教
- ❌ 过时的内容
