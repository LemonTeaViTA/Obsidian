### 站点 1️⃣：前端发起 - 组装 input 参数

**位置**：ai-program-factory 前端项目

**动作**：
```javascript
// 用户填写表单后，前端组装请求
fetch('https://ai24域名/api/taskInfo/create', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        taskName: "开发订单系统",
        input: JSON.stringify({
            depUrl: "http://dep.vdian.net/#/taskDetail?id=12345",
            flowType: "backend",
            templateId: "10001",
            model: "claude-opus-4-8",
            testerName: "张三"

        multiModel: false,
        models: [],
        domain: null
    })

```

**关键点**：
- `input` 是一个 **JSON 字符串**，不是对象
- 包含 5 个核心要素：depUrl、flowType、templateId、model、testerName

### 站点 2️⃣：ai24 Controller - 参数校验与权限检查

**文件**：`ai24-web/src/main/java/com/vdian/ai24/web/controller/TaskInfoController.java`

**流程**：
```java
@PostMapping("/create")
public Result<String> createTask(@RequestBody CreateTaskRequest request) {
    // 1. 参数校验
    if (request == null || !hasText(input)) {
        return Result.error("参数不能为空");
    }
    
    // 2. 获取用户信息
    String username = SSOUtil.getUser().getName();
    String realName = SSOUtil.getUser().getNick();
    
    // 3. 管理员判断
    boolean isAdmin = ALLOWED_USERS_NAME.contains(username);
    
    // 4. 环境权限校验（日常/预发环境仅管理员）
    if (isDailyOrPreEnv && !isAdmin) {
        return Result.error("当前环境仅管理员可创建");
    }
    
    // 5. PRD 自动迭代拦截
    if (!isAdmin) {
        String depUrl = TaskInputParser.extractDepUrl(input);
        Integer depId = TaskInputParser.extractDepId(input);
        
        // 查询 DEP 详情
        DepIssueDTO issueDetail = depApiProxy.getIssueDetail(depId);
        Integer iterationId = issueDetail.getIterationId();
        Long firstRequirementId = issueDetail.getRequirements().get(0).getRequirementId();
        
        // 需求白名单豁免
        if (MANUAL_CREATE_REQUIREMENT_ID_WHITELIST.contains(firstRequirementId)) {
            // 允许创建
        } else if (PRD_ITERATION_ID_WHITELIST.contains(iterationId)) {
            // 普通用户命中迭代白名单，拒绝手工创建
            return Result.error("该需求请通过 PRD 自动流程创建");
        }
    }
    
    // 6. 调用 Service 创建任务
    String taskId = taskInfoService.createTask(
        request.getTaskName(),
        request.getInput(),
        null,
        username,
        realName,
        false,
        Collections.emptyList(),
        null,
        true,
        false,
        null
    );
    
    return Result.success(taskId);
}
```

**关键点**：
- 不信任前端，所有参数后端重新校验
- PRD 自动迭代拦截：防止同一需求被重复创建
- 管理员有应急创建权限

### 站点 4️⃣：ai24 Orchestrator - 编排核心

**文件**：`ai24-core/src/main/java/com/vdian/ai24/core/orchestrator/TaskCreateOrchestrator.java`

**流程**：
```java
public String createTask(...) {
    // 1. 生成 taskId
    String taskId = generateTaskId();
    
    // 2. 构建 TaskInfoDO
    TaskInfoDO taskInfo = buildTaskInfoDO(input);
    taskInfo.setTaskId(taskId);
    taskInfo.setUserName(username);
    taskInfo.setStatus(0);  // 初始状态
    taskInfo.setIsDelete(1); // 有效
    
    // 3. 解析 input 中的信息
    String depUrl = TaskInputParser.extractDepUrl(input);
    Integer depId = TaskInputParser.extractDepId(input);
    DepIssueDTO issueDetail = depApiProxy.getIssueDetail(depId);
    
    taskInfo.setProjectName(issueDetail.getProjectName());
    taskInfo.setRequirementName(issueDetail.getName());
    taskInfo.setGitUrl(issueDetail.getGitUrl());
    taskInfo.setBranch(issueDetail.getBranch());
    
    // 4. 存库
    taskInfoManager.save(taskInfo);
    
    // 5. 创建初始记录
    taskRecordManager.createInitialRecord(taskId);
    
    // 6. 下发给 code-agent
    callTaskPerformService(taskId, input);
    
    return taskId;
}
```

**关键点**：
- 先存库（status=0），后下发
- 即使下发失败，任务也已创建，可以手动重试

### 站点 5️⃣：ai24 → code-agent - HTTP 调用

**方法**：`TaskCreateOrchestrator.callTaskPerformService()`

```java
private void callTaskPerformService(String taskId, String input) {
    String codeAgentUrl = "http://code-agent-service/task/perform";
    
    Map<String, Object> requestBody = new HashMap<>();
    requestBody.put("taskId", taskId);
    
    // 解析 input，拆成独立字段
    JSONObject inputJson = JSON.parseObject(input);
    requestBody.put("depUrl", inputJson.getString("depUrl"));
    requestBody.put("flowType", inputJson.getString("flowType"));
    requestBody.put("model", inputJson.getString("model"));
    // ... 其他字段
    
    // HTTP POST
    restTemplate.exchange(
        codeAgentUrl,
        HttpMethod.POST,
        new HttpEntity<>(requestBody),
        String.class
    );
}
```

### 站点 6️⃣：code-agent 接收 - Flask API

**文件**：`code-agent/main.py` - `TaskPerformResource.post()`

```python
@task_perform_ns.route('')
class TaskPerformResource(Resource):
    def post(self):
        data = request.get_json()
        task_id = data.get('taskId')
        dep_url = data.get('depUrl')
        model = data.get('model')
        
        # 1. 同步知识库（三套）
        sync_knowledge_repos()
        
        # 2. 解析 depUrl，提取 dep_id
        dep_id = extract_dep_id_from_url(dep_url)
        
        # 3. 保存任务元数据
        meta_container.save_task_metadata(task_id, data)
        
        # 4. 返回 202（异步处理）
        # 启动新线程执行任务
        thread = threading.Thread(
            target=execute_task_in_background,
            args=(task_id, data)
        )
        thread.start()
        
        return {'message': 'Task accepted'}, 202
```

**关键点**：
- 立即返回 202，不阻塞 ai24
- 真正的执行在后台线程中

```python
def execute_task_in_background(task_id, data):
    try:
        # 1. 初始化 Claude SDK
        service = ClaudeAgentSDK(
            model=data['model'],
            session_id=task_id
        )
        
        # 2. 调用 init-project Skill
        response = service.query(
            prompt="请使用 /init-project 初始化项目",
            tools=get_available_tools(),
            skills=get_available_skills()
        )
        
        # 3. init-project Skill 执行：
        #    - 调用 DEP API 获取需求详情、PRD
        #    - 克隆 Git 仓库
        #    - 准备 CLAUDE.md、OpenSpec
        #    - 分析项目结构
        
        # 4. 上报初始化完成
        report_status_to_ai24(task_id, status=100)
        
        # 5. 继续执行后续阶段...
        
    except Exception as e:
        # 上报失败
        report_status_to_ai24(task_id, status=-1, error=str(e))
```

**init-project Skill 内部动作**：
1. 查询 DEP 需求详情
2. 下载 PRD 文档
3. 克隆代码仓库
4. 生成 CLAUDE.md（项目说明）
5. 生成 OpenSpec（API 规范）
6. 分析项目结构和技术栈

### 站点 8️⃣：code-agent → ai24 - 状态回调

**code-agent 上报**：

```python
def report_status_to_ai24(task_id, status, message=None):
    url = "http://ai24-service/api/task/notify/taskStatus"
    
    payload = {
        "taskId": task_id,
        "status": status,  # 100=初始化完成, 500=完成, -1=失败
        "message": message
    }
    
    requests.post(url, json=payload)
```

**ai24 接收回调**：

**文件**：`ai24-web/src/main/java/com/vdian/ai24/web/controller/TaskNotifyController.java`

```java
@PostMapping("/taskStatus")
public Result<Void> updateTaskStatus(@RequestBody TaskStatusRequest request) {
    String taskId = request.getTaskId();
    Integer status = request.getStatus();
    
    // 1. 更新数据库
    TaskInfoDO task = taskInfoManager.getByTaskId(taskId);
    
    // 终态保护：已经是终态（500/600/-1）不能再改
    if (isTerminalStatus(task.getStatus())) {
        return Result.success();
    }
    
    task.setStatus(status);
    taskInfoManager.updateById(task);
    
    // 2. WebSocket 推送前端
    webSocketService.pushTaskStatus(taskId, status);
    
    return Result.success();
}
```

## 💡 关键设计思想

### 1. 异步解耦

```
ai24 下发任务 → 立即返回 202 → 不阻塞
code-agent 执行 → 后台线程 → 回调上报
```

### 2. 状态机驱动

```
0 (初始) → 100 (初始化) → 200 (执行中) → 500 (完成)
                                      ↘ -1 (失败)
```

### 3. 双向通信

```
ai24 → code-agent: HTTP POST（主动下发）
code-agent → ai24: HTTP 回调（状态上报）
ai24 → 前端: WebSocket（实时推送）
```

### 4. 终态保护

```java
// 已经是终态（500/600/-1）不能再改
if (isTerminalStatus(task.getStatus())) {
    return Result.success();
}
```

### 5. 失败兜底

- 下发失败：任务已存库，可手动重试
- 执行失败：code-agent 上报 -1，前端显示错误
- 回调失败：code-agent 重试机制
