## 🎯 两种任务类型

| 类型 | 接口 | 触发时机 | 作用 |
|-----|------|---------|------|
| **任务初始化** | POST /task/perform | ai24创建任务时 | 拉代码、安装依赖、拉PRD,准备项目环境 |
| **任务查询** | POST /task/query | 用户输入指令时 | 执行具体任务(写代码/改bug/生成文档) |

## 一、任务初始化流程 (perform)

### 入口
```
ai24 POST /task/perform {taskId, depUrl, gitUrl, model, ...}
    ↓
TaskPerformResource.post (main.py:230)
    ↓
启动新线程: threading.Thread(target=run_init_task_via_claude, args=(task_id,))
    ↓ (立刻返回 HTTP 202,不等初始化完成)
```

### 核心函数: run_init_task_via_claude

```
┌─────────────────────────────────────────────────────────┐
│ 1. 准备工作目录                                           │
│    PathManager.ensure_task_dir_exists(task_id)          │
│    → /home/www/.claude/projects/{task_id}/             │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│ 2. 启动文件备份监听                                       │
│    start_task_environment_backup(task_id, project_path) │
│    → 监控文件变化,定时备份到云端OSS                        │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│ 3. 上报会话状态"进行中"                                   │
│    MessageReporter.report_session_status(IN_PROGRESS)   │
│    → POST /api/task/notify/sessionStatus               │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│ 4. 上报系统消息"任务初始化中"                              │
│    MessageReporter.report_system_message(...)           │
│    → POST /api/task/report/content                     │
│    → ai24写task_record + WebSocket推前端                │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│ 5. 生成初始化提示词                                       │
│    prompt = prompt_holder.get_init_prompt(task_id)     │
│    → "请调用 init_project MCP 工具初始化项目..."         │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│ 6. 获取 ClaudeAgentSDKService 单例                      │
│    service = ClaudeAgentSDKService.get_instance()      │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│ 7. 构造初始化状态检查 Hook                                │
│    init_hooks = InitStatusCheckHook(task_id)           │
│    → 检查ai24的status是否=100,不是则提示Claude重试       │
└─────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ ★★★ 8. 调用 Claude SDK (核心!) ★★★                      │
│                                                          │
│ await service.query(                                    │
│     task_id=task_id,                                    │
│     prompt="请调用 init_project MCP 工具...",            │
│     cwd=current_dir,                                    │
│     model=model,                                        │
│     hooks=init_hooks,                                   │

│ )                                                        │
│                                                          │
│ ┌─────────── Claude 内部流程 ───────────┐               │
│ │ ① Claude收到提示词,思考                │               │
│ │ ② Claude决定调用 init_project 工具     │               │
│ │ ③ SDK检查 PreToolUse Hook(系统Hook)   │               │
│ │ ④ SDK调用 MCP服务器的 init_project    │               │
│ │    ├─ git clone                       │               │
│ │    ├─ 检测项目类型                     │               │
│ │    ├─ 安装依赖(npm/mvn/go...)         │               │
│ │    ├─ 拉取PRD文档                      │               │
│ │    └─ 上报进度(每步notify_task)        │               │
│ │ ⑤ MCP返回结果给Claude                 │               │
│ │ ⑥ Claude回复"初始化完成"               │               │
│ └───────────────────────────────────────┘               │
└───────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│ 9. 清理会话映射                                          │
│    TaskSessionMapper.remove_task_to_session_only()      │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│ 10. 上报会话状态"空闲"                                   │
│     MessageReporter.report_session_status(IDLE)         │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│ 11. 通知ai24初始化阶段完成                               │
│     CompleteStageClient().complete_stage(              │

## 二、任务查询流程 (query)

### 入口
```
ai24 POST /task/query {taskId, input, hooks, model, ...}
    ↓
TaskQueryResource.post (main.py:442)
    ↓
构造 TaskQueryMessage(task_id, input_text, hooks...)
    ↓
dispatch_task_query_message(query_message)
    ↓
启动新线程: threading.Thread(target=run_query_task_in_thread, args=(query_message,))
    ↓ (立刻返回 HTTP 202)
```

### 核心函数: execute_query_task

```
┌─────────────────────────────────────────────────────────┐
│ 1. 启动文件备份监听                                      │
│    start_file_backup_listener(task_id)                 │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│ 2. 检查并恢复任务环境                                    │
│    check_and_restore_task_environment(task_id)         │
│    → 如果任务换了机器,从OSS恢复会话文件                   │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│ 3. 检查中断标识                                          │
│    if service._get_interrupt_flag(task_id):            │
│        跳过执行,返回                                      │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│ 4. 上报会话状态"进行中" + 系统消息"收到请求"              │
│    MessageReporter.report_session_status(IN_PROGRESS)  │
│    MessageReporter.report_system_message("收到请求...")  │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│ 5. 获取任务元数据                                        │
│    meta_container = get_meta_container()               │

    ↓
┌─────────────────────────────────────────────────────────┐
│ 6. 判断任务类型,选择执行路径                             │
│    ├─ 纯净任务/自由任务 → 直接query,不插系统提示词       │
│    ├─ frontend_common → 根据ui_mcp_type选Figma/MasterGo │
│    ├─ openspec_proposal → 插入proposal系统提示词         │
│    ├─ openspec_apply → 插入apply系统提示词               │
│    └─ 其他 → 插入通用系统提示词                          │
└─────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ ★★★ 7. 调用 Claude SDK (核心!) ★★★                      │
│                                                          │
│ await service.query(                                    │
│     task_id=task_id,                                    │
│     prompt=input_text,       # 用户输入的指令            │
│     cwd=project_path,        # 项目目录                  │
│     model=model,             # 模型                      │
│     dynamic_hooks=hooks,     # ai24下发的hooks           │

│                                                          │
│ ┌─────────── Claude 执行流程 ───────────┐               │
│ │ ① Claude分析用户指令                   │               │
│ │ ② Claude思考解决方案                   │               │
│ │ ③ Claude调用工具:                     │               │
│ │    - Read读文件                       │               │
│ │    - Write写文件                      │               │
│ │    - Edit改文件                       │               │
│ │    - Bash执行命令                     │               │
│ │    - MCP工具(Figma/MasterGo/AI24...) │               │

│ │ ⑤ Claude完成任务,回复结果             │               │

│ └───────────────────────────────────────┘               │

## 三、perform vs query 对比

| | perform(初始化) | query(执行任务) |
|---|---|---|
| **触发时机** | 任务创建时(一次) | 用户输入指令时(多次) |
| **目的** | 准备环境 | 执行具体工作 |
| **提示词** | "请调用 init_project..." | 用户输入的指令 |
| **调用工具** | init_project MCP工具 | Read/Write/Edit/Bash/MCP... |
| **会话** | keep_session=True | 继续使用同一会话 |
| **完成标志** | status=100 | 看具体任务 |

## 四、关键认知点

### 1. 为什么都用新线程?
```python
thread = threading.Thread(target=..., args=...)
thread.daemon = True
thread.start()
return {'success': True}, 202  # 立刻返回
```

**原因**: 任务执行要几分钟甚至更久,不能让HTTP请求一直挂着。立刻返回202,任务在后台慢慢跑,通过回调上报进度。

### 2. Claude不是直接操作文件/git,而是通过工具
```
Claude想读文件 → 调用Read工具 → SDK检查Hook → 真正执行read_file()
Claude想提交 → 调用Bash工具 → GitCommitAuthorHook检查 → 执行git commit
```

**好处**: 每个操作都可控、可拦截、可审计。

### 3. Hook的三个来源
- **系统Hook**(启动时): PathSecurityHook / GitCommitAuthorHook
- **元数据Hook**(perform时): enable_tdd → TDD Hook
- **ai24下发Hook**(query时): proposal_files_gate / task_completion_gate

### 4. 流式上报的机制
```
Claude输出 "我来分析这个需求..."
    ↓ 每输出一段
SDK立刻POST /api/task/report/content 给ai24
    ↓
ai24写task_record + WebSocket推前端
    ↓
用户实时看到Claude在"打字"
```

不是等Claude全说完再上报,是**流式转短连接POST流**。
