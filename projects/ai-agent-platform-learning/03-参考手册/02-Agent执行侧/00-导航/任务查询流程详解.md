# 任务查询流程详解（POST /task/query）

> 执行用户的实际任务，支持多轮对话

**触发**：用户在 AI24 平台输入问题/需求  
**目的**：让 Claude 执行实际的开发任务  
**特点**：可以多次查询，支持多轮对话

---

## 📋 完整流程

```
用户在 AI24 平台输入："请实现用户登录功能"
    ↓
POST /task/query
{
  "taskId": "task_123",
  "input": "请实现用户登录功能，包括密码加密和 Session 管理",
  "model": "claude-opus-4-8",
  "hooks": ["document_upload"]
}
```

**做什么**：

## 阶段3：service.query() 核心执行

### Step 1: 获取任务锁 ⭐

```python
task_lock = self._get_task_lock(task_id)
task_lock.acquire()  # 阻塞，直到拿到锁

logger.info(f"[Task {task_id}] 已获取任务锁")
```

**作用**：
- 同一任务的请求**串行执行**（保证对话顺序）
- 不同任务的请求**并发执行**（提高吞吐）

**锁粒度 = task_id**

---

### Step 2: 查询 session_id ⭐ 多轮对话关键

```python
session_id = TaskSessionMapper.get_session_id(task_id)
```

### Step 3: 构建 ClaudeAgentOptions

```python
# 加载系统提示词
if flow_type == "backend":
    system_prompt = load_system_prompt("backend")
    # "你是一个专业的后端开发工程师..."

    cwd=project_path,  # 工作目录
```

**关键参数 `resume`**：
- `None`：创建新会话
- `"sess_abc123"`：恢复历史会话

### Step 4: 创建 ClaudeSDKClient

```python
client = ClaudeSDKClient(options)

# 注册到 active_clients（用于中断）

    self._active_clients[task_id] = client
    self._client_loops[task_id] = asyncio.get_event_loop()
```

**注意**：每次查询都创建新的 Client！

### 消息2：AssistantMessage（Claude 的输出）

```python

    content=[
        ThinkingBlock(thinking="用户想要实现登录功能..."),
        TextBlock(text="好的，我来帮你实现用户登录功能。")
    ]

```

**处理流程**：

#### 1. 渲染
```python

```

#### 2. 过滤检查
```python
if self._should_report_message(message, session_id):
    # 通过 → 继续

    # 跳过 → 不上报
```

**过滤规则**：
```python
def _should_report_message(message, session_id):
    # 1. 跳过评分 Session
    if "_scoring_" in session_id:
        return False
    
    # 2. 跳过 SystemMessage
    if isinstance(message, SystemMessage):
        return False
    
    # 3. 跳过空的 AssistantMessage
    if isinstance(message, AssistantMessage):
        if not message.content:
            return False
        
        text_blocks = [b for b in message.content if isinstance(b, TextBlock)]
        if text_blocks and all(not b.text.strip() for b in text_blocks):
            return False
    
    return True  # 其他情况，上报
```

```python
real_path = os.path.realpath(file_path)
if not real_path.startswith(project_dir):
    return {"action": "block", "error": "🚫 只能访问项目目录内的文件"}
```

## 🎯 核心设计总结

1. **多轮对话**：TaskSessionMapper + Claude SDK resume
2. **消息过滤**：SystemMessage、空消息、评分 Session
3. **逐条上报**：HTTP POST（不是长连接）
4. **Hook 拦截**：Pre（安全）、Post（上报）
5. **实时备份**：文件监听器 → COS
6. **任务锁**：task_id 粒度，同任务串行
