# Code-Agent 启动流程走读

> 从 `python main.py` 入口开始，逐段拆解服务启动到就绪的完整流程。
> 对应代码入口：[main.py:3799 `if __name__ == '__main__'`](../../code-agent/main.py#L3799)

比"项目概览"更贴近真实执行顺序：概览讲的是"有哪些模块"，这篇讲的是"开机时这些模块按什么顺序被点亮"。

---

## 一、全景图：启动 → 就绪

```
python main.py --env daily
        │
        ▼
┌──────────────────────────────────────────────┐
│  if __name__ == '__main__':   (L3799)                       │
│                                                              │
│  1. setup_runtime_environment()   解析参数 + 配环境 + mvn劫持 │
│  2. 注册信号处理器 SIGTERM/SIGINT   优雅停机                 │
│  3. init_coscmd_config()          配 COS 云存储             │
│  4. init_langfuse()               配 LLM 追踪               │
│  5. move_claude_project_on_startup()  恢复会话状态目录       │
│  6. copy_skills / agents / settings   同步配置到 ~/.claude   │
│  7. create_claude_service()       建 SDK 单例 ★核心         │
│  8. get_meta_container()          初始化任务元数据管理       │
│  9. recover_interrupted_tasks()   恢复上次被杀的中断任务     │
│  10. 心跳 + 磁盘清理调度            运维                     │
│  11. app.run(port=8080)           启 Flask，开始接客        │
└──────────────────────────────────────────────┘
        │
        ▼
  服务就绪，等待 AI24 发 HTTP 请求
```

> ⚠️ 已知问题：[L3807-3860](../../code-agent/main.py#L3807-L3860) 有一大段**重复代码**——信号注册、skills/agents/settings 复制各写了两遍。幂等无害，但属于复制粘贴残留，可清理。

## 二、分层时序图（按职责归类）

```
┌────────────── 启动阶段（一次性）──────────────┐
│                                                          │
│  环境层   setup_runtime_environment                      │
│          └─ --env / config / mvn 命令劫持                │
│                                                          │
│  容错层   signal handlers + atexit                       │
│          └─ 被杀时：存中断任务 / 停子进程                │
│                                                          │
│  外设层   init_coscmd  (云备份)                          │
│          init_langfuse (追踪)                            │
│                                                          │
│  配置层   move_claude_project (恢复会话状态)             │
│          copy skills/agents/settings (同步配置)          │
│                                                          │
│  核心层   create_claude_service ★                        │
│          └─ SDK 单例 + 几十个 MCP + hooks                │
│          get_meta_container (任务元数据)                 │
│                                                          │
│  恢复层   recover_interrupted_tasks                      │
│                                                          │
│  运维层   心跳 + 磁盘清理调度                            │
│                                                          │
└──────────────────────────────────────────────┘
                          ▼
┌────────────── 运行阶段（循环）────────────────┐
│  app.run → Flask 监听 8080                               │
│    AI24 → POST /task/perform  (初始化，存 MetaContainer)  │
│    AI24 → POST /task/query    (执行，service.query)       │
│    AI24 → POST /task/interrupt(中断)                      │
└──────────────────────────────────────────────┘
```
