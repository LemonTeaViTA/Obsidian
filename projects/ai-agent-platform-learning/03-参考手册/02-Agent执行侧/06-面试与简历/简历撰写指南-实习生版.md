## 项目背景统一描述

**项目名称：** AI代码工厂（AI Code Factory）

**项目简介：** 
基于 Claude AI 的智能代码生成平台，通过工作流驱动的方式实现需求分析、代码生成、代码审查的自动化流程。系统采用 Java（Spring Boot）+ Python（Flask）双语言架构，支持审批流程、实时流式推送等特性。

**技术栈核心：**
- 后端：Spring Boot、MyBatis Plus、Python Flask、Claude Agent SDK
- 中间件：MySQL、Redis、WebSocket
- 监控：Langfuse、日志追踪

## 版本1: AI工程师实习生 ⭐

### 📌 侧重点
- **Claude Agent 开发**：Claude Agent SDK、MCP 工具、Hook 机制
- **Prompt Engineering**：系统 prompt 设计、工作流 prompt
- **AI 可观测性**：Langfuse 日志、Token 消耗、对话追踪
- **安全控制**：PathSecurityHook、GitCommitAuthorHook

### 📝 简历描述

#### 项目职责
1. 参与 **Claude Agent 集成开发**，使用 Claude Agent SDK 实现任务初始化、代码生成、代码审查的 AI 工作流
2. 开发 **Hook 安全拦截机制**，实现 PathSecurityHook（路径黑名单）和 GitCommitAuthorHook（强制提交者信息），保证代码级安全控制
3. 协助开发 **MCP（Model Context Protocol）工具**，实现 init_project（项目初始化）、read_file（文件读取）、write_file（文件写入）等工具
4. 参与建立 **AI 可观测性体系**，集成 Langfuse 记录完整对话历史、Token 消耗、工具调用链路

#### 技术亮点
- **Hook 安全机制**（核心亮点）：
  - **PathSecurityHook**：通过黑名单 + os.path.abspath 规范化路径，防止目录穿越攻击，禁止访问 /etc、/var、其他任务目录
  - **GitCommitAuthorHook**：正则检查 git commit 命令，强制添加 --author="Claude AI"，保证审计可追溯
  - **代码级拦截**：Hook 返回 deny 时 SDK 直接跳过工具执行，而非依赖 prompt 约束（更可靠）
  
- **Agent 工作流实现**：
  - **任务初始化**：Claude 调用 init_project MCP 工具 → git clone → 安装依赖 → 获取 PRD
  - **代码生成**：Claude 读取项目结构 → 分析需求 → 生成代码 → 运行测试
  - **Stop Hook 通知**：任务完成时通过 Stop Hook 调用 CompleteStageClient，通知 ai24 平台触发工作流流转

- **Prompt Engineering**：
  - **系统 Prompt**：定义 Claude 角色（代码助手）+ 工具使用规范 + 输出格式要求
  - **工作流 Prompt**：每个阶段有独立 prompt（"请分析需求并拆分为领域模块"、"请生成代码实现"）
  - **动态注入**：PRD、项目结构、历史对话通过 context 注入，避免 prompt 过长

- **可观测性**：
  - **Langfuse 集成**：记录每次 query 的 prompt、response、tool_calls、token 消耗
  - **分布式追踪**：taskId 贯穿 ai24 → code-agent → Claude SDK，日志可关联查询

#### 数据与成果
- 实现 **10+ MCP 工具**，覆盖项目初始化、文件操作、Git 操作、测试运行
- PathSecurityHook 成功拦截 **多次越权访问尝试**，保证代码安全
- Langfuse 记录完整对话历史，帮助分析 Token 消耗并优化 prompt

## 版本2: 后端开发实习生

### 📌 侧重点
- **Java 后端开发**：Spring Boot、MyBatis Plus、事务管理
- **微服务通信**：跨语言 HTTP 调用、异步处理
- **并发与线程安全**：单例无状态设计、雪花算法 ID 生成
- **数据库操作**：表结构设计、索引优化、事务边界

### 📝 简历描述

#### 项目职责
1. 参与 **ai24 核心后端模块**开发，使用 Spring Boot + MyBatis Plus 实现任务管理、工作流引擎、审批流程
2. 学习并实现 **TaskCreateOrchestrator 任务编排器**，通过单例无状态模式保证高并发下的线程安全
3. 参与开发 **跨语言 HTTP 通信层**，使用 RestTemplate 实现 Java 与 Python 服务的异步调用，支持超时重试
4. 协助设计 **MySQL 数据库表结构**（task_info、task_record、approval_item），优化索引提升查询性能

#### 技术亮点
- **并发安全设计**：
  - TaskCreateOrchestrator 采用单例 + 无状态设计，所有依赖通过 @Autowired 注入
  - 所有状态通过方法参数传递，避免成员变量在多线程下的竞态问题
  - 使用雪花算法（TaskIdGenerator）保证分布式环境下 ID 唯一性
  
- **事务边界控制**：
  - @Transactional 覆盖数据库操作（INSERT task_info + task_record）
  - HTTP 调用 code-agent 放在事务外，避免长事务锁表
  - 调用失败时通过补偿机制更新任务状态为 FAILED，支持用户重试

- **数据库优化**：
  - 使用 MyBatis Plus Page 插件实现分页，避免全表扫描
  - 通过 (username, createTime) 联合索引优化任务列表查询
  - taskId 作为主键，保证查询性能

#### 数据与成果
- 参与开发的系统支持任务创建并发处理
- 通过索引优化，任务列表查询性能提升明显
- 学习了事务管理、并发控制、数据库优化等后端核心技能

## 版本3: 全栈开发实习生

### 📌 侧重点
- **全栈能力**：Java 后端 + Python AI 侧 + 前端流式交互
- **实时通信**：WebSocket 流式推送、状态同步
- **前后端协作**：API 设计、状态同步、错误处理
- **用户体验**：流式渲染、进度反馈

### 📝 简历描述

#### 项目职责
1. 参与 **全栈开发**，实现 Java 后端（Spring Boot）+ Python AI 服务（Flask）+ 前端流式交互的完整链路
2. 学习并实现 **三层流式推送架构**：Claude 流式输出 → code-agent 短连接 POST → ai24 → WebSocket 推送前端
3. 参与开发 **任务状态同步机制**，通过心跳检测（machine_status_manager）+ 状态上报（MessageReporter）保证前后端状态一致
4. 协助实现 **审批流程前端交互**，支持审批、拒绝理由回填、审批进度展示

#### 技术亮点
- **流式推送实现**：
  - 前端 WebSocket 接收 Claude 流式输出，实现打字机效果
  - 后端批量聚合 token 减少推送频率（100ms 或 50 token 触发）
  - code-agent 通过短连接 POST 而非 WebSocket，降低复杂度

- **状态同步机制**：
  - 三条上报链路：心跳上报（机器状态）、任务状态上报（开始/完成/失败）、内容上报（流式推送）
  - 任务状态机：INIT → IN_PROGRESS → SUCCESS / FAILED
  - WebSocket 断线重连后通过 /task/detail 接口补全状态

- **前后端协作**：
  - RESTful API 设计，统一返回 ApiResponse<T>
  - 区分系统错误（500）与业务错误（任务失败），前端展示不同提示
  - code-agent 异常时通过心跳超时自动降级

#### 数据与成果
- 实现实时流式输出，用户感知延迟低
- 学习了 WebSocket 实时通信、前后端状态同步、流式数据处理
- 参与完整的前后端开发流程，理解全栈技术栈

## 🎯 总结：如何选择简历版本？

| 岗位类型 | 推荐版本 | 核心能力要求 | 适合场景 |
|---------|---------|-------------|---------|
| **AI 工程师实习生** | 版本1 ⭐ | Claude Agent SDK、Hook、MCP、Prompt | AI 公司、大模型应用开发岗位 |
| **Java 后端实习生** | 版本2 | Spring Boot、MyBatis、并发、事务 | 传统后端开发岗位 |
| **全栈开发实习生** | 版本3 | Java + Python + WebSocket + 前端 | 需要全栈能力的创业公司 |

### 💡 我的建议

**如果投递 AI 相关岗位 → 首选版本1（AI工程师实习生）**
- 最能体现 AI 技术深度
- Hook 机制、MCP 工具是亮点
- 面试官更关心如何控制 AI 安全性

**如果投递传统后端岗位 → 选版本2（后端开发实习生）**
- 强调 Spring Boot、事务、并发
- 面试官会问并发安全、数据库优化

**如果投递全栈岗位 → 选版本3（全栈开发实习生）**
- 展示前后端协作能力
- 流式推送、WebSocket 是亮点
