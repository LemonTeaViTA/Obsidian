# 任务列表与筛选

## 概述

任务列表页面是用户查看和管理所有任务的中心页面，提供了强大的筛选功能、分页展示、状态显示以及任务操作。通过 `/src/routes/tasks.tsx` 实现，支持多维度筛选、筛选条件持久化、URL参数初始化等高级功能。

## 核心文件

- **页面组件**: `/src/routes/tasks.tsx`
- **数据Hook**: `/src/hooks/query/use-tasks-with-summary.ts`
- **常量定义**: `/src/constants/task-constants.ts`
- **删除Hook**: `/src/hooks/mutation/use-delete-task.ts`

## 功能特性

### 1. 多维度筛选

支持11个维度的任务筛选：

```typescript
interface TaskListFilterState {
  taskName: string;                    // 任务名称
  taskId: string;                      // 任务ID
  requirementName: string;             // 需求名称
  userId: string;                      // 创建人
  status: number | undefined;          // 任��状态
  projectName: string;                 // 项目名称
  flowType: string | undefined;        // 任务类型
  createTimeRange: [string, string] | null;  // 创建时间范围
  deptUserSelection: SelectedItem[];   // 部门/人员选择
  deptUserUsernames: string[];         // 选中的用户名列表
  workflowNo: string[] | undefined;    // 工作流编号（多选）
  depId: string;                       // DEP任务ID
  effectiveFilter: number;             // 任务有效性（1=全部, 2=无效, 3=有效）
  current: number;                     // 当前页码
  pageSize: number;                    // 每页条数
}
```

### 2. 筛选条件持久化

使用 `sessionStorage` 保存筛选状态，页面刷新或跳转后返回能恢复筛选条件：

```typescript
const TASK_LIST_FILTER_KEY = "task-list-filter-state";

// 保存筛选状态
const saveFilterState = useCallback(() => {
  const state: TaskListFilterState = {
    taskNameInput,
    taskIdInput,
    requirementNameInput,
    // ... 其他字段
    timestamp: Date.now(),
  };
  sessionStorage.setItem(TASK_LIST_FILTER_KEY, JSON.stringify(state));
}, [/* 依赖项 */]);

// 加载筛选状态
const loadFilterState = (): TaskListFilterState | null => {
  try {
    const stored = sessionStorage.getItem(TASK_LIST_FILTER_KEY);
    if (!stored) return null;
    return JSON.parse(stored) as TaskListFilterState;
  } catch {
    return null;
  }
};
```

### 3. 双态筛选模式

采用"输入态"和"查询态"分离的设计，优化用户体验：

```typescript
// 输入态：用户正在编辑的筛选条件
const [taskNameInput, setTaskNameInput] = useState<string>("");
const [statusInput, setStatusInput] = useState<number | undefined>(undefined);

// 查询态：已应用到API请求的筛选条件（点击查询按钮后才更新）
const [taskName, setTaskName] = useState<string>("");
const [status, setStatus] = useState<number | undefined>(undefined);

// 查询按钮：将输入态应用到查询态
const handleSearch = () => {
  setTaskName(taskNameInput?.trim() || "");
  setStatus(statusInput);
  // ... 其他字段
  setCurrent(1); // 重置到第一页
};
```

### 4. URL参数初始化

支持通过URL参数直接打开带筛选条件的任务列表：

```typescript
// URL参数示例
// /tasks?userid=zhangsan&start=1704038400000&end=1704124800000&status=500&depId=12345&effective=true

useEffect(() => {
  if (initializedFromQuery) return;

  // 检查URL参数
  const urlUserId = searchParams.get("userid");
  const urlStart = searchParams.get("start");
  const urlEnd = searchParams.get("end");
  const urlStatus = searchParams.get("status");
  const urlDepId = searchParams.get("depId");
  const urlEffective = searchParams.get("effective");

  // 优先使用URL参数
  if (urlUserId && urlUserId.trim()) {
    setUserIdInput(urlUserId);
    setUserId(urlUserId);
    setCurrent(1);
    setUserSearchKeyword(urlUserId);
  }

  if (urlStart && urlEnd) {
    const startTime = dayjs(Number(urlStart));
    const endTime = dayjs(Number(urlEnd));
    if (startTime.isValid() && endTime.isValid()) {
      setCreateTimeRangeInput([startTime, endTime]);
      setCreateTimeRange([startTime, endTime]);
    }
  }

  if (urlStatus) {
    const statusNum = Number(urlStatus);
    if (!Number.isNaN(statusNum)) {
      setStatusInput(statusNum);
      setStatus(statusNum);
    }
  }

  if (urlDepId && urlDepId.trim()) {
    setDepIdInput(urlDepId);
    setDepId(urlDepId);
  }

  if (urlEffective === "true") {
    setEffectiveFilterInput(3);
    setEffectiveFilter(3);
  }

  setInitializedFromQuery(true);
}, [initializedFromQuery, searchParams]);
```

### 4. 筛选条件标签生成

根据当前筛选条件自动生成标签展示：

```typescript
const filterTags = React.useMemo(() => {
  const tags: Array<{ label: string; value: string }> = [];

  if (taskName) tags.push({ label: "任务名称", value: taskName });
  if (taskId) tags.push({ label: "任务ID", value: taskId });
  if (requirementName) tags.push({ label: "需求名称", value: requirementName });
  if (projectName) tags.push({ label: "项目名称", value: projectName });
  if (userId) tags.push({ label: "创建人", value: userId });
  
  if (status !== undefined) {
    const statusInfo = STATUS_MAP[status];
    if (statusInfo) tags.push({ label: "状态", value: statusInfo.text });
  }
  
  if (flowType) {
    const flowTypeInfo = FLOW_TYPE_MAP[flowType];
    if (flowTypeInfo) tags.push({ label: "任务类型", value: flowTypeInfo.text });
  }
  
  if (createTimeRange?.[0] && createTimeRange?.[1]) {
    tags.push({
      label: "创建时间",
      value: `${createTimeRange[0].format("YYYY-MM-DD")} ~ ${createTimeRange[1].format("YYYY-MM-DD")}`,
    });
  }
  
  if (deptUserUsernames.length > 0) {
    tags.push({ label: "部门/人员", value: `${deptUserUsernames.length}项` });
  }
  
  if (workflowNo.length > 0) {
    const names = workflowNo.map((no) => {
      const wfOption = workflowOptions.find((opt) => opt.value === no);
      return wfOption?.label || no;
    });
    tags.push({ label: "工作流", value: names.join(", ") });
  }

  return tags;
}, [taskName, taskId, requirementName, projectName, userId, status, flowType, createTimeRange, deptUserUsernames, workflowNo, workflowOptions]);
```

## 数据流

```
页面初始化
  ↓
URL参数检查
  ├─ 有URL参数 → 使用URL参数初始化筛选条件
  ├─ 无URL参数 → 从sessionStorage恢复
  └─ 都没有 → 使用默认值（当前登录用户）
  ↓
构建查询参数
  ��
调用 useTasksWithSummary(current, pageSize, queryParams)
  ↓
发送API请求 (GET /api/taskInfo/list)
  ↓
接收任务列表数据
  ↓
渲染表格 + 分页器
  ↓
用户操作
  ├─ 修改筛选条件 → 更新输入态
  ├─ 点击查询 → 将输入态应用到查询态 → 重新查询
  ├─ 点击重置 → 清空所有筛选条件 → 重新查询
  ├─ 切换页码 → 更新current → 重新查询
  ├─ 点击任务 → 保存筛选状态 → 跳转到对话页
  ├─ 点击用户 → 保存筛选状态 → 跳转到Dashboard
  ├─ 点击统计数据 → 显示弹窗
  └─ 点击删除 → 确认弹窗 → 调用删除API → 刷新列表
```

## 常见问题

### 1. 筛选条件丢失？

**原因**: 未调用 `saveFilterState` 保存状态。

**解决方案**:
```typescript
// 导航前保存筛选状态
const handleNavigate = useCallback(
  (path: string) => {
    saveFilterState();
    navigate(path);
  },
  [saveFilterState, navigate],
);

// 使用handleNavigate替代直接的navigate
<a onClick={() => handleNavigate(`/conversations/${record.taskId}`)}>
  {displayTitle}
</a>
```

### 2. URL参数不生效？

**原因**: `initializedFromQuery` 标志未正确设置或useEffect依赖错误。

**解决方案**:
```typescript
// 确保useEffect只执行一次
const [initializedFromQuery, setInitializedFromQuery] = useState(false);

useEffect(() => {
  if (initializedFromQuery) return; // 已初始化，直接返回
  
  // URL参数优先级最高
  const hasUrlParams = urlUserId || (urlStart && urlEnd) || urlStatus;
  if (hasUrlParams) {
    // 处理URL参数
    setInitializedFromQuery(true);
    return;
  }
  
  // 其次尝试从sessionStorage恢复
  const savedState = loadFilterState();
  if (savedState) {
    // 恢复状态
    setInitializedFromQuery(true);
    return;
  }
  
  // 最后使用默认值
  setInitializedFromQuery(true);
}, [initializedFromQuery, searchParams]);
```

### 3. 筛选后页码未重置？

**原因**: 查询时忘记重置页码。

**解决方案**:
```typescript
const handleSearch = () => {
  setTaskName(taskNameInput?.trim() || "");
  setStatus(statusInput);
  // ... 其他字段
  setCurrent(1); // 重要：重置到第一页
};
```

### 4. 部门/人员筛选不工作？

**原因**: 未正确提取用户名列表传递给API。

**解决方案**:
```typescript
// 使用DepartmentUserSelector组件
<DepartmentUserSelector
  value={deptUserSelectionInput}
  onChange={handleDeptUserSelectionChange}
/>

// 正确处理选择变更
const handleDeptUserSelectionChange = useCallback(
  (newValue: SelectedItem[], usernames: string[]) => {
    setDeptUserSelectionInput(newValue);
    setDeptUserUsernamesInput(usernames); // 提取用户名列表
  },
  [],
);

// 传递给API
const queryParams = {
  // 单用户筛选
  userId: userId || undefined,
  // 多用户筛选（部门/人员）
  userIds: deptUserUsernames.length > 0 ? deptUserUsernames : undefined,
};
```

### 5. 时间选择器无法选择未来日期？

**原因**: 设置了 `disabledDate` 函数禁用未来日期。

**解决方案**:
```typescript
// 禁用未来日期（业务需求）
const disabledDate: RangePickerProps["disabledDate"] = (date) =>
  date && date > dayjs().endOf("day");

// 如果需要允许未来日期，移除此配置
<RangePicker
  showTime
  format="YYYY-MM-DD HH:mm:ss"
  value={createTimeRangeInput}
  onChange={(dates) => setCreateTimeRangeInput(dates)}
  // disabledDate={disabledDate} // 移除此行
/>
```

### 6. 表格横向滚动不流畅？

**原因**: 列宽度设置不合理或未设置 `scroll` 属性。

**解决方案**:
```typescript

}
```
