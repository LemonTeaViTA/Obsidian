# 通用组件库

## 概述

AI Agent Platform 使用多个UI组件库构建界面，主要包括 Ant Design 5、HeroUI 2 和自定义组件。Ant Design 提供企业级组件，HeroUI 提供现代化的UI组件，自定义组件满足特定业务需求。

## 核心组件库

### 3. 自定义组件

#### BrandButton - 品牌按钮

```typescript
// src/components/features/settings/brand-button.tsx
import { Button } from '@heroui/react';
import { cn } from '#/utils/cn';

interface BrandButtonProps {
  variant?: 'primary' | 'secondary' | 'danger';
  size?: 'sm' | 'md' | 'lg';
  isDisabled?: boolean;
  isLoading?: boolean;
  children: React.ReactNode;
  onClick?: () => void;
  type?: 'button' | 'submit' | 'reset';
  className?: string;
  testId?: string;
}

export function BrandButton({
  variant = 'primary',
  size = 'md',
  isDisabled = false,
  isLoading = false,
  children,
  onClick,
  type = 'button',
  className,
  testId,
}: BrandButtonProps) {
  const baseStyles = 'font-semibold transition-all duration-200';
  
  const variantStyles = {
    primary: 'bg-[#22D3EE] text-white hover:bg-[#06B6D4]',
    secondary: 'bg-[#71717A] text-white hover:bg-[#52525B]',
    danger: 'bg-[#EF4444] text-white hover:bg-[#DC2626]',
  };

  return (
    <Button
      type={type}
      size={size}
      isDisabled={isDisabled || isLoading}
      isLoading={isLoading}
      onClick={onClick}
      className={cn(baseStyles, variantStyles[variant], className)}
      data-testid={testId}
    >
      {children}
    </Button>
  );
}
```

**使用示例**:
```typescript
<BrandButton
  variant="primary"
  size="md"

>
  提交任务
</BrandButton>
```

#### Loading - 加载指示器

```typescript
// src/components/shared/loading.tsx
import { Spinner } from '@heroui/react';

interface LoadingProps {
  size?: 'sm' | 'md' | 'lg';
  text?: string;
  fullScreen?: boolean;
}

export function Loading({ size = 'md', text, fullScreen = false }: LoadingProps) {
  const content = (
    <div className="flex flex-col items-center gap-3">
      <Spinner size={size} />
      {text && <p className="text-default-500">{text}</p>}
    </div>
  );

  if (fullScreen) {
    return (
      <div className="fixed inset-0 flex items-center justify-center bg-black/50 z-50">
        {content}
      </div>
    );
  }

  return (
    <div className="flex items-center justify-center p-8">
      {content}
    </div>
  );
}
```

## 常见问题

### 1. 如何自定义Ant Design组件样式？

```typescript
// 方法1: 使用className（推荐）
<Table className="custom-table" />

// 方法2: 使用内联样式
<Button style={{ backgroundColor: '#22D3EE' }}>按钮</Button>

// 方法3: 使用ConfigProvider主题配置
<ConfigProvider theme={{ components: { Button: { ... } } }}>
```

### 2. Tailwind CSS样式不生效？

检查 `tailwind.config.js` 配置：
```javascript
module.exports = {
  content: [
    './src/**/*.{js,jsx,ts,tsx}',  // 确保包含所有文件
  ],
  // ...
}
```

### 3. 如何实现暗色模式？

```typescript
// 使用Tailwind的dark模式
<div className="bg-white dark:bg-[#09090B]">
  <p className="text-black dark:text-white">内容</p>
</div>

// 或使用HeroUI的主题切换
import { useTheme } from '@heroui/react';

function ThemeToggle() {
  const { theme, setTheme } = useTheme();
  
  return (
    <button onClick={() => setTheme(theme === 'dark' ? 'light' : 'dark')}>
      切换主题
    </button>
  );
}
```
