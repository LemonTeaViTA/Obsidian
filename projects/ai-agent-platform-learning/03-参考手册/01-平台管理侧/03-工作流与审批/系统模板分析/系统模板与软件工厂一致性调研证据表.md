三、跨领域共性问题

COM-01 系统模板存在不等于工作流已经引用

状态：已确认机制存在，当前工作流绑定待确认。

结论：AI24 的 Stage 和 Convention 保存具体 templateId。系统模板创建新版本时会生成新的 UUID，但现有工作流记录不会因为名称相同自动改绑。只有工作流发布新版本或命中最新工作流白名单时，查询才可能转向新绑定。

COM-02 Stage 与 Convention 使用两条不同的获取链路

状态：已确认。

结论：Code Agent 执行斜杠命令时使用 promptType=1 获取 Stage；系统提示只在看到 `@` 开头的引用时要求用 promptType=2 获取 Convention。普通文件名不会触发 Convention 获取，把 Stage 命令写成 `@` 引用也不会自动转成 Stage 查询。
