## 🔄 主要变化一览

### ✅ 已改进的问题

1. **TDD 审批服务通用化**
   - `TddApprovalFeedbackService` → `ApprovalFeedbackService`
   - 支持多种审批类型（技术方案、测试清单、领域划分等）

2. **Web 视觉验证工具升级**
   - Figma 官方 MCP 对接（`ui_mcp_type='figma'`）
   - 节点级验证流程 V3
   - assetRef 机制（短引用 + 服务端存储）

3. **产物协同机制**
   - 新增产物更新接口
   - 自动影响评估和下游通知

### 🔄 需要重新验证的问题

1. **前端 Proposal 目录一致性**
2. **后端测试脚本 manifest 字段协议**
3. **TDD 状态同步问题**
4. **视觉验证工具实际配置**
5. **客户端占位符替换机制**

### 🆕 新增功能

1. **Topology 拓扑图查询**
   - 代码依赖关系可视化
   - 支持增量更新（每秒刷新）
   - 提供本地测试工具和文档

2. **MCP 服务增强**
   - 新增 backstage、neo4j-query-remote MCP
   - 独立的 Web 验证 MCP Server
   - 所有 MCP 支持 `alwaysLoad` 配置
