## 概念边界

- `agentTaskData` / `agentClaudeData`：管理平台提供的结构化状态数据接口。
- COS：任务目录、PRD 和 Claude 会话文件的实时备份来源之一。
- OSS / DEP / Git：按资源类型参与恢复，不是所有资源都走同一条恢复链。
- TaskSessionMapper：维护 `task_id` 与 `session_id` 的双向映射。
- Claude SDK `resume`：使用 `session_id` 续接会话；跨机器时仍可能需要恢复本地会话文件。
- Hook：当前项目主要使用 `PreToolUse`、`PostToolUse` 和 `Stop`，没有独立的 `CompletedCommand Hook` 类型。
