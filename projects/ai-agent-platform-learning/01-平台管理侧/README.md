## 🎯 核心概念

### 工作流三层结构

```
spec_workflow (工作流配置)
    ├─ workflow_no: 工作流编号
    ├─ workflow_name: 工作流名称
    └─ workflow_template_id: 模板ID
    
spec_stage (阶段配置)
    ├─ stage_no: 阶段编号
    ├─ stage_name: 阶段名称
    ├─ need_approval: 是否需要审批
    └─ next_stage_no: 下一阶段

spec_convention (约束规范)
    ├─ convention_name: 约束名称
    └─ convention_content: 约束内容
```

### 任务状态机

```
0 (初始) → 100 (初始化完成) → 200 (执行中) 
                                    ↓
                              500 (完成)
                                    ↓
                              -1 (失败)
```

### 审批流程

```
code-agent 完成阶段
    ↓
上报审批事项 (approval_item, status=PENDING)
    ↓
产品/测试审批
    ├─ 全部通过 → onAllApproved() → 创建下一阶段任务
    └─ 存在拒绝 → onSomeRejected() → queryTask 打回重做
```
