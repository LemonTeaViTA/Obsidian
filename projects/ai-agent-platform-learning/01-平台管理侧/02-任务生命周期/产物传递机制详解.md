## 🎯 核心认知

### 什么是产物传递？

**产物 (Artifact)**: 任务执行过程中生成的中间结果，例如：
- PRD 文档
- 领域拆分结果
- 设计文档
- 代码变更清单
- 测试报告

**产物传递**: 将上游任务的产物传递给下游任务使用

**典型场景**:
```
任务A (PRD编写)
  ↓ 产物: prd.md
任务B (领域拆分) 
  ↓ 产物: domain_split.json
任务C (应用拆分)
  ↓ 产物: app_list.json
任务D (代码开发)
```

**核心挑战**:
- ❓ 什么时候传递产物？(任务完成时 vs 审批通过时)
- ❓ 传递给谁？(直接子任务 vs 整个编排链路)
- ❓ 如何处理审批场景？(PRD审核完成后的特殊逻辑)
- ❓ 如何避免重复传递？(幂等性保证)

## 一、产物传递的触发时机

### 1.1 标准触发时机

**时机1: 任务执行完成** (最常见)
```java
// TaskExecutionService.java
public void onTaskComplete(String taskId) {
    // 1. 标记任务完成
    taskManager.updateStatus(taskId, TaskStatus.COMPLETED);
    
    // 2. 触发产物传递
    artifactTransferService.transferArtifactsToDownstream(taskId);
    
    // 3. 触发下游任务
    orchestrationService.triggerNextTasks(taskId);
}
```

**时机2: 审批通过** (需要人工确认的任务)
```java
// ApprovalService.java
public void onApprovalPassed(Long approvalItemId) {
    String taskId = getTaskId(approvalItemId);
    
    // 1. 标记审批通过
    approvalItemManager.updateStatus(approvalItemId, ApprovalStatus.APPROVED);
    
    // 2. 触发产物传递
    artifactTransferService.transferArtifactsToDownstream(taskId);
    
    // 3. 触发下游任务
    orchestrationService.triggerNextTasks(taskId);
}
```

**时机3: PRD审核完成** (特殊场景 - commit e6623b783)
```java
// RequirementFlowService.java
public void onPrdReviewComplete(String requirementId) {
    // PRD审核完成，但编排任务还未创建
    // 需要在创建编排任务时传递PRD产物
    
    // 标记: PRD已完成，等待创建编排任务
    requirementManager.markPrdReviewCompleted(requirementId);
}

// OrchestrationService.java
public void createOrchestrationTasks(String requirementId) {
    // 创建编排任务时，检查PRD是否已完成
    if (requirementManager.isPrdReviewCompleted(requirementId)) {
        // 立即传递PRD产物到编排任务
        String prdTaskId = requirementManager.getPrdTaskId(requirementId);
        artifactTransferService.transferArtifacts(prdTaskId, orchestrationTaskId);
    }
}
```

### 1.2 触发时机对比

| 触发时机 | 适用场景 | 优点 | 缺点 |
|---------|---------|------|------|
| 任务完成时 | 自动化任务 | 实时传递，无需等待 | 可能传递未审核内容 |
| 审批通过时 | 需人工确认 | 保证质量，可追溯 | 有延迟，需要人介入 |
| 延迟传递 | 编排场景 | 灵活适配复杂流程 | 实现复杂，容易遗漏 |

## 二、产物传递规则优化 (commit a52113537)

### 2.1 优化前的问题

**问题1: 传递范围不明确**
```java
// 旧逻辑: 传递给所有相关任务
artifactTransferService.transferToAll(taskId);
// 结果: 不相关的任务也收到产物，造成干扰
```

**问题2: 重复传递**
```java
// 场景: 任务A → 任务B → 任务C
// 任务A完成时传递给B和C
// 任务B完成时又传递给C
// 结果: C收到重复产物
```

**问题3: 时序问题**
```java
// PRD审批完成 → 创建编排任务
// 但产物传递在审批完成时触发
// 此时编排任务还不存在，传递失败
```

### 2.2 优化后的规则

**规则1: 只传递给直接下游任务**

```java
public void transferArtifactsToDownstream(String sourceTaskId) {
    // 1. 查询直接下游任务 (非递归)
    List<String> downstreamTaskIds = orchestrationManager.getDirectDownstream(sourceTaskId);
    
    // 2. 只传递给直接下游
    for (String targetTaskId : downstreamTaskIds) {
        transferArtifacts(sourceTaskId, targetTaskId);
    }
}
```

**规则2: 幂等性保证**

```java
public void transferArtifacts(String sourceTaskId, String targetTaskId) {
    // 1. 检查是否已传递
    if (artifactTransferRecordManager.exists(sourceTaskId, targetTaskId)) {
        log.info("产物已传递，跳过: {} -> {}", sourceTaskId, targetTaskId);
        return;
    }
    
    // 2. 执行传递
    List<ArtifactDO> artifacts = artifactManager.listByTaskId(sourceTaskId);
    for (ArtifactDO artifact : artifacts) {
        copyArtifactToTarget(artifact, targetTaskId);
    }
    
    // 3. 记录传递历史
    artifactTransferRecordManager.insert(
        new ArtifactTransferRecordDO(sourceTaskId, targetTaskId, new Date())
    );
}
```

**规则3: 延迟传递支持**

```java
public void transferPrdArtifactWhenOrchestrationCreated(String requirementId, String orchestrationTaskId) {
    // 1. 查询PRD任务ID
    String prdTaskId = requirementManager.getPrdTaskId(requirementId);
    
    // 2. 检查PRD是否已审核完成
    if (!requirementManager.isPrdReviewCompleted(requirementId)) {
        log.warn("PRD未审核完成，不传递产物");
        return;
    }
    
    // 3. 传递PRD产物
    transferArtifacts(prdTaskId, orchestrationTaskId);
}
```

## 三、核心实现：ArtifactTransferService

### 3.1 服务接口定义

```java
public interface ArtifactTransferService {
    
    /**
     * 传递产物到下游任务
     * @param sourceTaskId 源任务ID
     */
    void transferArtifactsToDownstream(String sourceTaskId);
    
    /**
     * 传递产物到指定任务
     * @param sourceTaskId 源任务ID
     * @param targetTaskId 目标任务ID
     */
    void transferArtifacts(String sourceTaskId, String targetTaskId);
    
    /**
     * 批量传递产物
     * @param sourceTaskId 源任务ID
     * @param targetTaskIds 目标任务ID列表
     */
    void batchTransferArtifacts(String sourceTaskId, List<String> targetTaskIds);
    
    /**
     * 查询产物传递历史
     * @param sourceTaskId 源任务ID
     * @return 传递记录列表
     */
    List<ArtifactTransferRecord> queryTransferHistory(String sourceTaskId);
}
```

### 3.2 实现类

```java
@Service
public class ArtifactTransferServiceImpl implements ArtifactTransferService {
    
    @Autowired
    private ArtifactManager artifactManager;
    
    @Autowired
    private ArtifactTransferRecordManager transferRecordManager;
    
    @Autowired
    private OrchestrationManager orchestrationManager;
    
    @Override
    public void transferArtifactsToDownstream(String sourceTaskId) {
        // 1. 查询直接下游任务
        List<String> downstreamTaskIds = orchestrationManager.getDirectDownstream(sourceTaskId);
        
        if (CollectionUtils.isEmpty(downstreamTaskIds)) {
            log.info("任务 {} 没有下游任务，无需传递产物", sourceTaskId);
            return;
        }
        
        // 2. 批量传递
        batchTransferArtifacts(sourceTaskId, downstreamTaskIds);
    }
    
    @Override
    public void transferArtifacts(String sourceTaskId, String targetTaskId) {
        // 1. 幂等性检查
        if (transferRecordManager.exists(sourceTaskId, targetTaskId)) {
            log.info("产物已传递，跳过: {} -> {}", sourceTaskId, targetTaskId);
            return;
        }
        
        // 2. 查询源任务的所有产物
        List<ArtifactDO> artifacts = artifactManager.listByTaskId(sourceTaskId);
        
        if (CollectionUtils.isEmpty(artifacts)) {
            log.info("任务 {} 没有产物，无需传递", sourceTaskId);
            return;
        }
        
        // 3. 复制产物到目标任务
        for (ArtifactDO artifact : artifacts) {
            ArtifactDO copy = new ArtifactDO();
            copy.setTaskId(targetTaskId);
            copy.setArtifactType(artifact.getArtifactType());
            copy.setArtifactKey(artifact.getArtifactKey());
            copy.setArtifactValue(artifact.getArtifactValue());
            copy.setArtifactPath(artifact.getArtifactPath());
            copy.setSourceTaskId(sourceTaskId);  // 记录来源
            artifactManager.insert(copy);
        }
        
        // 4. 记录传递历史
        ArtifactTransferRecordDO record = new ArtifactTransferRecordDO();
        record.setSourceTaskId(sourceTaskId);
        record.setTargetTaskId(targetTaskId);
        record.setTransferTime(new Date());
        record.setArtifactCount(artifacts.size());
        transferRecordManager.insert(record);
        
        log.info("产物传递成功: {} -> {}, 共 {} 个产物", sourceTaskId, targetTaskId, artifacts.size());
    }
    
    @Override
    @Transactional
    public void batchTransferArtifacts(String sourceTaskId, List<String> targetTaskIds) {
        for (String targetTaskId : targetTaskIds) {
            try {
                transferArtifacts(sourceTaskId, targetTaskId);
            } catch (Exception e) {
                log.error("产物传递失败: {} -> {}", sourceTaskId, targetTaskId, e);
                // 继续处理其他目标任务
            }
        }
    }
    
    @Override
    public List<ArtifactTransferRecord> queryTransferHistory(String sourceTaskId) {
        return transferRecordManager.listBySourceTaskId(sourceTaskId);
    }
}
```

## 四、数据模型

### 4.1 产物表 (spec_artifact)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| `id` | BIGINT | 主键 |

| `artifact_key` | VARCHAR(100) | 产物键 (文件名或标识) |
| `artifact_value` | TEXT | 产物内容 (小文件) 或引用路径 |
| `artifact_path` | VARCHAR(500) | 产物存储路径 (COS/本地) |
| `source_task_id` | VARCHAR(50) | 来源任务ID (传递时记录) |
| `create_time` | DATETIME | 创建时间 |

**示例数据**:

### 4.2 产物传递记录表 (spec_artifact_transfer_record)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| `id` | BIGINT | 主键 |
| `source_task_id` | VARCHAR(50) | 源任务ID |
| `target_task_id` | VARCHAR(50) | 目标任务ID |
| `transfer_time` | DATETIME | 传递时间 |
| `artifact_count` | INT | 传递的产物数量 |

**作用**:
- 幂等性保证：避免重复传递
- 审计追踪：查看产物流转路径
- 问题排查：定位传递失败原因

## 五、特殊场景处理

### 5.1 PRD审核完成场景 (commit e6623b783)

**问题**: PRD审核完成后，编排任务创建时产物没有传递

**原因分析**:
```
时序问题:
  1. PRD任务完成 → 提交审批
  2. 审批通过 → 触发产物传递
  3. 此时编排任务还未创建
  4. 产物传递失败
  5. 后续创建编排任务时，没有触发产物传递
```

**解决方案**:

**步骤1: 标记PRD审核完成**
```java
// RequirementFlowService.java
public void onPrdApprovalPassed(String requirementId) {
    // 标记PRD审核完成
    RequirementInfoDO requirement = requirementManager.getById(requirementId);
    requirement.setPrdReviewStatus(PrdReviewStatus.COMPLETED.getCode());
    requirement.setPrdReviewTime(new Date());
    requirementManager.updateById(requirement);
}
```

**步骤2: 创建编排任务时传递产物**
```java
// OrchestrationService.java
public String createOrchestrationTask(CreateOrchestrationRequest request) {
    String requirementId = request.getRequirementId();
    
    // 1. 创建编排任务
    String orchestrationTaskId = createTask(request);
    
    // 2. 检查PRD是否已审核完成
    RequirementInfoDO requirement = requirementManager.getById(requirementId);
    if (PrdReviewStatus.COMPLETED.getCode().equals(requirement.getPrdReviewStatus())) {
        // 3. 查询PRD任务ID
        String prdTaskId = requirement.getPrdTaskId();
        
        // 4. 传递PRD产物到编排任务
        artifactTransferService.transferArtifacts(prdTaskId, orchestrationTaskId);
        
        log.info("PRD审核完成，产物已传递到编排任务: {} -> {}", prdTaskId, orchestrationTaskId);
    }
    
    return orchestrationTaskId;
}
```

### 5.2 编排任务链传递

**场景**: 编排任务内部有多个节点，产物需要逐级传递

```
编排任务 orchestration_001
  ├─ 节点1: 领域拆分 (domain_split)
  ├─ 节点2: 应用拆分 (app_split)
  └─ 节点3: 代码生成 (code_gen)
```

**传递逻辑**:
```java
// OrchestrationExecutionService.java
public void onNodeComplete(String orchestrationTaskId, String nodeId) {
    // 1. 查询节点信息
    OrchestrationNodeDO node = orchestrationNodeManager.getById(nodeId);
    
    // 2. 查询下游节点
    List<OrchestrationNodeDO> downstreamNodes = 
        orchestrationNodeManager.listDownstream(orchestrationTaskId, nodeId);
    
    // 3. 传递产物到下游节点对应的任务
    for (OrchestrationNodeDO downstreamNode : downstreamNodes) {
        String downstreamTaskId = downstreamNode.getTaskId();
        artifactTransferService.transferArtifacts(node.getTaskId(), downstreamTaskId);
    }
}
```

### 5.3 产物拉取接口 (前端主动拉取)

**背景**: 有时下游任务需要主动拉取上游产物，而非被动接收

**接口设计**:
```java
@RestController
@RequestMapping("/api/artifact")
public class ArtifactController {
    
    /**
     * 拉取上游任务产物
     * @param taskId 当前任务ID
     * @return 可用的上游产物列表
     */
    @GetMapping("/pull-upstream")
    public Result<List<ArtifactVO>> pullUpstreamArtifacts(@RequestParam String taskId) {
        // 1. 查询上游任务
        List<String> upstreamTaskIds = orchestrationManager.getUpstreamTasks(taskId);
        
        // 2. 汇总上游产物
        List<ArtifactVO> artifacts = new ArrayList<>();
        for (String upstreamTaskId : upstreamTaskIds) {
            List<ArtifactDO> upstreamArtifacts = artifactManager.listByTaskId(upstreamTaskId);
            artifacts.addAll(convertToVO(upstreamArtifacts));
        }
        
        return Result.success(artifacts);
    }
}
```

**前端调用**:
```javascript
// 代码生成任务启动时，拉取上游的领域拆分和应用拆分结果
const response = await api.pullUpstreamArtifacts(taskId);
const domainSplit = response.data.find(a => a.artifactType === 'domain_split');
const appSplit = response.data.find(a => a.artifactType === 'app_split');
```

### 6.2 产物存储策略

**小文件** (< 1MB): 直接存储在数据库
```java
artifact.setArtifactValue(content);  // 存储内容
artifact.setArtifactPath(null);
```

**大文件** (> 1MB): 存储在COS，数据库记录路径
```java
String cosPath = cosService.upload(content, "artifacts/" + taskId + "/" + filename);
artifact.setArtifactValue(null);
artifact.setArtifactPath(cosPath);  // 存储路径
```

### 6.3 产物版本管理

```java
// 产物键增加版本号
artifact.setArtifactKey("design_v2.md");

// 或使用时间戳
artifact.setArtifactKey("design_20260723.md");
```

### 6.4 错误处理

```java
public void transferArtifacts(String sourceTaskId, String targetTaskId) {
    try {
        // 传递逻辑
        doTransfer(sourceTaskId, targetTaskId);
    } catch (Exception e) {
        // 记录失败
        ArtifactTransferRecordDO record = new ArtifactTransferRecordDO();
        record.setTransferStatus(TransferStatus.FAILED.getCode());
        record.setErrorMessage(e.getMessage());
        transferRecordManager.insert(record);
        
        // 发送告警
        alertService.sendAlert("产物传递失败", sourceTaskId, targetTaskId, e);
        
        throw e;  // 重新抛出，触发重试机制
    }
}
```

## 七、监控与排查

### 7.1 产物传递监控指标

```sql
-- 产物传递成功率
SELECT 
    DATE(transfer_time) AS date,
    COUNT(*) AS total,
    SUM(CASE WHEN transfer_status = 0 THEN 1 ELSE 0 END) AS success,
    SUM(CASE WHEN transfer_status = 1 THEN 1 ELSE 0 END) AS failed
FROM spec_artifact_transfer_record
WHERE transfer_time >= DATE_SUB(NOW(), INTERVAL 7 DAY)
GROUP BY DATE(transfer_time);
```

### 7.2 产物流转路径查询

```sql
-- 查询某个产物的完整流转路径
WITH RECURSIVE transfer_chain AS (
    -- 起点: 原始产物
    SELECT 
        task_id AS current_task,
        NULL AS previous_task,
        1 AS level
    FROM spec_artifact
    WHERE artifact_key = 'requirement.md' AND source_task_id IS NULL
    
    UNION ALL
    
    -- 递归: 查找下游传递
    SELECT 
        r.target_task_id,
        r.source_task_id,
        tc.level + 1
    FROM spec_artifact_transfer_record r
    JOIN transfer_chain tc ON r.source_task_id = tc.current_task
)
SELECT * FROM transfer_chain;
```

### 7.3 常见问题排查

**问题1: 下游任务没有收到产物**

检查清单:
```sql
-- 1. 检查上游任务是否有产物
SELECT * FROM spec_artifact WHERE task_id = 'upstream_task_id';

-- 2. 检查是否有传递记录
SELECT * FROM spec_artifact_transfer_record 
WHERE source_task_id = 'upstream_task_id' AND target_task_id = 'downstream_task_id';

-- 3. 检查传递记录的状态
SELECT * FROM spec_artifact_transfer_record WHERE transfer_status = 1;  -- 失败记录
```

**问题2: 产物重复传递**

```sql
-- 查询重复传递记录
SELECT source_task_id, target_task_id, COUNT(*) as count
FROM spec_artifact_transfer_record
GROUP BY source_task_id, target_task_id
HAVING count > 1;
```
