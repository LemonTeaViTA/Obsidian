## 💡 提炼的核心要点

### 核心概念1：三个系统协作
```
前端 (ai-program-factory)
  ↓ HTTP
ai24 (管理平台)
  ↓ HTTP
code-agent (执行引擎)
  ↓ Claude SDK
Claude API
```

### 核心概念2：八站链路
```
站1：前端发起
站2：Controller 校验
站3：Service 创建任务
站4：下发 code-agent
站5：初始化项目
站6：执行任务
站7：上报状态
站8：前端更新
```

### 核心概念3：异步执行模型
```
ai24 POST /task/perform → code-agent
  ↓ 立即返回 202 Accepted
  ↓ 新线程执行
  ↓ 执行完成
  ↓ 回调 ai24
```

### 核心概念4：可配置工作流
```
spec_workflow (工作流配置)
  ↓
spec_stage (阶段配置)
  ↓
spec_convention (约束规范)
```
