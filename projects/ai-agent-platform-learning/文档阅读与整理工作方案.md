## 🔧 三遍阅读法

### 第一遍：快速扫描（5分钟/篇）
```
只看：
✓ 标题
✓ 目录结构  
✓ 小标题
✓ 流程图/架构图
✓ 代码示例的注释

目的：了解这篇讲什么
```

### 第二遍：重点精读（15分钟/篇）
```
重点读：
✓ "为什么"部分（设计思路）
✓ "如何工作"部分（核心原理）
✓ 关键代码（带注释）
✓ 流程图说明

目的：理解核心原理
```

### 第三遍：提炼记录（10分钟/篇）
```
记录：
✓ 核心概念（3-5个关键词）
✓ 关键流程（用自己的话）
✓ 代码片段（最核心的几行）
✓ 面试亮点（可讲的点）

目的：提取精华
```
