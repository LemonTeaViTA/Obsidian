# 项目总览与开场介绍

**是什么**：对标 Claude Code 的本地 Java Agent CLI，用自然语言驱动代码开发、调试和自动化。

**为什么**：想深入理解 Agent 工程化落地的真实问题——执行循环、工具调用、上下文管理、安全，从零实现而不只是调 API。

**怎么做**：
- 执行层：三条路径 ReAct / Plan-and-Execute / Multi-Agent，按任务复杂度切换，共享同一套工具与记忆栈
- 模型层：数据驱动多平台适配（SeriesQuirks 注册表）+ 故障转移
- 上下文层：长上下文动态压缩 + prompt cache 省钱
- 工具生态：12 个内置工具并行 + MCP 协议 + Chrome 浏览器自动化
- 安全层：HITL 审批 + 路径围栏 + 命令黑名单 + 操作审计

**关键权衡**：三条路径共享工具栈和记忆栈，不是三套独立系统——灵活性和可控性按任务复杂度按需切换。

---

## 开场话术（一分钟版）

> SageCLI 是对标 Claude Code 的终端编程 Agent。核心是三条执行路径——简单任务走 ReAct，多步依赖任务走 Plan-and-Execute（拆成 DAG 并行执行），需要质量审查的走 Multi-Agent，三条共享同一套工具和记忆。底下支撑它的有：数据驱动的多模型适配 + 故障转移、长上下文动态压缩、MCP 工具生态、浏览器自动化，以及 HITL + 路径围栏 + 命令黑名单的安全纵深。比较得意的是多模型注册表（加平台只改配置）和绝对预留的压缩策略。

## 常见坑

- `reflection` 不是第四条路径，它是 Multi-Agent 里 Reviewer 审查未通过后带反馈重试的机制
- 开场不要平铺功能清单，先讲定位 + 动机，再分层讲架构
